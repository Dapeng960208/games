## 三个 M12 的运行时表示

M12 #5/#6/#7 的精确旧区域比例需要略超出原生 1254² PNG 的透明空间。仅这三条可使用 `scripts/combat/variant_hd_texture.gd`：

1. 验证原生尺寸 1254²、虚拟尺寸 1280²，以及精确整数偏移 #5=(0,0)、#6=(6,0)、#7=(0,0)
2. 验证完整原生图与虚拟登记区域均在虚拟画布内，原生/虚拟区域和脚点平移一致，安全原生采样区及目标比例与计算交集一致
3. 新建全透明 RGBA8 画布，以 `blit_rect` 原样复制原生像素后生成 mip；无缩放、混合、锐化、重绘或 alpha 清理，不写 PNG
4. 按三个精确路径缓存，最多三张 1280² 纹理；RGBA+mip 约 25 MiB。原生临时图不另存为共享 sampled GPU 纹理
5. `EnemyArt` 继续按原高度统一缩放；既有身体绘制、接触 alpha 掩模、无子节点回退绘制及死亡快照收到合法的虚拟纹理/区域，无需更改各消费者接口

源码在场时直接解码 PNG；导出回退使用无损导入。三个 M12 `.png.import` 必须设置 `process/fix_alpha_border=false`，避免导入器改写透明边缘 RGB。虚拟纹理之外的 19 个允许项继续使用现有采样器。
