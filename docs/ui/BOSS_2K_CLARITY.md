# 四首领战斗身体的原生高清接入

2026-10-02。范围仅为 BO01–BO04 的身体纹理与注册；没有生成新图、修改原 PNG、改镜头、碰撞、伤害、AI、技能时间或房间数据。

## 问题与来源确认

生产战斗通过 `EnemyVisual.configure → EnemyArt.install` 覆盖早期 boss portrait。此前最终绘制的是四张 `storybook_B0x_bodies_v2.png` 图集中的小区域，不能根据 `BossProfiles.visual_asset` 或 `render_state().asset_path` 的旧路径断言实际身体已高清。

逐张检查了当前图集、BO04 原生 2560×1440 房间截图，以及 `assets/generated/ui/refactor_v1/codex/BO01.png` 至 `BO04.png` 的真实像素。四张已批准的 1254×1254 RGBA 图均包含完整身体、足部和武器，并与当前战斗身份一致：

- BO01：白金、青绿构装巨像与圆盾
- BO02：琥珀虫后、青色翅膀与前爪
- BO03：高礼帽缝合镇长、南瓜杖与手提灯
- BO04：绿皮红甲兽人酋长、角冠与大斧

原始生成、身份核验与像素来源继续以 `assets/generated/ui/refactor_v1/codex/provenance_bosses.json` 为准。旧 `assets/bosses/` 不是这轮实际身份的高清来源。没有把头像截取为战斗身体，也没有图像拉伸、放大插值或新制动作帧。

## 独立战斗注册

新增四份 `assets/generated/enemies/BO0x_storybook_body_hd_v1.regions.json`，明确记录纹理、SHA-256、有效 alpha 区域、source_height、source_identity、足点、旧来源和缩放约定。区域包围 alpha>16 的全部身体，并加 4 原生像素余量；纹理文件不变。

`EnemyArt` 最后加载该组 manifest。只有可解析、存在且 source_identity 对应的资源覆盖本首领的旧 atlas 项；资源失效时保留同身份旧图集回退。普通怪基础图与变体池不变。

战斗身体高度继续使用已有公式 `clamp(navigation_radius × 3.45, 170, 220) × 1.20`，足点 y=48 不变；横向足点按旧身体的相对注册位置映射至新完整源图。缩放为等比，保留批准新图比例，因此宽度会有少量自然变化，不能称每个外接框像素都不变。所有碰撞、导航与攻击判定仍由原角色参数决定。

| 首领 | 旧/新源区域高度 | 战斗高度 | 旧→新身体宽度 | 2K 显示高度 | 新源像素/显示像素 |
|---|---:|---:|---:|---:|---:|
| BO01 | 236→1104 | 223.56 | 228.30→247.66 | 380.05 | 2.90 |
| BO02 | 271→1201 | 248.40 | 262.15→252.95 | 422.28 | 2.84 |
| BO03 | 241→1188 | 215.28 | 217.96→212.02 | 365.98 | 3.25 |
| BO04 | 230→1176 | 256.68 | 257.80→258.86 | 436.36 | 2.70 |

以上为实际生产房间的 0.85 镜头、1280×720 逻辑画布和 2560×1440 窗口。旧图同场景约放大 1.52–1.90 倍；新图为有充足源像素的缩小采样。重复注册不再基于已放大的 boss bounds 叠加 1.20。

## 定向验证

`tests/test_boss_hd_art.gd` 使用实际四个房间、MineBoss、BossBrain、警示层和 HUD。在同一场景中分别恢复旧图集与新身体进行对照；只在隔离测试进程中替换内存注册表，不改变文件或正式运行数据。

Godot 4.7.2 无界面定向检查 **202 项通过、0 失败、无脚本/引擎错误**，覆盖：

- 完整 alpha 身体包围、真实源纹理/区域、身份匹配与原始1254²尺寸
- 新旧实际战斗高度、地面足点、角色位置、导航半径和完整 profile 相同
- 实际预警、锁定、释放与收势保持同一高清身体；警示层与 HUD 读取同一招式
- 释放身体动作、真实命中后的受击变化、高清 alpha 接触点和降低特效
- 重复注册三次不继续放大、偏移或改变碰撞

图形模式已在隔离的 X11 会话中完成 **242 项通过、0 失败**，生成并逐张独立目视检查全部 **20 张原生 2560×1440 帧**：每位首领的旧图待机、新图待机、新图前摇、释放、受击。全身、足部、武器和关键身份保留；旧图明显偏软的边缘和装备/面部细节在 HD 图中清晰，技能警示与施法 HUD 继续可读，受击没有残留第二层静态身体。BO03 仍是高礼帽镇长，BO04 仍是红甲绿皮兽人。截图中个别动作顶部接近血条属于既有局部姿态变换，不是源图裁切。

渲染记录为 Godot 4.7.2、OpenGL Compatibility、Mesa llvmpipe 软件渲染器；这是实际图形管线及原生帧缓冲的像素证据，不是硬件 GPU 性能验证。日志无 SCRIPT ERROR/ERROR，只有驱动不支持切换 VSync 的警告。截图、测量和日志保留在忽略的 `artifacts/boss-hd-art/` 与 `artifacts/boss-hd-gpu.log`，不入 Git。未操作用户当前运行的预览实例。

运行入口：`tools/test.ps1 -Suite boss_hd_art -Graphical -SkipImport`。也可直接以 Godot 4.7.2 启动 `tests/test_boss_hd_art.tscn` 并传入含 `test_boss_hd_art` 的独立 `--test-profile`；使用隔离用户目录，不能指向实际玩家存档。

## 边界

这轮复用的是原有静态全身图和姿态变换。未新增完整逐帧动作，不宣称自然战斗平衡或所有普通怪都已达到高清；旧普通怪变体另行只读审计，不混入四首领修复。
