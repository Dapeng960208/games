# 文档入口

文档与美术资源使用相同层级：职业、系统功能、关卡。当前状态以 [开发进度](DEVELOPMENT_PROGRESS.md) 为准，未实现事项见 [路线图](LEVEL_ROADMAP.md)，目录/命名和开发约束见 [开发规范](DEVELOPMENT_STANDARDS.md)。

| 分类 | 入口 | 对应资源 |
|---|---|---|
| 角色 | [characters](characters/README.md) | assets/characters/<profession> |
| 系统 | [system](system/README.md) | assets/system/<feature> |
| 关卡 | [levels](levels/README.md) | assets/levels/<chapter>；普通怪 enemies、首领 bosses |
| 工程 | [检查目录规范](engineering/test_workspace_policy.md) | tools/testing、tools/maintenance |
| 目录结构 | [目录结构规范](engineering/repository_structure.md) | 代码／资源／文档的完整放置规则 |
| 来源与许可 | [asset_licenses](legal/asset_licenses.md) | 素材旁来源记录及字体许可 |

正文统一标注“已接入”“候选／待验证”或“未实现”。未开放关卡与职业设计不计入可玩内容；数值设计和候选样本不计入正式验收。已失效的阶段记录、旧 PR 过程、重复初稿已删除。
