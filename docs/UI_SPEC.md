# 深渊拾荒者：M1 UI 规范

本次界面服务于可玩的单房间闭环。实现和实机验证分别记录于 [TEST_PLAN.md](TEST_PLAN.md)，不以本设计文档代替结果。

## 视觉与画布

逻辑画布为 1280×720；窗口缩放保持比例，其他宽高比可留边，不裁切交互区。1280×720、1920×1080、2560×1440 必须分别检查文字、焦点、弹窗与 HUD 边缘。使用直角或轻微切角、薄铜边、少量矿业机械装饰。战斗世界保持视觉主体。

| 用途 | Token |
|---|---|
| 背景 | `#0D131A` |
| 面板 | `#17232C` |
| 抬升面板 | `#20333D` |
| 主要文字 | `#F1EADC` |
| 次要文字 | `#B2BBC4` |
| 行动／提灯 | `#E6AA4A` |
| 遗物／矿物 | `#67C7D5` |
| 危险 | `#E46B69`，同时配文字或形状 |
| 成功 | `#80B69A`，同时配文字 |
| 间距 | 8、16、24、32 逻辑像素 |

正文目标 18、辅助说明至少 16、标题约 28—36。使用授权允许且覆盖中英文的字体。按钮目标高度至少 44；包含正常、悬停、焦点、按下、禁用状态。焦点轮廓不能只依赖颜色微差。避免大圆角、网页统计卡、毛玻璃、装饰性假控件和中央战斗遮挡。

## 页面与真实状态

| 页面 | 必要内容 | 返回／确认行为 |
|---|---|---|
| 主菜单 | 标题、继续、新游戏、设置、退出 | 无档案时继续不可用并有说明；已有档案时新游戏覆盖需确认；取消返回原焦点 |
| 营地 | 永久废金、真实永久发现、开始远征、返回主菜单、设置入口（若已实现） | 只显示已实现功能；不展示勘测台／遗物匣购买按钮 |
| 战斗 HUD | 生命、当前区域、携带废金、死亡保留、已实现动作及遗物 | 所有数字由游戏状态提供；底部仅显示普攻与冲刺，不展示脉冲或等级 |
| 遗物详情 | 当前装备、明确机制与触发条件、关闭 | 可暂停查看；空状态说明尚未拾取；Esc 关闭当前层 |
| 撤离确认 | 可带回数量、当前死亡保留量、确认撤离、继续战斗 | 显示真实数值；取消后恢复输入释放保护 |
| 暂停 | 继续、已实现设置、放弃远征 | 世界全部停止；放弃需二次确认并写明 20% 向下取整 |
| 结算 | 撤离／死亡／放弃标题、本局携带、带回、损失、永久余额、永久发现、返回营地 | 显示已提交记录；不在按钮事件中发奖；连点不会重复到账 |
| 设置 | 中英文、窗口／全屏、低闪烁 | 切换立即生效并持久保存；从上层打开后返回原页面与焦点 |

没有实现的音量分组、UI 缩放滑块、手柄设置、地图、升级三选一、永久解锁和保存继续不显示成可用操作。操作说明只列实际输入；不将未来动作保留为假槽位。

## 输入、暂停与焦点

键鼠：WASD 移动，鼠标瞄准，左键普攻，空格冲刺，E 交互，Tab 遗物详情，Esc 暂停／返回。按键通过输入动作映射管理。M1 不声称手柄完整支持。

弹窗使用栈：只有最上层面板接受输入；Esc 关闭一层；仍有暂停层时战斗继续停止。最后一层关闭才恢复世界。每次进入页面给出有效初始焦点，关闭嵌套面板后恢复打开它的控件；不可用按钮不得获得执行机会。点击或按键确认离开菜单后，必须释放战斗输入再重新触发。

远征中的应用关闭／返回请求必须说明放弃规则；确认后由游戏逻辑执行死亡式结算，保存完成才离开。不得提示“保存并继续”。未保存成功时保留可恢复的当前状态和错误提示。

## 本地化与辅助

已实现的菜单、HUD、遗物名称／说明、确认提示、错误信息和结算使用本地化键支持简体中文与英文。切换语言后当前打开页面同步刷新。为英文留约 40% 文本伸展空间，不依靠缩小字号避免溢出。

低闪烁设置应真实减少受伤／命中闪烁。危险仍保留轮廓、动作预警或文字，不能仅通过闪光传达。设置保持跨启动有效。暂不将未实现的音效与震动控制显示为可用选项。

## 实机检查重点

1. 生命、携带废金、死亡保留、冲刺冷却、遗物与结算来自同一份真实状态。
2. 中央区域能看清敌人的攻击预警、侧向子弹、燃烧和电弧。
3. 中英两种语言在三种目标分辨率下无截断、重叠或不可达按钮。
4. 鼠标及键盘焦点可辨识；弹窗返回顺序一致；取消不触发攻击。
5. 截图来自实际 Godot 运行，记录版本与窗口尺寸；概念图不作验收证据。
