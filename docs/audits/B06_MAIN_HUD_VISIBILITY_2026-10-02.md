# B06 真实 Main HUD 遮挡修复

## 范围与原因

基线为环境接线提交 `6e02e31`。真实 Main 的 2K 基线批次 `20261002T200222743812Z-ca08c88e`（472/0、无 engine/script ERROR）及机关靠近批次 `20261002T200613365114Z-da176267`（410/0、无 ERROR）暴露：L35 北钟在中心视角被顶部重复房间牌遮住；BO06 靠近视角的上缘、名称、血条被房间牌与技库牌遮住；L36 上下中央潮向箭头被顶板与技能栏盖住。靠近 L35 潮钟时原 F 提示已可见，不能把这个近景当作中心视角也通过。

## 实现

- 仅 `biome_id=B06` 且真实 `b06_candidate` 布局启用紧凑战斗排布；不改变命令行门槛、发布章节数、几何、单位位置、机关和战斗计时。
- 宽屏中收起顶部重复房间牌与装饰珠串。房名、目标、进度仍保留在右侧任务栏，路线 M 仍可打开；远征计数放在右上方。
- 五个技能槽以 0.70 的统一比例贴底，保留图标、技能名、键位、资源不足、施放/队列、冷却等既有读数与输入目标。1280×720 逻辑画布中每个目标至少 61.6×77；实际 2560×1440 输出上常驻 16px 字体为 22.4px。
- Boss 技库和实际施法牌均侧置，仍使用真实冻结预警的阶段、锁定、倒计时和进度。没有隐藏重要危险信息；地面危险绘制没有改动。
- 发现既有 B06 Boss 技能名会显示 `siege_claw` 等内部键，同步补齐运行 action ID 到章节正式中英文技能名的映射，未知键维持原保守回退；没有自创译名或改变招式规则。
- 离开 B06 时恢复原布局；其他章节不启用新布局。窄于 880 逻辑像素的堆叠界面保持现有布局，不在本轮像素验收范围。
