# 界面逐页截图审查

日期：2026-10-01。使用真实 Godot 4.7.2、OpenGL Compatibility 与 RTX 3060 Laptop GPU。先捕获改动前页面，再沿相同生产入口捕获改动后页面；102 张截图全部目视检查，另有按钮文字安全区、弹窗边界、成对操作及标题区域检查。当前记录覆盖 51 个界面状态的中英文版本。

## 发现与修复

| 问题 | 原来对使用的影响 | 修复结果与证据 |
|---|---|---|
| 标题、功能和导航挤在同一区域 | 工坊标题附近操作密集，缺少稳定层级 | 独立页头放标题／金币／返回，第二行放五个导航与当前功能；08–26、59–77 |
| 套装长名称压到卡片装饰线 | 英文南瓜与赤陶名称难读 | 安静卡片、独立名称／定位／图标／价格行、完整名称提示；21–22、72–73 |
| 只有基础属性摘要，无法查完整装备数值 | 强化、换装和套装收益缺少判断依据 | 固定详情显示原始／强化／实际值；比较列出当前／预览／差值及套装得失；14–17、23–26、33、38–40，及对应英文 |
| 英雄档案无法查当前属性与装备来源 | 玩家不知道最终战力由何处构成 | 25 项基础／成长／装备／总值来源表，三英雄与战斗档案共用；08–10、17、32、40，及对应英文 |
| 放弃与保存退出操作宽度不一致 | 确认弹窗缺少稳定的视觉重心 | 两按钮统一 324×52、间距16、同基线；35–36、86–87；同一布局规则扩展到新建、出售、撤离与错误重试 |
| 英文按钮末尾文字贴边或截断 | Return to camp、Branches、Quit game 等不完整 | 在原生文字重排之前适配字号，额外保留安全留白；52、59、62及全局按钮文案检查 |
| 英文英雄名与等级、职业挤在同一行 | 预览区换行与主操作争位 | 身份信息分行，左侧预览说明简化；59–61、83–84 |
| 遗物长列表／长选择说明撑大弹窗 | 底部返回与跳过可超出窗口 | 固定 826×660 列表弹窗与 1048×660 选择弹窗，正文滚动、操作固定；27、34、41–42、78、85、92–93 |
| 英文营地金币标题与数值拥挤 | 数值区域不稳定 | 金币标签与金额分为两行；04、55 |
| 英文服务房名称、被动名与任务仍为中文 | 混合语言破坏信息一致性 | 房间读取英文服务定义，被动使用英雄英文定义，整备／补给／继续／撤离目标补译；79–80 |
| 空遗物提示硬编码 E | 和实际交互绑定不一致 | 读取当前交互键；34、85 |

编号按完整图册：中文 01–51，英文对应编号加 51。滚动区域边缘出现的下一行局部是正常滚动裁切；网格长名称使用省略号并提供详情与悬浮说明，不将其称为正文丢失。
