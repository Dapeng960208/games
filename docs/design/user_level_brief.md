地图点位人工固定，不随机生成陈设；前四地图每族六战斗房和一首领场地，共 28 张设计图。剔除内场大方块和高墙，外围按种族建筑、生态自然延伸。地板、人物和道具尺度符合参考图；功能目标、装饰和奖励不能混用重复造型，按用途成组摆放。
