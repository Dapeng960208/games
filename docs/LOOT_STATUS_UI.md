# 战利品与战斗状态 UI

2026-10-01，代码直接在 main 分支开发。

房间奖励完成后显示装备插画卡，包含槽位、种族、真实强化等级、含强化的基础加成以及专属条件词条。玩家可以对比并拾取、收进行囊，或稍后整理；场景中的战利品插画与椭圆光晕标记使用真实未处理掉落记录，靠近后按当前绑定的交互键重新打开。

拾取沿用原有 `field_decision` 事务：收进行囊保存 keep，穿戴保存 equip。物品仍需成功撤离才永久入库。原有保存失败、重试、检查点过期和状态恢复路径保留。UI 不创建第二套奖励发放接口，也不虚构白绿紫金随机品质。

背包和战地对比将词条区分为基础加成、护盾/恢复/机动/状态联动/战斗触发；完整触发条件可滚动查看。触发收益与固定属性分开展示，套装激活与失去提示保留。对比窗口扩大为 980×620，并按实际窗口比例缩放。

HUD 增加技能与装备护盾、装备限时加成徽章，以及持续时间环；护盾详情显示各来源的实际数值和独立剩余时间，多来源取最大值。减伤显示实际百分比，灼烧/腐蚀/流血显示减免前每秒基础伤害。预备护盾继续保持首次承伤才计时的规则；状态和装备加成到期后徽章移除。

验证：`loot_status_ui` 图形模式 32 项检查、`field_equipment_ui` 图形模式 265 项检查均通过。覆盖实际奖励事务、世界交互、拾取和装备回调、独立护盾到期、中英文长词条、保存失败与重试、1280×720 和 960×540 布局。此前 `backpack` 27 项检查通过。实际截图保存在 `artifacts/loot_status_discovery.png`、`loot_status_comparison.png`、`loot_status_comparison_compact.png` 和 `loot_status_shield_sources.png`。
