# 界面系统

> 状态：当前菜单、营地、职业、装备/工坊、图鉴、路线、HUD、保存和错误处理页面已接入；完整设备与自然游玩体验待验证。

使用羊皮纸、黄铜、深紫文字、职业/技能独立图标及用途按钮。标题、导航、内容分行；确认窗口两侧同宽、同高、同基线。数值和资格从当前实例及解析器读取，不由界面复制公式或发放奖励。

页面在 `scripts/presentation/screens`，共用组件在 `components`，HUD 在 `hud`，装备页面在 `equipment`；主界面的营地、远征、档案和设置入口已拆为 `scripts/presentation/app/services`。

[界面设计图](mockups.md)和 references 只作视觉参考，不代表当前所有页面截图。角色与首领的清晰度来源登记在相应职业／关卡资源；验收必须说明分辨率和渲染环境。当前保存页面行为可用 `save_recycle_ui` 定向检查。
