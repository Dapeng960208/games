# 三职业真实技能与普通怪交互复查

更新：2026-10-03。范围为 `codex/three-role-skill-ui-refactor` 独立分支。本文区分实际游戏观察、直接模块检查和未通过的美术项目，不把设计规则当作已验收体验。

## 方法与可复现入口

使用现有 `tools/test.ps1` 的隔离存档和真实 Main 场景，从新版营地技能页应用四槽后出征。自动操作通过生产普攻、移动、闪避、装填、技能请求及实际 UI 按钮进入现有流程；战斗以原生 60Hz 推进，不直接写生命、伤害、资源、冷却、敌人位置或清场状态。

- `role_natural_ui`：三职业各三套四技能，覆盖 36 个身份；另让角色自然承受野怪伤害完成死亡流程。
- `role_natural_ui_chapter`：每职业开局四技能，走真实奖励选择、章节路线、BO01 首领、撤离弹窗及检查点重启恢复。
- `role_natural_ui_effects`：对控制、反击和部署物补查。释放后延迟读取真实状态，避免在伤害信号早于附加效果应用时误判。
- `role_kits`、`skill_config_migration`、`skill_system_ui_flow`：职业边界、身份冷却、支付／取消、有限效果、旧档与失败恢复、页面／服务出征锁定。

## 已修正的操作与反馈问题

| 问题 | 处理后的行为 | 职业意义 |
|---|---|---|
| 战士 0.12 秒普攻起手后，释放阶段改用实时鼠标方向 | 提交时冻结方向，准备姿态、挥斧锥和实际接触保持一致；目标移出范围仍可自然落空 | 重斧有明确承诺感，鼠标转向不让已经起手的伤害锥跳到另一侧 |
| 普攻统一叠加大推力，枪手连射和星弹把怪物持续推远 | 删除结算前通用推力；真实战士确认命中位移、技能自身推拉和首领抗位移继续使用已有规则 | 战士靠贴身压制，枪手靠走位与弹匣，法师靠范围控制，各自保持操作节奏 |
| 一次接触的攻击者与受击者定帧长度不同 | 在真实接触入口只计算一次视觉停顿并共享；轻接触不会覆盖较重停顿 | 命中有重量，AI、移动、预警和游戏时钟继续更新 |
| 枪手装填阶段主要只有进度条反馈 | 自动空弹匣与手动入口共享四种真实事件，分别提示开始、普通完成、精准成功、精准失败；失败判定只发一次 | 玩家能听见／看见换弹节拍，装填中继续移动和施放主动技能 |
| 法师共鸣、巡游、跃步 kind 沿用旧映射 | 接上 `resonance/moving_pulses/blink_burst`；周身波在实际脚点，跃步寒冷圈在原点，终点只发到达光 | 联合施法、领域展开和位移留下控制区有不同语义 |
| 职业说明混用 authored 和 V2 资源单位 | 从真实规则与资源获取倍率生成中英文说明；保留实际弹数、层数、秒数和百分比 | 技能页、HUD 和遗物不会把 100 怒气写成 10，或把 100 法力退款写成 10 |

三职业继续沿批准机制工作：战士持续进攻积怒并进入狂暴；枪手移动射击、翻滚补弹与精准装填；法师依靠唯一团团及三层星辉协奏。没有为职业差异统一增加普攻迟滞，也没有改变本轮批准的伤害预算。

## 未通过及尚未覆盖

**CH03 战斗角色美术身份失败。** 路由确实取得 CH03，但 `assets/characters/mage/animations/actions_front.json` 和八方向来源明确记录有胡须的男性工程师，实际图像一致。女性露弥的新立绘与东南普攻样板尚不足以替换完整战斗家族。新 `combat_clips.json` 保持关闭，没有用单方向镜像、静态立绘旋转或隐藏身体掩盖缺口。完整动作与角色身份修复完成前，不能宣布新法师美术接入完成。

**原生 2K 美术要求尚未达到。** 动作源实际 1254×1254，立绘为 1254×1254 或 1024×1536。逐帧分离、透明边缘整理及脚点审核保留原生像素，没有上采样后重新标成 2K；法师 B 来源站立人体约 407 像素，也低于 448 像素主体门槛。详见 [本地动作整理记录](../../characters/shared/role_art_processing.md)。

UI 已使用原生 2560×1440 渲染窗口检查，但当前物理屏幕为 1920×1080；自然自动操作改用实际可完整显示的 1280×720 窗口。不能据此声称在用户的物理 2K 屏幕完成了人工试玩。更多章节、难度、构筑、长时间舒适度、真实音响输出与人工主观手感仍需要单独验收。
