## 方法与可复现入口

使用现有 `tools/test.ps1` 的隔离存档和真实 Main 场景，从新版营地技能页应用四槽后出征。自动操作通过生产普攻、移动、闪避、装填、技能请求及实际 UI 按钮进入现有流程；战斗以原生 60Hz 推进，不直接写生命、伤害、资源、冷却、敌人位置或清场状态。

- `role_natural_ui`：三职业各三套四技能，覆盖 36 个身份；另让角色自然承受野怪伤害完成死亡流程。
- `role_natural_ui_chapter`：每职业开局四技能，走真实奖励选择、章节路线、BO01 首领、撤离弹窗及检查点重启恢复。
- `role_natural_ui_effects`：对控制、反击和部署物补查。释放后延迟读取真实状态，避免在伤害信号早于附加效果应用时误判。
- `role_kits`、`skill_config_migration`、`skill_system_ui_flow`：职业边界、身份冷却、支付／取消、有限效果、旧档与失败恢复、页面／服务出征锁定。

连续操作的首轮 `20261003T082855269-69ba9222` 为 192 项／26 失败，退出 1。测试误把闪避映射为不存在的 `skill_dash`；弹体进入树的信号早于技能身份配置，即时读取身份得到空值；法师总生命预测又混入了现有连段及派生感电。随后修正实际键位、延后只读弹体身份，并按 `skill_id/cast_id/proc_depth=0` 读取四次真实命中收据与冻结快照，保留支付、先后顺序、超时及取消反向断言；未通过修改生产数值消除测试失败。

本轮完整矩阵的战士三套配置均合法撤离，基础四技能经过 BO01 清场；枪手基础配置在 BO01 战斗中死亡，第二套合法撤离、第三套死亡；法师基础配置 BO01 清场后撤离，另外两套已取得全部配置技能效果，但 120 秒内未完成路线，准确记录为 `bounded_inconclusive` 并显式放弃清理。额外的三职业死亡观察均由原生敌人伤害产生。此前章节补验中枪手击败 BO01 的结果仍有效，不能据本轮一个自动策略的死亡样本判定职业强弱。

原始节奏样本包含实际移动、输入接续、队列、离墙约 35 像素检测及 180 像素内至少三只怪的近身密集样本。本轮自然队列最大实际观测为两项；三项容量和第三输入长招等待由上述定向回归证明。`moving_skill_frames` 精确表示“导航活跃、施法中且实际移动”，可能含技能自己的位移；不能全部算成普通边走边施法。自动行为、帧数与路线时间不替代人工舒适度判断，也不能用作职业速度排名。

**CH03 旧身份缺陷已修复。** 首轮实际复查曾选中有胡须的男性工程师，历史失败保留。随后三职业完整八方向共享家族同时启用，`20261003T114729560-1ea7dff7` 的 596 项真实 Main 检查确认露弥使用成年暗黑女性法师新 PNG，唯一团团仍由中央普攻驱动。该结果证明新身份接入；`combat_clips.json` 的十二技能独立连续动画仍未完成。
