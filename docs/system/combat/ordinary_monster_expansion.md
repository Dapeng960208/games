# 前四关普通怪扩充与难度技能登记

> 状态：当前参考：具体已实现范围以开发进度和运行代码为准。

更新：2026-10-03。当前登记：B01/B02/B03/B04分别9/12/15/18种，共54种普通怪，另有4位首领。旧M01–M36身份保持；新增M37–M39属B02、M40–M45属B03、M46–M54属B04。

身份与难度技能矩阵用于当前登记；图鉴与战斗从 EnemyAbilityCatalog 读取实际招式。旧数值包、导出哈希及旧批次结果已移除，自然平衡待验证。

## 等级、难度和数量的边界

- 新规则的区域等级仍为每章5级阶梯：三战区为5×(章−1)+1/3/5；难度不抬高等级
- mechanic_tier仍由1/5/10/15级划分并用于既有技能伤害倍率；难度技能另用difficulty_mechanics，不能混算
- D0只有本体技能；D1/D2/D3/D4依次累计解锁1/2/3/4个额外机制。每轮最多从已解锁池轮换1段，不同时追加4段；M36为单次爆破例外，各难度在唯一爆破前施放该档最新解锁的准备招，旧准备招被替换而非连放，爆破后停机
- 物种数不等于同屏数量；仍每区6、整房18并发，有限增援、3秒间隔、低压力才补员，出生至少0.8秒保护
- M42/M45/M51计入保护型配额，M43/M48计入功能支援配额；原配额保持每战区各至多1个，非无限支援叠加

## 当前运行来源

招式、参数与反制读取 `scripts/domain/combat/enemy_ability_catalog.gd`、`scripts/gameplay/monsters/enemy_brain.gd` 和 `scripts/gameplay/monsters/enemy_skill_runtime.gd`；属性与技能包读取当前配置及 `enemy_numbers.gd`。首领使用独立脑与技能目录。关卡专属入口在 `scripts/levels/<chapter>`。

当前属性入口见 [普通怪数值](../balance/ordinary_monster_numbers.md)，预警公式见 [时序规范](../balance/enemy_warning_timing.md)，身体注册见 [普通怪表现](enemy_variants.md)。各关普通怪与首领文档分开维护；未实现关卡只保留明确标注的设计。

如需当前机器可读诊断，可通过隔离档运行 `tools/balance/export_progressive_monsters.gd`，显式指定忽略目录内的输出；输出绑定本次源码，不能作为固定数值来源或自然平衡通过证明。
