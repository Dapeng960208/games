# 当前数值规则与后续边界

> 状态：八槽实例与新整数规则已接入；六章已正式接入，自然平衡持续验证。

## 1. 运行范围与来源

`data/rules/numerical.json` 是唯一运行参数源。正式入口为六章／Lv30；B05/Lv25、B06/Lv30 通过正常首领通关撤离顺序解锁。B07–B12 的最终 Lv60 范围是未实现目标，不提前写入默认闸门。

## 2. 属性与结算

攻击、法强、生命、双抗、穿透、平值伤害/护盾/治疗/职业资源在当前整数尺度计算。百分比、时间、速度、距离、货币、材料和层数不随该尺度放大；完整表达式和明确结算边界取整，不在中间乘积逐次截断。实际公式由 `scripts/domain/combat` 与 `scripts/domain/equipment` 提供。

角色基础、装备主属性、随机词条、强化、天赋、套装与临时增益分别聚合。暴击、命中、派生预算与反递归以冻结的本次战斗协议为准，不能由界面复制数值后独立结算。

## 3. 装备与成长

正式目录 124 模板／14 套、八槽独立实例；白绿紫金、词条、购买/打造和工坊操作已接入。参见 [装备入口](../equipment/README.md)、[工坊规则](random_forging_design.md)和[职业资格](../equipment/class_policy.md)。

死亡保留已有等级、已结算经验和永久装备；扣本局 50% 金币，临时装备与未结算经验按结果清除。成长/奖励/入库与主动冒险清除在一次文档事务中提交。

## 4. 普通怪与首领

前四关普通怪 9／12／15／18 种，敌人等级由章节/房间与实际遭遇决定，不按玩家等级或装备追平。普通、精英与首领使用各自定位/成长/难度规则。普通怪数值、实际技能和短预警见 [数值册](ordinary_monster_numbers.md)、[技能册](../combat/ordinary_monster_expansion.md)、[时序册](enemy_warning_timing.md)。

默认校准 14 保持；15 的基础倍率、坦克双防/生命、法强和暴击属于明确隔离候选。当前真实档案与伤害/行为、连续整关、自然获取验收分别验证，某个候选或单个种子通过不表示全量通过。
