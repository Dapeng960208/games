# 首领难度与标准构筑验证协议

更新：2026-10-03。**状态：规则和验证入口已接入；自然强度目标待验证。**

正式范围为 B01–B04、Lv20；B05/Lv25 与 B06/Lv30 仅为隔离候选。首领配置、阶段、有限召唤、机关反制与实际技能包由当前解析器和游戏节点执行，不复制旧基础表或旧战时结果判定通过。

## 输入与构筑

每组声明职业、合法等级/天赋/分支、八槽实例、物品等级、品质、词条、强化、难度、种子及冻结校准版本。默认版本14，版本15仅为显式候选。构筑必须通过当前实例、职业资格与技能解锁校验；失效固定配装应停止并修正协议，不能放宽生产规则。

| 样本 | 验证用途 |
|---|---|
| 合理金+2标准构筑 | 三职业共享首领参数下的输出、生存与机制体验 |
| 合法紫+5对照 | 主属性等效及词条/套装差异 |
| 金+0、混装、绿/白、较低随机分位 | 强化收益、自然获取与压力边界 |
| 连续裸装 | 装备依赖负向样本；和标准构筑分开 |

B05/B06 标准构筑60–90秒是待验证目标。其他章节的自然目标需按当前职业循环和合法构筑冻结。各组完整记录，单职业或单种子不能判定全章通过。

## 操作与测量

通过真实移动、技能、普攻、闪避和交互处理首领与反制目标。保留阶段、免疫、召唤、盾与治疗；不得关闭机制、改生命/伤害、挑胜局或给取消技能补计理论输出。品质对照共享种子和操作策略。

分别记录游戏活动秒与主机墙钟、终局、生命剩余、有效命中、实际HP损失、盾吸收、有效治疗、资源断档、施法/取消及阶段驻留。盾与治疗不可重复减账；所需反制目标耐久与首领耐久单列。暂停、观察上限、导航阻塞和脚本失败均明确标记。

当前普通怪/首领参数按难度、章节与冻结版本解析；实战时长受机制和输出影响，不由面板单调性推断。自然整关、受控首领与实际图形/人工操作是分别报告的范围。候选关协议见 [B05](../../levels/b05/balance/README.md)、[B06](../../levels/b06/balance/README.md)，共用规则见 [数值总则](level_equipment_numerical_design.md)。
