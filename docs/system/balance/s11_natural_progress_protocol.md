# S11 自动真实路线进程采样协议

> 状态：当前参考：具体已实现范围以开发进度和运行代码为准。

状态：采样入口存在，当前自然路线与长期经济目标待验证。本协议使用真正房间、敌人AI、机关、成长、掉落、锻造与保存事务；它是自动操作的自然获取流程，不是人类学习/操作时间调查。不得把加速后的主机耗时或模拟时长直接称作玩家获得配装所需时间。

## 隔离与可重现输入

- 三职业各从原生新档开始，零金币/素材、合法入门装备；不注入经验、装备、金币、素材、首领通关或保底计数。
- 使用独立固定源码工作树、官方Godot4.7.2、各自XDG与明确test_存档。记录源文件SHA、提交、配置与控制器版本、每次路线种子及随机战利品种子/运行ID。路线种子固定为20000加出发序号，不检查未来掉落、不挑种子。
- 原生60Hz物理、time_scale=1；`--fixed-fps 60`仅用于加速批量样本，分别记录simulation_seconds与wall_seconds。普通实时图形交叉验证另列。
- 控制器只提交实际移动、普攻、技能、闪避和交互请求。近战/远程范围、指针更新、技能完整释放、资源/冷却、可见预警和机关均由实际游戏执行。SubViewport提供可靠虚拟鼠标；测试不直接写HP、伤害、资源、状态、无敌或敌人AI。

## 当前采样决策（natural-route-v2）

1. 遵守已解锁章节及等级门槛；一次首领成功撤离后提高一档全局难度，死亡降低一档；进入新解锁章节时携带该全局档位，不声称已在同章节逐档通过。未通关首领的提前撤离不提高难度。
2. 正常持续普攻与E→R→W→Q优先，危险预警/首领反制优先；普通房先处理实际活敌，再操作可见必需机关、探索导航目标。只在游戏判定目标与战斗完成后前往下个节点。
3. 遗物从当前真实候选中选择首个未满阶且有容量的选项；HP低于40%时可选择原生跳过治疗。供应点用实际金币购买一次大治疗（HP低于65%且付得起），并使用已有免费法力/能量整备。没有额外药品或战前叠层。
4. 清房后用真实背包/收据接口比较、穿戴更合适的掉落；不补HP、资源或清除CD。营地合法分配天赋、选择已解锁分支、更新穿戴。比较分数是明确固定的常驻输出/生存估计，不读取未来掉落或敌人内部决策。
5. 保留入门物品；仅拆解已落后至少四级、未穿戴的白/绿备用品。只用实际已有资产补空槽、改善到合法白/绿+3、紫+5、金+2；已有更高免费强化不降级，换装时在付得起且等级门槛允许时通过实际继承转移旧阶数；不免费升阶、不重抽、不伪造历史付款。
6. 满级后按章节标尺的最终合理模板目标打造缺少的金装；只在相应模板已解锁、金币和材料足够时提交。金装定向配置优先保持目标套装，避免只按单件面板拆散构筑。愿望槽偏向仍在用入门武器、空槽或较弱/缺失的目标部位；根据缺件种族选择已解锁采集区。
7. 营地决策固定计8模拟秒，明确是采样假设，不用任意等待把进程人为拉长至6–10小时。每次实际成功、失败、报价不满足/资产不足、保存拒绝、控制器停滞与观察上限分别保留。

## 输出与验收边界

`tools/balance/run_s11_natural.py`对固定工程运行三份独立样本。输出保存在仓库外，包括清房/升级/换装/购买/打造/强化/拆解/遗物/撤离/死亡事件、金币素材余额、配装、实际统计、源码清单及引擎日志。进程被杀或脚本失败不是战斗失败，也不是通过；保留原样并使用同一固定源码另建样本重试。

本协议不复用旧源码的短样本结果；仍待验证D0–D4所有房间已平衡，或人类玩家6–10小时目标成立。主方案6–10小时的成型条件为20级/19天赋点、6件核心套+2件补强、紫为主且关键金件、主力+5，并能重复成功D3；逐次营地记录这些组成条件，八金+2另列而不替代该目标。长期结果需与受控普通/精英/Boss样本、实时图形验证和人工操作记录分别报告；失败与未覆盖项不删除。

## 引擎依据

Godot官方[命令行说明](https://docs.godotengine.org/en/stable/tutorials/editor/command_line_tutorial.html)明示`--fixed-fps`关闭实时同步，因此批量结果只能标为模拟经过时间；实时检查使用`--max-fps 60`并独立记录主机墙钟。[Engine参考](https://docs.godotengine.org/en/stable/classes/class_engine.html)说明物理步率默认60Hz，time_scale会影响delta模拟，故不通过提高time_scale加速战斗。[Viewport参考](https://docs.godotengine.org/en/stable/classes/class_viewport.html)提供局部输入注入与坐标接口；测试按实际viewport变换提交鼠标事件，并通过真实技能释放方向和命中记录核验。
