# S11 受控实战矩阵协议

更新：2026-10-03。**状态：采样入口存在；合法构筑、当前控制器和自然强度均待验证。** 本次目录整理不启动全量 S11 采样，不保留旧源码批次的胜率或战时结果。

固定工程、职业、合法等级/天赋/分支、八槽实例、难度、种子和校准版本。已有 `tests/support/s11_battle_fixtures.gd` 属于验证输入；每次采样前必须通过当前实例、职业资格和技能解锁校验，不能仅依据旧文档称其合法。无效输入停止该组，不静默换成有利配装。

`tests/balance/test_s11_battle_matrix.tscn` 和候选关的 balance_matrix 使用生产房间、角色、首领、状态、装备、机关及保存链路。驱动器只提交真实操作；冻结策略对所有品质对照一致，保留真实未命中、取消、死亡与导航问题，不补写伤害或终局。

每组独立记录有效命中、HP/盾损失、治疗、资源断档、阶段与施法、终局和时间。模拟活动秒与主机墙钟分别报告；有限受控操作不能视为人类反应、全部设备或长期装备获取的证据。
