# 装备与角色属性界面重构

更新日期：2026-10-01。保留当前 96 件固定模板、14 套、六槽和已有持久事务；本轮重构查看、查找、比较和配装流程，不以界面暗示尚未实现的随机品质或独立实例。

## 参考与信息结构

参考[《激战2》装备面板](https://wiki.guildwars2.com/wiki/Equipment)的物品筛选、角色配装和动态属性区域，以及[《暗黑破坏神 IV》官方界面改进说明](https://news.blizzard.com/en-gb/article/24092663/diablo-iv-patch-notes-1-0-1-2)的库存搜索／筛选和稳定词条排列。落实为装备网格、固定详情栏、按用途分组的数值表和可查看来源的角色属性。保留明亮青年向手绘奇幻、羊皮纸、黄铜与青蓝交互，不复制其他游戏的美术。

## 已接入：角色属性与统一数据

`equipment_inspection.gd` 是只读展示数据层，装备强化数值、套装穿戴预览及三职业属性都取 `StatResolver`。单件强化按实际逐件取整；装备移动速度显示比例，角色移动速度显示结算值；百分比变化以百分点区分。查看不购买、不换装、不写入档案。

`stat_sheet.gd` 提供 25 项完整属性，分进攻、生存、机动与资源，分别展示角色一级基础、等级成长、装备带来的实际变化和当前总值。普攻间隔与护甲／魔抗减伤的装备列是公式结算后的变化；超上限装备注明原始贡献和采用值。词条、已穿戴套装 2／4／6 档以及职业被动在下方完整列出，条件触发效果不折算成常驻攻击力。

营地英雄档案直接显示这张属性表，可预览任一英雄的自身等级和共享配装；预览不改变出战英雄。在装备背包、商城和强化页增加「角色属性」按钮，打开同一张完整来源表。

## 商城、仓库与远征背包

营地装备页改为三栏：左侧六槽配装，中间四列装备网格，右侧固定详情。背包默认显示全部已拥有装备，单件商城显示全部 96 个模板；职业适配是可选开关。支持名称／词条／套装搜索、槽位／套装筛选、槽位／名称／价格／强化排序及清除筛选。输入后保留搜索焦点，切换详情页签保留选择和滚动位置。

单件详情有「完整属性」「数值对比」「套装效果」三个页签。完整属性显示属性名、原始值、强化增量、实际值；比较显示当前值、预览值、差值及将获得／失去的套装档位，不再只给一句基础属性摘要。未穿戴装备的强化比较使用该装备穿戴后的相邻强化等级，避免把换装收益算作强化收益。长网格名称采用省略号，完整名称和数值可在固定详情及悬浮说明查看。

套装商城保留 14 套，新六套置顶；两列卡片分别显示名称、定位、六件图、拥有数和价格。详情可点开任一件的完整属性，查看 2／4／6 件效果，或者比较整套穿戴后的真实角色数值。购买与补齐仍走缺件九折事务，购买不自动换装，一键穿戴保留已有强化。

远征背包采用配装／三列背包网格／详情结构，并可切换完整角色属性来源表。战斗角色档案共用 25 项来源表，点击任一穿戴插槽可查看完整装备数值。裤子与戒指明确显示为未开放预留槽；实际后端仍为六槽。远征换装保持已有生命、资源、冷却、被动和结算规则。

回收页面保留多选、全选未穿戴装备、逐件价格、总价预览和确认出售；已穿戴装备受保护，出售和加金币仍一次保存。取消不删除装备。

## 标题、导航与按钮

工坊标题、金币与返回放在独立页头，导航与当前页功能放在第二行；五个导航采用固定宽度的短标签，选中态为深青绿色。角色属性、套装／单件切换和多选回收拥有稳定功能区，不挤占标题。

全局按钮启用 `workshop_buttons_v5` 六类插画构件：蓝色符文主操作、米白手册次操作、青绿叶革页签、罗盘返回、珊瑚红危险操作、安静的装备卡片。默认、悬浮、按下、焦点与禁用态保留 Godot 原生输入语义。按不同构件预留文字安全边距，长文案在固定宽度内适配。

成对确认操作统一由 `MineStyle.action_pair` 布局：左右边距各 28、按钮间距 16、同宽同高同基线。放弃远征与保存退出的两按钮均为 324×52；新建档案、撤离、装备出售和远征错误窗口使用同一规则，具体宽度随对应弹窗宽度计算。遗物列表与长选择说明使用固定范围滚动区，避免弹窗被内容撑出屏幕。
