# 已知问题与验证边界

记录日期：2026-09-28。本表将“已复现缺陷”“待验证”与“范围外功能”分开；不能把未运行写成无问题。

## 当前验证边界

| 项目 | 当前状态 | 影响／处理方式 |
|---|---|---|
| 引擎与主场景运行 | `4.7.2.stable.official.ed1daf0bf` 已导入，headless 与 Windows 图形运行通过 | 使用 README 中记录的确切引擎；未承诺其他版本兼容性 |
| 两结局、遗物、永久保存、暂停焦点 | 已由真实引擎自动检查及实际截图验证；详细范围见 TEST_PLAN | 自动驱动不是真人手感验收；未把未覆盖边界当作通过 |
| 三目标分辨率与中英长文本 | 已看营地 1280／1920／2560 及 1280 中英；未穷举所有页面×语言×尺寸 | 实际窗口保持比例，交互区未发现阻断裁切；全组合仍需后续检查 |
| Windows 可执行包 | 待确认导出能力并实际启动 | 未完成时使用实际验证过的 Godot 工程运行方式 |
| 战斗节奏与长期趣味性 | 未经外部试玩验证 | 本测试房验证机制闭环，不承诺 15—25 分钟体验或市场表现 |

已修复并回归的缺陷包括：死亡结算写失败无重试入口、UI 在 autoload 失败事件后才订阅、模态键盘焦点泄漏到背景、设置写失败静默、临时新档写失败无法同进程重试，以及撤离交互暂停后同帧继续拾取。当前未保留已知阻断闭环的缺陷。

## 已观察的非阻断问题

| 问题 | 复现／影响 | 绕过与后续处理 |
|---|---|---|
| 营地英文规则背景略杂 | 1280×720 英文营地右下规则与升降机装饰轨道重叠，文字仍可读 | 规则也可在撤离确认中读取；后续为规则加淡底或微调位置 |

## 有意保留的 M1 限制

| 限制 | 触发方式与影响 | 当前用法／后续阶段 |
|---|---|---|
| 无远征中途恢复 | 离开或强制终止远征不能回到原战斗位置 | 常规退出须确认并按死亡规则结算；强制终止活动标记用于一次放弃兜底；M3 才做房间入口快照 |
| 固定单房、固定遗物与持续增援 | 每局测试布置相同，内容量小 | 用于重复观察三件遗物；M2 扩展有限模板地图 |
| 无局内等级、脉冲、随机遗物候选 | 没有升级三选一或替换流程 | UI 仅显示已实现动作与拾取；M2 实现后新增对应验收 |
| 营地无永久购买 | 永久废金当前作为结算记录保存 | 不展示假购买入口；M3 加入勘测台与遗物匣 |
| 无手柄适配承诺 | 不保证摇杆、扳机和手柄菜单提示完整 | M1 使用键鼠；M3 适配并实测 |
| 无地图、小地图和迷雾 | 右上没有小地图 | 单房无需地图 UI；后续房间连接后加入 |
| 原创占位美术与简化演出 | 视觉用于辨识机制，非最终资产质量 | 保留统一矿井风格，按 ASSET_LICENSES 标注替换点 |
| 无音效／音乐 | 战斗反馈目前主要是图形、动画和伤害数字 | 不展示假音量按钮；M3 增加并记录素材许可 |
| 无独立 UI 缩放滑杆 | 当前仅随窗口按整体比例缩放 | 选择合适窗口尺寸；后续完整设置阶段再实现独立缩放 |
| 未测试真人操作舒适度／硬断电 | 自动流程不能替代实际玩家，也不能覆盖全部文件系统崩溃时序 | 当前已有 tmp／备份／跨进程恢复与模拟写失败测试；后续补真人与故障测试 |
| 未验证性能目标 | 不提供“低配稳定 60 FPS”结论 | M4 用记录配置的机器和固定密度采样 |
