# 深渊拾荒者：M0—M1 游戏设计

范围依据：[原始范围基线](SCOPE_BASELINE.md)。本文件描述本次最小闭环的设计约定；实际验证情况以 [TEST_PLAN.md](TEST_PLAN.md) 为准。文中数值为原型测试值，不是平衡结论。

## 本次终点与必要假设

- 单人、离线、Windows 优先，原生 Godot 4.x / GDScript / 2D。
- 正式项目目录为 `D:\dev\zgame\abyss-delver`。已有 Phaser 工程保留且不修改；本次原生 Godot 工程置于其 `godot/` 子目录。`D:\dev\test-game` 仅作本次开发暂存目录，不是最终运行入口。
- 一个拾荒者、一把火花弹武器、一间固定测试房、一种近战敌人、一个撤离点。
- 三件遗物固定放在房内，以可观察的拾取顺序验证攻击差异。M1 不引入随机候选、初始三选一、升级、槽位替换或跳过奖励。
- 废金分为本局携带量和营地永久量。营地只承担档案展示、出发与返回，不提前放置永久解锁购买按钮。
- 使用 imagegen 按主题原创的人物、锈壳寄生体、三件遗物、矿井主视觉和地板，配合程序绘制的瞄准、弹体、预警与矿轨；素材来源及完整提示词见 [ASSET_LICENSES.md](ASSET_LICENSES.md)。

## 玩家流程

```text
主菜单 → 新建／继续档案 → 营地 → 开始远征
                                 ↓
                  移动、瞄准、火花弹、冲刺
                                 ↓
                   击败敌人 → 拾取废金和遗物
                                 ↓
             撤离点确认撤离 ／ 生命归零 ／ 确认放弃
                                 ↓
                 一次性持久化结算 → 结算明细
                                 ↓
                      返回营地 → 再次出发
```

新远征恢复起始生命和起始武器，携带废金从 0 开始，遗物为空。先前结算的营地废金和永久发现仍保留。主菜单继续只进入已有营地，不恢复战斗中途状态。

## 战斗与反馈

| 动作 | M1 行为 | 可读反馈 |
|---|---|---|
| 移动 | WASD，斜向移动不额外加速 | 角色轮廓、朝向与地面位置清楚 |
| 瞄准 | 鼠标位置决定射击方向 | 武器／提灯朝向跟随鼠标 |
| 普攻 | 按住鼠标左键连续发射火花弹 | 发射轨迹、命中反馈、敌人生命变化 |
| 冲刺 | 空格，有集中配置的持续时间、冷却和短暂无敌 | 运动变化及实际冷却提示 |
| 交互 | E，在有效范围内拾取遗物或使用撤离点 | 仅靠近有效目标时显示提示 |

敌人有接近、攻击预警、攻击、受伤、死亡流程。近战预警给玩家躲避机会；角色受伤后的保护时间避免多个重叠敌人同帧造成无法理解的伤害。以下初始测试值集中在 [`config/balance.gd`](../config/balance.gd)，UI 不另外维护副本。

| 参数 | 当前测试值 |
|---|---:|
| 角色生命／移速 | 100 / 240 逻辑像素每秒 |
| 普攻伤害／间隔 | 20 / 0.25 秒 |
| 主弹速度／寿命 | 650 逻辑像素每秒 / 1.6 秒 |
| 冲刺速度／持续／冷却 | 690 逻辑像素每秒 / 0.16 秒 / 1.15 秒 |
| 受伤保护 | 0.65 秒 |
| 敌人生命／移速 | 60 / 96 逻辑像素每秒 |
| 敌人伤害／预警／恢复 | 14 / 0.65 秒 / 0.9 秒 |
| 每敌人废金 | 17 |
| 子弹／电弧伤害 | 8 / 7 |
| 敌人／弹体上限 | 18 / 100 |
| 单次武器命中触发预算 | 4 |

暂停与其他阻断战斗的面板打开后，敌人、弹体、持续伤害、冷却和玩家运动均停止。恢复后等待相关输入释放，避免点击菜单或确认弹窗的输入立即变成射击、冲刺或交互。

## 三件遗物

| 遗物 | 必须实际执行的效果 | 触发约束与观察方法 |
|---|---|---|
| 分裂镜片 | 主弹首次命中生成 2 枚侧向子弹，各造成基础弹伤的 40% | 子弹来源标为子投射物，不能继续分裂；观察侧向弹体与旁边敌人的生命变化 |
| 余烬灯芯 | 武器投射物命中附加燃烧，每秒 3 伤害，持续 3 秒；重复命中刷新持续时间，不叠层 | 停止射击后仍有有限次数的燃烧伤害；持续伤害不再产生武器命中触发 |
| 弧电线圈 | 每第 3 次普攻的主弹首次命中触发电弧，最多连接 2 个其他目标，各造成基础弹伤的 35% | 主弹只触发一次；电弧与子弹不继续触发电弧；观察跨目标连线与生命变化 |

拾取同名遗物不会叠加同名效果。M1 三件遗物可共存，但不引入第四件或满槽替换 UI。永久档案可以记录发现；发现记录不代表下一次远征自动装备遗物。

伤害来源至少区分原始主弹、子投射物、燃烧和电弧。附加伤害不能回流为新的原始攻击。主弹首次命中标记、同弹命中去重、触发预算和弹体数量上限共同约束效果，不依赖玩家主动避开组合。

## 房间与资源

房间使用固定布置，入口、战斗空间、三件遗物和撤离点均可到达。M1 没有房间拼接、秘密房、局部迷雾或深度选择。顶部区域文本显示实际测试房名称，不展示不存在的深度进度。

敌人死亡产生本局废金拾取物。收集后立刻更新携带量及死亡保留量，不在拾取时写入营地余额。撤离点是唯一主动撤离入口；暂停菜单的离开远征属于放弃，使用死亡规则。

## 结算与持久化

设本局携带废金为非负整数 `C`，原营地余额为 `P`：

| 结局 | 带回 | 损失 | 新营地余额 |
|---|---:|---:|---:|
| 成功撤离 | `C` | `0` | `P + C` |
| 死亡／确认放弃 | `floor(C × 0.20)` | `C - floor(C × 0.20)` | `P + floor(C × 0.20)` |

例如携带 19 废金：撤离带回 19；死亡带回 3、损失 16。起始角色和武器从不丢失，本局遗物在任意结算后清空。

每次远征有唯一标识。奖励到账、发现合并、结算记录和活动远征清除属于同一次存档提交。重复调用结算、连点返回、重开结算页或重启游戏，不能再次发放同一远征奖励。UI 只显示已计算的结算记录，不修改余额。

永久档案与局内对象分离，存档包含版本号。保存使用临时文件、替换和备份；读失败保留损坏文件并明确提示。保存失败时不能显示“已到账”并允许依靠重试重复领取。

M1 不恢复远征中途进度。常规离开必须先提示按死亡规则结算；强制终止时留下的活动标记仅用于下一次启动执行一次放弃兜底。它不恢复位置、敌人、弹体或局内遗物。兜底使用最近已成功持久化的携带量，规则与实际实现应在测试中确认。
