# 打造、锻造细节与原创配乐（2026-10-02）

## 本次范围

对应用户反馈「打造和锻造需要优化细节，优化ui展示方式，增加锻造和打造的配乐」。在现有米白／青绿／黄铜视觉系统上调整生产界面，不修改装备来源、品质、概率、价格、解锁等级或任何事务实现。

- 重铸结果不再被大量 `0 → 0` 属性淹没：左侧并列显示当前词条与已保存候选，分别显示真实词条数值和 u 分位；下方默认仅列实际变化。右侧明确已付款、绑定槽位、退出／重载不重抽、不重复扣款和不退款规则，并提供完整属性比较展开按钮。保留／替换操作仍提交原有冻结事务。
- 所有锻造页在完成后优先展示上次结果，再展示操作预览，其后列当前各槽词条真实数值、强化阶及规则。重铸／精炼下拉框明确槽号及 u=0–100；实例 UUID 移到提示信息保留调试身份，不占主要标题。回收确认先显示装备名，保留末八位识别；回收仍需确认。
- 打造品质选择明确绿 Lv5、紫 Lv10、金 Lv15；商店说明仅售白／绿，紫／金到打造。模板首领解锁与装备等级限制保持。材料费用标注所需／持有，非可执行状态保留原错误说明。

## 声音

`tools/compose_audio.py` 新增两首原创16小节配乐，未使用外部录音、采样或下载音乐；音符事件、固定种子、测量和PCM SHA-256登记在 `assets/music/score.json`，与原配乐相同CC0-1.0来源许可。

- 打造：巧手织光 / Hands of Light，88 BPM，43.64秒；毛毡键、木质琶音和玻璃应答
- 锻造：砧上星火 / Sparks on the Anvil，104 BPM，36.92秒；克制的低音脉冲、共鸣木槌与金属感应答

仍由唯一常驻MusicDirector管理两声部、1.25秒淡入淡出。打造、锻造路由分别请求craft、forge，离开回营地曲；重复请求幂等，不创建额外播放器。两曲都服从主音量／音乐音量及静音，不增加新音效声部。WAV为24kHz双声道16bit，无损导入；峰值0.579987、首尾样本差0，保留混音余量。
