## 1. 定位与成长

正常游戏默认接入，无需候选标志或独立档。敌人Lv26/28/30，Boss Lv30，装备iLv跟随区段、首领上沿30。章HP/攻击因子1.60/1.40。比B05增加“周期先后”：玩家不只拆节点，还要预留潮水推进时的落脚点。前章装备可开始D0，潮甲没有指定元素破盾要求。

视觉采用日照浅海、珊瑚街巷、珍珠白贝桥和海蓝玻璃水渠。鱼鳍、螺旋壳、横向蟹足承担轮廓区分；不把所有海族画成换色虫族。

## 2. 地图元素与种族特性

**固定潮汐**：每房16秒周期：退潮8秒→涨潮预告2秒→高潮6秒。入口教学房首轮延长退潮至12秒。潮线先显示方向，再改变已标识浅水区；水位不随玩家位置调整。高潮区移动-15%，不会溺死、瞬移或永久失去路线。全周期至少保留35%干地及一条宽180世界像素的主路。

**潮息甲壳**：海族在浅水中移速+12%；进入本轮高潮时获最大HP10%的潮甲盾，持续6秒、12秒内只触发一次，盾不叠加。干地不给盾；固定排水闸F交互0.6秒使其负责的一区保持干地8秒，CD16秒。三职业都能操作或直接击破护盾。

**海螺回音**：少数支援怪通过清晰声波线给予一次受击保护，不是全族反射。所有击退距离按可走区裁剪，不能把角色推出导航边界。角落至少有两个脱离方向。

## 4. Boss：行走巨蟹堡垒

BO06 固定 Lv30，实际属性与技能包由当前首领解析器计算；三职业自然实战待验证。四腿撑起珊瑚城堡，双钳分别为破城锤与喷潮炮；腹部珍珠核心是可达弱点。

P1 100–70%为干地钳击；P2 70–40%接入16秒潮周期；P3 40–0%改变左右炮口轮换，但不加第二个独立潮周期。正面甲壳减伤35%；排水后引钳击撞上固定礁柱可让其侧腹暴露5秒、承伤+15%，触发CD12秒。柱不会用完，冷却期间仍可直接输出，不等机制才能造成伤害。

## 6. 实施接口与待验边界

26–30成长/iLv、固定潮相保存、浅水状态、位移保护、18种敌人、首领、七房与35装备模板已正式接入。商店/打造凭证 v3 支持B06与Lv30，历史凭证边界保留。共有套装六件追击要求六件装备取向一致，混合取向仍保留2/4件效果。实验性平衡协议和诊断见本关 balance、enemies、bosses 文档；自然整关与首领三职业目标继续验证。

后续检查18种完整覆盖；潮相恢复不跳过预告；任何潮位可达闸与出口；怪物推移不把玩家锁到地图外；三职业前章装备可开始D0；枪手真实贯穿与法师付费施法只计一次；两共有位能提高容错但不取消潮汐玩法。难度需分别记录潮位驻留、被推次数、资源断档及TTK，不能仅据历史设计HP或当前单调性宣称比B05自然更难。
