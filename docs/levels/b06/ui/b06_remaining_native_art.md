已查看27姿态和35装备原图的完整像素联系表。怪物保留全幅region，以每物种idle可见高度作为统一参考，各姿态使用来源中的独立脚点和视觉出口；不按每姿态alpha包围框自动缩放。身体核心是表现用源像素估计。视觉出口不会替换真实技能伤害原点。M10/M11脚点是悬浮投影，M16出口为发射器口而非网边，M17环仍由地面机制绘制。
