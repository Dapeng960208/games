## 1. 等级与挑战

B08通关后开放；敌人Lv41/43/45，Boss Lv45；装备iLv随区段、首领上沿45。章HP/攻击因子1.96/1.64。前章练移动，本章练“在哪里停下”：惯性、晶面破层与裂桥时序共同增加决策压力，但不能让角色失去输入控制。

视觉为日照冰川、冰青与淡紫晶宫、香槟金反光、暖灯工坊。轮廓使用几何切面与浮动晶核，不用蓝色石头替换所有敌人，也不以全屏白闪表达寒冷。

## 2. 独特地图与种族特性

**可控冰面**：仅标识的亮冰区有惯性。角色抵达移动目标时最多额外滑行40世界像素/0.25秒；新的移动指令、闪避立即响应，不延迟输入、不改变键位。粗雪和固定摩擦垫立即结束滑行。不同职业位移技能仍按原距离/碰撞执行。

**裂桥重组**：局部桥段裂纹预告2秒后暂停通行4秒，再重组；每房至少两条路线，不能同时关闭。站在崩裂区域时按最近合法边缘回摆并承受一次0.6a环境打击，a取本区普通F档攻击，实际伤害上限为玩家最大HP8%；不掉出地图、不连续结算同一次崩裂。战斗完毕桥永久重组。

**晶面层**：指定冰晶怪有最多3层可见晶面，每层减伤8%。每次独立直接命中事件破一层；同次技能多段最多破一层。持续场每秒最多破一层，避免彻底克制法师。晶面只在8秒未受伤后重组一层，不能一边受击一边永久重生。普通攻击、技能与暖灯均可破层，不要求火系职业。

**暖灯**：F交互0.6秒使半径160内变为粗雪8秒，并去除范围敌人一层晶面，CD16秒；Boss仅去除其明确的可破晶面，不取消阶段护盾。灯位和照明常驻可见，敌人不能让HUD或整场变黑。

## 4. Boss：霜晶女王

Lv45；原始HP1400/攻击32/速度60/护甲12/魔抗12。D0设计HP37044、攻击708。女王由半透明晶裙、悬浮冰冠和可见心核构成；重要锁点在地面而非耀眼冠光。

P1 100–70%为剑弧/霜印；P2 70–35%开启两段轮流裂桥；P3 35–0%加入镜身分线。女王最多3层王庭晶面，每层减伤8%，每次独立直接伤害可破1层，持续场每秒可破1层；去完后4秒承伤+15%。重组必须1.5秒可打断引导且CD14秒，暖灯命中可替代一次打断，不能无限重组锁血。

**SM 雪冠凝晶**：2件，E直接伤害+8%。4件，E一次真实命中至少2敌人回复60法力，ICD8秒；单Boss场景改为回复30，必须实际成功扣费，派生场不计。6件，W或R成功提交后为其首段命中的最多3目标挂“凝晶”4秒；对每个目标首次Q命中追加0.25P并消耗其印，整轮ICD10秒。无需普攻，Q/W/E/R本体伤害不以印记为门槛。

**SU 暖灯踏雪**：2件，普通减速持续时间-20%，同类减免合计≤50%，不取消裂桥。4件，HP低于50%时受到直接伤害-8%，不作用自损/固定环境回摆。6件，累计承受相当于最大HP10%的真实伤害后，移除1层普通减速或持续伤害状态并获得最大HP3%盾4秒，ICD15秒；优先清最长剩余持续伤害，再清减速，不清Boss阶段标记。只有真实承伤计数，不能靠装备切换触发。
