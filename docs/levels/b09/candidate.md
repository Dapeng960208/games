# B09 七房战斗候选

B09 已提供独立的七房试玩入口，使用新生成的冰晶族资源。该入口沿用 PR #7 的候选验证方式；主线章节开放、成长等级和玩家正式存档仍按已有实现执行。

当前状态为**隔离候选／地图与 2K 受控接入验收通过**。正式入口已随 B05/B06 发布开放至六章／Lv30／194 装备，B09 不扩展正式闸门；合并后机制与地图／路径复测通过，合并后新地图 GPU 247 项通过，合并后 GPU 已通过 247 项检查。

从本工作区运行：

```powershell
.\tools\play_b09.ps1 -EnginePath "C:\webdev\games\tools\godot\Godot_v4.7.2-stable_win64_console.exe"
```

在菜单选择战士、枪手或法师，以及 D0–D4。方向键或鼠标右键移动，鼠标左键普攻，Q/W/E/R 施放职业技能，空格闪避，F 使用附近暖灯或清场后的出口。七房顺序为 L49 → L50 → L51 → L52 → L53 → L54 → BO09。死亡后返回菜单重新开始。

启动器默认使用 **2560×1440**，也可传入 `-Resolution 1920x1080`。菜单、返回按钮和装备面板按逻辑画布布局，并在窗口打开后应用目标尺寸，避免启动阶段被桌面尺寸裁剪。全局 HUD 复用已有职业头像、生命条、资源条与底部技能栏，按参考效果图适当调整；此前候选入口的大块文字 HUD 已撤下。1280×720／1920×1080／3840×2160 是可选启动尺寸，本轮受控操作检查的实际输出为 2560×1440。

入口只接受 `--candidate-b09` 和隔离的 `user://test_b09_candidate/` 存档路径。候选角色以 Lv45 裸装开始；点击“装备与战利品”可查看自然获得的装备，或领取明确标注来源的 19 件测试装备。正式入口为 B01–B06／Lv30。房间切换保留当前 HP、资源和战斗状态，试玩没有中途战斗恢复。

装备界面采用三栏：当前角色与八槽配装、可按武器／防具／饰品分类的图标行囊，以及属性／换装对比／套装效果页签。选中装备显示青色边框、品质文字和当前穿戴状态，完整数值仍由原有详情组件显示。打开行囊暂停房间战斗与机关计时，关闭或按 Esc 后恢复；换装继续保留已消耗生命、资源与冷却。槽位图标复用系统通用图，并非 B09 独立装备插画。

## 已接入内容

- 18 种普通怪和霜晶女王的独立身份、原生图集、冻结预警与主动招式；敌人按 Lv41/43/45 分段。D2/D4 追加行为与女王阶段、难度门槛分开控制。
- 每次独立直接命中破一层晶面，同次技能多段只破一次；持续伤害每秒至多破一层，受击后八秒才开始重组。暖灯可去层，女王破尽后存在输出窗口。
- 标识冰面最多产生 40 世界像素 / 0.25 秒的额外滑行；新指令和闪避立即响应，粗雪停止惯性。暖灯通过 0.6 秒交互制造粗雪，受伤或离开会中断，冷却 16 秒。
- 裂桥预告 2 秒、关闭 4 秒，单次仅关闭一段并轮流选择；站在桥上时回摆到合法地面，一次伤害不超过最大 HP 的 8%。清场后桥永久重组。
- 七套独立的原画运行几何、导航障碍和有限遭遇，L54 共三波。L51 两岸双桥、L54 三平台四桥使用真实裂隙障碍，L52 晶柱使用画面足迹；入口、出口、暖灯与遭遇点同步重定位。晶墙和折射柱可拆，造墙不能占住出口或暖灯，侍卫不掉独立奖励。
- 35 个可生成、穿戴并解析实际属性的装备模板：三职业各八件、共有八件、三个散件。职业锁、八槽、随机品质／词条、强化数值和实例固定属性取向沿用现有装备系统；共有装备可以由三职业使用同一实例，换职业不会重抽物理／法术取向。
- 碎晶重誓、霜线定轨、雪冠凝晶、暖灯踏雪的 2／4／6 件效果和三个散件已接入运行事件。装备与晶面、护盾、付费技能、普通减速、实际承伤、净化和冰面滑行联动；派生伤害不再次触发，单次施法与 ICD 有界。换装保持消耗后的生命、资源和冷却。
- 每职业自然池为职业八件＋共有八件＋散件三件。普通怪使用原有 1% 几率、每房最多两件，精英 15%／每房最多一件；侍卫与技能机关不参加掉落。清房保底一件，首领 D0–D4 为 2／2／3／3／4 件，保留品质、槽位／来源偏向和 D4 连续非金保底。
- 自然获得和测试领取的装备通过现有原子存档系统写入隔离行囊，保留实例 ID、来源、随机值和强化记录；重复清房／死亡回调不重复发奖，写入失败保留冻结结果供重试。库存跨启动保留；本次运行的配装重新选择，不写入正式库存。
- 19 张三姿态角色图集、七房 background、42 张逐片生成的原生高清 detail 与六张陈设／材质原图，提示词、来源和 SHA-256 均随资源保存。六房背景沿用本批 B09 原画字节迁移；L54 增补两组双通路并保留旧原画来源，没有复用 B05/B06 图。参见 [资源登记](art/README.md)。

地图按 B02 L07 的 `background/`＋`detail/` 结构接入。`background/environment.png` 是实际房间底图，`background/environment.json` 登记 placement 与多边形，`detail/manifest.json` 登记六片原生高清图与原画映射；七房 placement 为 `[0.10, 0.10, 0.80, 0.74]`。运行沿用前四关的 `WorldArt → Backdrop → EnvironmentChunks → WorldCamera` 管线，地图与导航使用同一变换。旧平铺白板、矩形静态冰桥和围栏阵已撤下；静态建筑、桥与地面由房间原画表现，运行机制负责状态与交互反馈。L54 的旧 `overview.png` 仅保留为新背景来源。

42 张 detail 来自逐片 `image_gen` 原生重绘，实际输出为 1244×1264 或 1254×1254；像素密度至少为对应原画裁区的 2.375 倍。以无损 WebP 保存，解码 RGB 与生成 PNG 一致，未通过离线缩放补分辨率。来源 PNG 哈希、裁区、提示词和 WebP 哈希随清单保留。底图作为回退和片间羽化基底，不等于已实现流式加载。

角色当前使用待机、蓄势、释放三个静态姿态，行走和收势复用已有姿态，尚未达到连续动作与多朝向动画的正式美术验收。明确房间待办为 L52 技能分步教学、L53 巨像后仅一次切桥、BO09 完整外缘桥通行。L53 目标是外围四块小冰岛，不要求裂隙隔离；BO09 中央粗雪环已有净空可达点，不要求额外的中间裂隙或完整外环。
