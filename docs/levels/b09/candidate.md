# B09 七房战斗候选

B09 已提供独立的七房试玩入口，使用新生成的冰晶族资源。该入口沿用 PR #7 的候选验证方式；主线章节开放、成长等级和玩家正式存档仍按已有实现执行。

从本工作区运行：

```powershell
.\tools\play_b09.ps1 -EnginePath "C:\webdev\games\tools\godot\Godot_v4.7.2-stable_win64_console.exe"
```

在菜单选择战士、枪手或法师，以及 D0–D4。方向键或鼠标右键移动，鼠标左键普攻，Q/W/E/R 施放职业技能，空格闪避，F 使用附近暖灯或清场后的出口。七房顺序为 L49 → L50 → L51 → L52 → L53 → L54 → BO09。死亡后返回菜单重新开始。

入口只接受 `--candidate-b09` 和隔离的 `user://test_b09_candidate/` 存档路径。角色使用候选运行中的 Lv45 裸装属性；不会修改正式等级上限、开放 B07/B08/B09、提交经验金币或写入自然掉落。房间切换保留当前 HP、资源和战斗状态，试玩没有中途存档恢复。

## 已接入内容

- 18 种普通怪和霜晶女王的独立身份、原生图集、冻结预警与主动招式；敌人按 Lv41/43/45 分段。D2/D4 追加行为与女王阶段、难度门槛分开控制。
- 每次独立直接命中破一层晶面，同次技能多段只破一次；持续伤害每秒至多破一层，受击后八秒才开始重组。暖灯可去层，女王破尽后存在输出窗口。
- 标识冰面最多产生 40 世界像素 / 0.25 秒的额外滑行；新指令和闪避立即响应，粗雪停止惯性。暖灯通过 0.6 秒交互制造粗雪，受伤或离开会中断，冷却 16 秒。
- 裂桥预告 2 秒、关闭 4 秒，单次仅关闭一段并轮流选择；站在桥上时回摆到合法地面，一次伤害不超过最大 HP 的 8%。清场后桥永久重组。
- 七套独立的运行几何、导航障碍和有限遭遇，L54 共三波。晶墙和折射柱可拆，造墙不能占住出口或暖灯，侍卫不掉独立奖励。
- 19 张三姿态角色图集、七张房间设计图和六张陈设／材质原图，提示词、来源和 SHA-256 均随资源保存。参见 [资源登记](art/README.md)。

房间 `overview.png` 是设计效果图，运行画面由 `room_geometry.json`、雪／冰材质、桥和暖灯等资源共同构成。角色当前使用待机、蓄势、释放三个静态姿态，行走和收势复用已有姿态，尚未达到连续动作与多朝向动画的正式美术验收。

## 正式开放前仍需完成

35 件装备当前保存名称、槽位、套装及效果契约，`runtime_enabled` 和各模板的 `runtime_implemented` 均为 `false`。套装效果、自然获取、装备保存以及正式 Lv41–45 成长尚未接入。试玩不能用于声称 B08 装备可自然进入 B09。

三职业使用裸装候选属性；仍需以真实 B08 配装逐难度记录破层耗时、滑行误差、治疗和 TTK。七房导航、机制与清场测试通过也不替代人工自然战斗、连续动画及完整成长验收。候选不会提高 `implemented_chapters`。
