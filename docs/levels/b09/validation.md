## 获取、保存与操作

自然池为本职业八件＋共有八件＋散件三件。房间／怪物偏向使用原有权重方式，普通击杀 1%、精英 15%，各房上限普通两件／精英一件；清房保底一件。首领按 D0–D4 生成 2／2／3／3／4 件，D4 连续三次非金后的保底继续使用同件数替换规则。iLv 随区段 ±1，最高 45。

库存自动写入 `user://test_b09_candidate/` 下的现有原子存档，保留冻结来源与随机记录。测试经真实 `EnemyActor` 死亡回调验证普通掉落、两件上限和重复回调，使用选定可复现的随机 seed；清房相同事件只发一次，改变难度的重试被拒。写入失败保留冻结结果，下一次清房／出口重试不会重抽。原子重读核对相同实例，兼容 JSON 整数表示为浮点的规范化比较。候选库存跨启动保留，本局配装重新选择；正式金币、经验、章节解锁不受候选装备结算影响。
