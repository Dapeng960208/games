## L38：M05／M06 的实际合同

M05 受光治疗：至少 1.3 秒可见引导，开始固定一名受光受伤的同章普通／精英同伴，D4 最多两名共用一条可见折线。排除自己、其他祀者、Boss 和机关。任一链接失光、死亡、离开 200 范围或视线受阻，整次取消，不偷偷换人；祀者实际受击（含状态盾消耗）或强制位移也会打断。

- D0 治疗目标最大 HP 的 6%；D2 治疗 4% 并给 4% 盾；D4 两名各治疗 3%，累计保留 D2 的 4% 盾。
- 治疗走既有重伤／整数结算，盾走非叠加状态池，显示实际增加量；不受攻击／暴击放大，同一施法 ID 不重复结算。范围 200、盾持续 3 秒是局部候选参数。

M06 钻出：至少 1.1 秒预警，锁点后不追人；地面隆起、脚下影子与半径 70 危险边界在低特效和隐藏可选路径时仍保留。通过碰撞安全运动抵达后才结算 1.0a；沿途不伤人，阻挡／位移中断不把爆点挪到墙边。

- D2 成功出土后留 2 秒无伤减速沙，每 0.5 秒刷新 0.75 移速，最后一次减速最多再延续 0.5 秒；镜座附近持续区域被拒绝，出生帧只扣实际出土后的时间。
- D4 至少 1.2 秒静止反击窗口后，沿冻结侧向无伤移动 80。被位移取消、撞墙停止；不追加爆点／沙区／转位，也不提前接下一次攻击。
- 钻行距离 150、动作 0.3 秒、0.75 减速是局部候选值，不是自然平衡结论，不改全局公式。

### 按用途验收有效像素

逐资产、逐动作、逐用途记录有效源内容尺寸及允许范围内最大的实际显示尺寸。线性采样比例为“有效源内容像素 ÷ 同一内容最大显示的物理像素”，宽高分别计算，以不足的方向为约束；不计透明留白，不拿整张图集尺寸替代单帧，也不把简单插值放大当作新增细节。最大显示尺寸应含实际允许的相机放大和窗口缩放；若以后加入图鉴／UI 放大展示，应独立列用途与尺寸，不能把尚未实现的展示当作当前验收结果。

- 角色／怪物：每个动作的身体与武器关键细节，以最大实际显示下至少 1:1 的有效采样为基线；1.25–1.5 倍余量是工程建议，并非用户额外指定的精确要求。仍须在实际 2K 小尺寸中验轮廓、脸部／武器辨识、alpha、脚点与动作可读性，像素充足不等于美术通过。
- 地形／近景建筑：按纹理覆盖范围、局部纹素密度和最大视角评估，优先足够清晰的原生图块／模块，不能用一张大图的整图尺寸证明每处细节充足。
- 远景：可有意低于 1:1 或柔化，以实际 2K 中层次清楚、不抢角色和玩法信息为准；不得只因源图未达 2K 判失败。
- 图标：以实际允许的最大 UI 物理像素为依据，建议源内容约 2 倍，并在真实小尺寸检查轮廓。尚未接入的 B07 专属图标不能因此标成已完成。
- 特效：按每帧有效包围盒、最大覆盖范围与关键危险边界验收；允许分段纹理或程序绘制边界，不用整张图集尺寸代替单帧质量，也不要求所有特效都用一张 2K 图。

当前 1280×720 逻辑视口到 2560×1440 的物理倍率为 2。M01 解剖身高源内容 824.5 像素，固定世界身高 82.08；美术试验 0.72 下实际约 118.20 物理像素、有效比例约 6.98:1，0.75 QA 近景约 123.12 物理像素、约 6.70:1。身体与武器合计的 alpha128 有效包围盒为 1123×1108，按同一比例投影，不能把该包围盒总高当作解剖身高。常规相机 0.85 当前不启用这张 M01 试稿；未来若改变允许镜头或加入图鉴／UI，需重新计算对应最大显示尺寸。现有 idle 像素储备不构成“必须补成 2K 源图”的理由，也不替代原始 alpha、运行动态质量及目标硬件验证。
