## 1. 定位与等级

B06通关后开放；敌人Lv31/33/35，Boss Lv35；装备iLv随区段，首领上沿35。章HP/攻击因子1.72/1.48。继承前两章的节点和时序概念，再增加“看见目标、获得攻击角度”的考验。难度来自镜阵和前排掩护，不靠完全隐身或反射秒杀。

美术为金沙阶梯城、青绿太阳盘、朱红布棚、绿松石壁画。蜥人长尾、眼冠和背鳞区分于兽人与龙裔；镜具是太阳祭仪工具，不做成机械科幻炮台。

## 2. 独特地图与种族规则

**三态引光镜**：每个固定镜座只有三种已标识朝向；F交互0.6秒切到下一态。射线路径人工固定，预览完整显示下一个方向。镜光可开门、显形或压制祭坛，不能照进无出口区域。解谜门保留两侧手动闸后备，战斗胜利后可直接开闸，避免缺少交互状态造成软锁。

**日鳞向光**：指定蜥人受光时正面120度减伤20%，侧后方无此加成；对应镜座转走后立即失效。不是物理/魔法免疫，也不把玩家高额伤害反射回自身。近战绕背、枪手转射线、法师改落点均可处理。

**沙纹伪装**：变色个体保留至少35%身体轮廓、脚印和明确技能预警。光束或靠近120距离均可显形；任何实际伤害均使其完全显形3秒。已锁定的合法技能不因贴图变淡而失效。

地图沿用2800×1800蓝图与0.58映射；坐标为百分比。镜座交互区半径90内不生成持续封锁伤害；至少一条宽180世界像素路线不受镜光伤害。镜光本身用于解谜时不伤玩家，敌方攻击光束另用危险色与轮廓。

## 4. Boss：日轮蜥王

Lv35；原始HP1200/攻击28/速度56/护甲10/魔抗10。D0设计HP27864、攻击559。金色太阳背冠、绿松石长尾与长矛仪杖构成身份。

P1 100–70%为持矛试探；P2 70–35%中央祭坛维持日鳞盾；P3 35–0%蜥王在两片日照区间转位。祭坛存活时Boss减伤30%，任意两镜照向祭坛即可压制8秒；也可直接打掉祭坛护罩，其HP为Boss设计HP的8%，不计Boss本体治疗。压制后Boss露背4秒，承伤+15%；每次触发间隔至少12秒，不强制三职业使用同一条解法。

## 6. 后续实现/验收边界

待开发31–35等级与iLv、三态镜座持久化、伪装可见性、角度快照和35装备模板；本PR不改当前资格版本。
