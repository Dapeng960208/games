用户提供的 `B07(1).png` 是最新视觉方向：峡谷上多层城堡、跨谷拱桥、陡直城墙，巨大金色太阳镜、蜥首雕像、朱橙长旗和阶梯门楼。来源 SHA-256 为 `8c7acde5497a7fff8a084b19818a7b4501403c513f3aff9fa5787a692e414984`。它是已查看原像素的概念参考，不直接当作游戏背景，也不替代可走几何。

当前第二次真实入口帧：渲染流程通过，约 75% 画面仍是亮地板，主要太阳地标和城体没有进入入口构图；M02／M03 使用 main 现存调试占位，不恢复退役虫形原图。M01 已有独立 idle 身份稿，尚未完成运行质量门。成功出图不等于满足概念图构图或角色验收。
