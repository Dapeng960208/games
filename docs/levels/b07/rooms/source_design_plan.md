## 共享层与本批必要生成

1. 远景：复用峡谷，不新增第二套矩形背景。
2. 外围中景：透明terraced_city_wing、lower_arch_bridge、sun_mirror_landmark；把城、桥、镜分开，避免以前整块裁背景和强压宽低比例。全部仅非导航装饰，最终放置/遮挡未定。
3. 有限立面：复用原源图；不能纵向无限重复，更不能盖住主地面。
4. 地面：现有源图近景采样约0.64；新增低对比砂岩局部重复模块候选，需另验拼缝，不以整图上采样解决。
5. 功能独立层：18镜座、7祭坛、12手闸、13低石复用4类新中性组件；状态光、实际光束和危险边界不烘焙进建筑。
6. 六个房间个性组件：布棚摊位、砂盘、工坊台、庙后廊、方尖碑、王台后景。仅源图覆盖，不表示每房构图已完成。

L39沙盘、L42双碑、BO07日照区目前只有设计字段，无独立运行对象；L42碑锚点等于低石rect左上而非脚点中心。不能把新图当新增碰撞。BO07没有stone_covers。

## QA边界

每源图保存原字节/hash/prompt/provenance；检查RGBA、alpha16/128有效内容bbox、边缘接触、正常alpha合成浅/深背景。原图RGB在alpha0下的隐藏彩边不等于实际可见晕边。必须以正确合成判断。

新图没有指定最大运行显示尺寸；不声称2560×1440最终清晰度通过。单组件有效像素对实际显示比例另验，不算整canvas留白，不强制每图原生2K。宽高/视角/脚点/遮挡/拼缝统一收敛；不从源图推定玩家能看见。
