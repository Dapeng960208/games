# 晴辉遗庭：七张固定房间设计

> 状态：当前参考：具体已实现范围以开发进度和运行代码为准。

实施状态：本页保留批准时的设计记录。固定摆放、独立道具与分块环境已接入；实际范围及仍待实现的玩法见 [当前实现说明](../../rooms.md)。蓝图坐标保留原单位，运行时统一映射。
本轮交付人工指定的空间图纸，不修改游戏生成逻辑。坐标统一为 2800 × 1800；L01–L06 与 BO01 保留既有 ID 和名称。每个房间都有独立路线、地标、环境叙事、目标位置、三个固定信标与三个怪群区域。信标功能可随机，场景位置和装饰种类不随机。

统一画面是明亮手绘 2.5D，高机位三分之四斜俯视。米白石地、黄铜机关、青蓝晶光与清绿植物贯穿七房；古典花园融合魔法蒸汽构装文明。物件从旧矿井绞盘、箱子，转向太阳花钟、晶芽温室、日月星仪、三叶光秤、花蕾升舱、吐云铜炉和齿瓣机械花。具体素材仍需按图纸制作。

| 房间 | 路线与视觉中心 | 场景差异 |
|---|---|---|
| L01 晴辉门庭 | 西南到东北的斜线，北侧回环；停转花钟 | 迎宾铜铃树、园匠曲背椅、晶籽摇篮讲述入口生活 |
| L02 浮晶拱桥 | 北线进入、南线回归；透空浮晶光拱 | 连续干地晶桥、外围细渠、两座小温室与导光镜 |
| L03 符文回廊 | 北绕南归的 S 形；齐地三环符盘 | 春冬晶芽、季节铃树、小日月星仪表现报时园艺 |
| L04 琉光仪场 | 偏北折线，南侧大回环；日月星仪 | 形状不同的三处光秤、圆铜炉、冷露瓶和聚光镜 |
| L05 悬曜升台 | 南线切入北线的宽 U 形；休眠花蕾舱 | 外围幼花舱、候日温室、升降铃枝与露压阀 |
| L06 辉核祭庭 | 南北交替的 Z 形；三瓣校准座 | 炉温、凝露、废光三片环境小景对应三处回路 |
| BO01 日曜机关巨像 | 开放环路，三处破盾接座；原初花冠座 | 复苏温室和庆典铃树呼应首领击败后花园恢复 |

普通房各 14 件场景道具、首领房 16 件，种类均控制在 8–12 类。普通房只有 2 件外围小碰撞物，首领房 3 件；单件实体足迹不超过 120 × 75。其他细框、花枝、灯、椅与低矮地纹不承担碰撞。主路线至少留 360 单位宽，内场保留宽阔战斗与绕背空间。

禁止恢复大矩形水池、坑洞、地图内高墙和被拉伸的地板侧面。水只出现在地图边界外的细渠；L02 的“桥”由连续白石地面与悬浮晶拱表达，L05 的“升台”由外围低舱表达。地面圆纹和核心座保持低矮，不阻断角色移动或遮挡预警。

地图边缘不使用灰色外圈或直接裁断的地砖。北侧接透空花廊与温室，东侧接窄渠与睡莲，南侧接下层花园与完整石阶，西侧接园匠小径。地砖依次经过草缝、窄花边或收边石，再进入外景；石台短侧面单独绘制，不拉伸贴图。少量前景花叶只出现在底角并逐步淡化。每房 `edge_variant` 再指定与其地标对应的外圈叙事。

本图继续采用初版的接通回路与清场目标，2／3 目标数量交替。独立搬运、旋转、升降、温压机关仍为后续设计；JSON 的环境名称和说明不代表这些系统已经上线。首领的三个怪群区域是有限增援候选点，不在开场同时包围玩家。装备与遗物条目提供主题关联，保持已有掉落名称，未添加虚构的新数据 ID。
