## 1. 成长与玩法定位

B07通关后开放；三区敌人Lv36/38/40、Boss Lv40，装备iLv随区段、首领上沿40。章HP/攻击因子1.84/1.56。本关把上一章的射线管理升级成“移动后重新建立射线”：风道、俯冲与侧翼支援按顺序制造压力，不要求像平台游戏一样精确跳跃。

天蓝云海、象牙白空港、亮金翼形屋顶与靛蓝帆布构成日照浮岛。建筑体现航运、缆索、泊船与报风用途；翼人有羽翼和轻装轮廓，不和终章龙角长颈混淆。

## 2. 地图元素与种族机制

**定向风道**：三态风标控制固定风道，F交互0.6秒，切换预告1秒。顺风移动+20%、逆风-10%，仅影响有明确风纹的地面；不暗改玩家子弹方向、不替玩家换目标。每条风道旁有正常速度的步行路线。

**云桥与安全转移**：六房人工固定桥位，宽度≥180世界像素；风道可缩短支线行程，但不能作为唯一出口。边界阻挡与角色脚点一致，无无提示跌落即死。桥上被推移按可走区裁剪，并保留2秒连续位移保护。

**占风势**：翼人在专用风道完成一次有预警的转位后，下一次已解锁主动伤害+12%，4秒内使用、内置CD10秒；不是永久全族攻速光环。每房可拆报风旗关闭该区8秒占风势，旗HP为本区F档40%。飞行视觉不使近战失去合法命中点；俯冲后至少1.1秒着地收势。

**空战信息**：落点圈、影子与高度提示同源。遮挡淡化不隐藏敌人影子；场外候机单位不在被锁定列表中，不从画面外立即攻击。

## 4. Boss：苍穹风羽统领

Lv40；原始HP1300/攻击30/速度58/护甲11/魔抗11。D0设计HP32292、攻击632。身份为持长翼枪的翼人指挥官，不使用龙形轮廓。视觉飞行不制造长时间免伤，脚点与技能命中代理始终一致。

P1 100–70%中央平台枪术；P2 70–35%交替启用左右风道；P3 35–0%宣布“俯冲→羽阵→回台”的固定组合。玩家把本轮迎风标转为侧风后，可让下一次俯冲落地收势延长1.5秒，Boss承伤+15%持续4秒、ICD12秒；不交互也有常规落地窗口。
