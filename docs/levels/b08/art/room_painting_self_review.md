## 代码与映射断点

1. B08 `room_controller.gd` 的 `load_room_layout` 只有 `id`，缺少标准 `room_id/blueprint_room_id`；`_configure_world_view` 隐藏共享 MineBackdrop，镜头仅绑定固定 ARENA。L43 再通过专属环境节点拼图，未复用完整原画边界。
2. `geometry.gd` 单次缩放原则正确，但 L43 渲染脚本又写死 `.58` 与 1624×1044。新路径应从同一 room mapping 获取画面、通行并集、风标/入口/出口、脚点和镜头目的坐标，避免图与机制分别维护比例。
3. **不能把 B08 并集换成凸包。** 共用 `room_boundary.gd` 只支持单凸多边形；L43/L47/L48/BO08 存在凹边、云洞或分岛连接。直接套凸包会填平不可走空域。原画可复用 WorldArt/Backdrop，物理继续保留并集语义并从相同原画坐标映射，或另做保留洞的明确多区域数据。
4. B08 场景 MineBackdrop 尚无正式场景的 z=-20；直接 show 会盖住 z=-3 机制地面反馈。新原画路径须按现有正式层级设置，并停止叠画旧矩形材质、桥腹/石檐拼装，避免双重地面。
5. 已接入 L43 风标/报风旗使用共享脚点节点，源锚点与实际碰撞位置一致，可保留。可遮挡玩家的高道具不能只烘焙在背景里，继续通过现有深度/淡化节点表示。

## 最小修正次序与布局影响

先为 L43 制作一张独立房间原画和环境元数据：统一高机位、白石主桥/北桥、蓝顶翼塔、岛体纵深、光照与地面材质尺度。现有角色与交互源图保留，动态技能/旗/风标/出口不烘焙。将标准逻辑 ID 登记到 manifest，再以现有 WorldArt/Backdrop、同一源→世界映射和真实玩家镜头验证首房；之后按七房各自场景身份推广，不复制换色。

仅更换原画和映射可以统一透视、光影、采样和建筑比例，但**固定大矩形可走并集的面积不会因此消失**。若要达到用户参考图中狭桥、自然岛缘和更明显多岛关系，需要另列可审阅的 L43 轮廓调整：会影响实际通行边界、寻路净空、出生/遭遇锚点、风道覆盖和 AI 位移目标。入口/出口稳定 ID 与玩家档可以保留，但不能声称碰撞完全没变，也不能先画不可通行墙体/断桥来掩盖问题。本轮自查尚未执行这样的布局修改。

下一份首房设计需把固定锚点、合法脚点净空、两条现有路线和中央云缝直接叠在原画坐标上审查；绘制与几何不同步时不接入。此前拼装源包与受控测试记录完整保留，明确属于未终验候选。
