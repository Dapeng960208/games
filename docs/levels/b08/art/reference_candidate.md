### 本章不同用途的分辨率要求

- **角色/首领动作帧**：按每帧有效身体、武器及关键细节计算，排除透明留白与 atlas 总尺寸；有效源像素对最大实际显示像素至少 1:1 为基础。建议留 1.25–1.5 倍余量，这是实现建议，不是用户逐值指定。游戏镜头和图鉴展示分别验收。M01 当前只有 idle：解剖源高 937→默认玩家画面约 170 高；包含弓/翼/身体的 alpha≥16 有效边界为 `(303,25,881,1189)`，完整投影约 160×216，不能拿 1254² 空白画布作为人体指标。该帧采样余量充裕，其他姿态仍缺失。
- **地面与近景建筑**：按实际材质密度、石缝/轮廓/饰件可读性判断。需要增加细节时优先可重复原生图块、分块或建筑模块，不默认用一张低分大图铺满屏；重复图块仍须检查接缝。现有完整地表的约 1.765 倍显示放大需实际查看纹理，不能仅凭倍率否决。
- **远景**：允许有意柔化/低分采样，重点是 2K 玩家画面的空间层次、无明显伪影和不抢近景。45% 空气透视小样只影响远景绘制，原 PNG 保持不变；其清楚程度应符合远景用途。
- **UI 图标**：按最大 UI 显示尺寸，建议源有效主体约为其 2 倍；不同 UI 缩放/图鉴用途单独检查。目前没有新增完整 B08 图标库，不能借现有环境尺寸标完成。
- **特效与预警**：按每帧有效主体和最大屏幕范围计算，不能用 atlas 总尺寸代替单帧清晰度。长条可分段复用；危险边缘、方向与低特效可读性必须保留。当前风纹为运行绘制，按真实 2K 边缘/方向效果检查。

透明外景的有效像素按 alpha≥16 测量，不能用整画布代替：西岛 1397×932、东岛 1471×912、大拱 1467×948、风塔 872×1483、翼殿 864×1039、飞艇 1512×999。对应最大实际屏内范围仍受走区裁剪/镜头遮挡；上表完整矩形仅是保守上界，不冒充有效主体覆盖。
