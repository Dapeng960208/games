## 1. 实际环境与覆盖

Godot 4.7.2-stable，Windows，OpenGL 3.3 Compatibility，NVIDIA GeForce RTX 3060 Laptop GPU。GPU framebuffer／截图为 2560×1440，logical viewport 为 1280×720；没有查询本轮物理显示器尺寸，不能据此称在物理 2K 屏幕完成了人工试玩。

CH01／CH02／CH03 对 B01–B06 与 B10 的 49 房形成 147 组矩阵，实际创建角色、房间和既有 HUD，经生产物理读取映射按键与视口点击，检查渲染、移动、脚点、镜头、HUD 与战斗接线。夹具使用新建隔离档、指定拍摄位置及禁用普通刷怪 AI 的受控条件。B09 本轮只复查 release gate，没有重跑其七房完整 GPU 矩阵；此前候选验收不能混称为本轮覆盖。

真实 Main 检查营地锁定预览、隔离档的 BO09／等级准备、出征路线、七房推进、必选奖励、正常撤离与终章完成界面。清场通过演员的受控致命伤害进入生产死亡／奖励链，没有将此操作记为自然战斗通关或全职业自然平衡。

## 4. 彩蛋与玩家数据

B10 有 35 个自然模板及一枚 `B10-EASTER-RING`「星冠万象戒」，合计 36 个模板；基础六章加终章合计 230 模板／26 套。该金色 Lv50 固定实例 `instance:finale:ring` 对三职业通用，19 项 `Registry.STAT_KEYS` 均有正向固定收益，同时覆盖物理和魔法取向。

每份存档仅一枚。D4 的 BO10 实际完成后正常撤离，同一次奖励保存事务首次领取；满包保留 pending。死亡、提前撤离、重复回执、保存失败重试与再次通关不能另发一枚。不进入随机、购买或打造，也不能售出、拆解、继承或进行任何锻造。一次性奖品由远征保存事务处理，不由美术／首领表现节点直接发放。

真实玩家 `profile.json` 在验收前后 SHA256 保持 `DB5464D299E685A3AB6C21BD23FD6A4BC8E3D10C9E821585B75839989394C876`。隔离档、日志和缓存不入库；实际玩家数据、永久装备、资源来源与许可保留。
