## 1. 等级与挑战定位

B09通关后开放；敌人Lv46/48/50，Boss Lv50；装备iLv随区段，首领上沿50。章HP/攻击因子2.08/1.72。比冰晶王庭多一项持续预算：不是看到圈就走，而是规划连续两轮喷发后的冷却路线与输出窗口。等级不随玩家装备动态追平。

场景保持亮橙、砖红、铜金、日照火山玻璃和白蒸汽。炎魔以角、火焰鬃与赤陶甲轮廓区分，不把全关压成黑红地狱；熔岩、可走冷岩、装饰炉火必须不同造型。

## 2. 地图元素与种族特性

**熔流节拍**：固定18秒周期，冷却8秒→预热2秒→喷发4秒→降温4秒。只有标明的熔沟和火口进入危险；永久石路占可走面积至少40%，始终连通入口、冷却阀和出口。第一次进入房间至少6秒内不会开始喷发组合。

**灼热层**：玩家在已激活热区每2秒积1层，上限5；离开热区每秒减1层。到3/4/5层分别承受0.10/0.15/0.20a每秒，a取本区普通F档攻击；每秒只结算一个最高层热伤来源，不把多个重叠火区叠成无限伤害。层数与来源有图标；未预热完成的区域不积热。

**冷却阀**：F交互0.6秒，使指定120半径地面冷却6秒并移除范围内玩家2层灼热，CD16秒。阀不增加永久货币/资源，不是新增装备槽。三职业都可使用，不要求冰系技能；冷却阀旁不得安排必中的全覆盖攻击。

**熔甲排热**：部分炎魔有20%熔甲减伤。连续提交两次主动后进入3秒排热，关闭减伤且承伤+15%；冷却阀命中可提前触发，单体触发CD10秒。不能让冷却机关造成永久控制，也不给炎魔完全物理/法术免疫。排热身体开口与地面蒸汽提示清楚可见。

蓝图2800×1800按0.58映射，坐标为百分比；永久主路宽≥180世界像素。熔岩只在低处窄沟和外缘，不使用占据内场的大方块坑池。

## 4. Boss：熔冠魔君

Lv50；原始HP1500/攻击34/速度62/护甲13/魔抗13。D0设计HP42120、攻击789。赤陶王甲、铜金冠焰、胸前炉门构成主轮廓，Boss招式由炉压与重武器驱动。

P1 100–70%教重锤和单沟喷发；P2 70–35%加入18秒熔流周期；P3 35–0%宣告双次炉压，但仍保持至少一阀可达。王甲减伤25%；连续两次主招后开炉排热4秒，关闭减伤且承伤+15%。冷却阀可提前开炉，CD14秒；不能让Boss因重复交互永久僵直。该窗口不要求玩家使用冰技能。
