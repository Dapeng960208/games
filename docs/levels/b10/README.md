## 1. 等级与终章定位

BO09 通关后解锁；敌人 Lv46／48／50，最终首领 Lv50，装备 iLv 随所在区，首领上沿 50，等级上限 50。B07、B08 未实现且本次不集成，B09 仍为隔离候选、正式入口未开放，因此正常流程尚不能抵达 B10。章节 HP／攻击因子按第十章 2.08／1.72 解析，不沿用取消的后续章等级与倍率。L55–L60 为稳定房间 ID，原设计迁移后继续保留，不重排存档身份。

综合检查取角、转位、持续压力、节点优先级与延迟攻击，但每轮最多挑其中两类高威胁机制同时出现。终章难度通过分区调度和星核优先级递增，不把前面章节的所有危险无差别叠满。

全章以 `assets/levels/b10/ui/design_reference.png` 为视觉参考：白金高空圣庭、蓝晶星纹、金色星环、日光星门和外围云海，统一明亮手绘卡通奇幻、高机位三分之四斜俯视与 2.5D 质感。龙裔必须有角、翼或长颈长尾的明确组合，六守关龙各有独立轮廓；BO10 为单头星冠古龙，以白金鳞片、蓝晶胸核和金冠体现身份，保留三阶段星核，不再要求多头结构。

## 2. 独特地图与种族机制

**成对星门**：每个房间门户连接固定两点，F交互0.6秒，传送0.4秒，显示目的地预览与剩余技能危险。没有随机出口。传送不回血、不回资源、不清技能/闪避CD、不刷新套装计时；未释放接招队列按现有切换安全规则清理。门户旁总有半径100落脚区，传送启动后不新增针对落脚中心的即时追踪攻击；已有预告照常结算。

**分区伤害归属**：所有弹体/地面区带来源分区；普通弹体不会因玩家过门就瞬移到另一分区。明确的“星门射线”可跨门，但必须预览两端、完整保留两段预警并按同次施放去重。伤害、怪物HP和击杀奖励不会因出入门户重置。无收益的纯传送往返不能刷资源或护盾。

**星核对位**：固定星核最多连接2个龙裔，连接线和星纹编号可见。被连单位每10秒最多让一次主动在原锁定位置产生0.25a回响，延迟0.9秒，回响不能再回响。星核HP为本区F档60%；击破后断开8秒，普通攻击与所有合法技能都能拆，不能只允许法术打星核。

**鳞阵换守**：部分前排在被命中后只改变面向/位置，不获得全免疫。每次守势最长2秒，换守后必须1.2秒收势；让战士找侧背、枪手找射线、法师找落点，不能频繁瞬移令任一职业无法完成技能。

蓝图2800×1800按0.58映射；坐标为百分比。普通房主战斗区与机关区由宽步道或固定双门连接，门户不放在细桥尽头。Boss本体主要停留中央大场，侧台仅承载星核和守卫，不让巨型古龙挤满小机关台。

## 4. Boss：星冠古龙

Lv50；原始 HP1700／攻击38 由 B10 战斗目录与现有难度解析器处理，不把原始值或旧设计面板当作当前实测结果。单头、白金鳞片、蓝晶胸核、星环双翼与金色古龙冠形成最终首领身份；前爪、胸核与尾部动作分别对应攻击来源。下表为本轮必须对照实际运行和图形记录的招式合同。

**星核盾阶段**：P1 100–70%激活1核；P2 70–35%激活2核；P3 35–0%激活3核。每活跃核提供15%减伤，上限45%，不是无敌。单核HP为Boss设计本难度HP的6%；每阶段每核最多重建一次、间隔至少16秒，重建引导1.5秒可打断。三职业都能打核。每阶段首次清空活跃核时，古龙伏地5秒、承伤+15%；之后仍可直接输出，不强制等核反复复活。

古龙主要留在中央大场；左右核台配有限守卫而非缩小Boss战斗空间。玩家去核台时Boss不回血、不重置阶段；明确跨门技能有完整提示，普通爪击不能隔场地命中。
