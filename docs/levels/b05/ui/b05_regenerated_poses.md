## 明确边界

这是原生源图与受控生产渲染的局部验收，不是完整自然战斗/平衡、硬件GPU性能或八方向动画验收。三张关键姿态不是完整连续动画；walk/recovery仍复用idle及运行时变换。上/下瞄准仍以侧身图配合真实地面预警。部分源图小于20像素安全建议、个别外沿有alpha1生成噪声，均原样保留；alpha≥16的有效身体没有触边裁切。普通站位下他人身体的自然遮挡仍存在。
