# 赤岩战寨 · 现有素材与新增素材差异

状态说明：本文保留批准前的目标效果与素材增量作为设计对照。环境、独立道具和新版 UI 构件已部分接入；当前实际范围见 [开发进度](../../DEVELOPMENT_PROGRESS.md)。表中旧键位、待确认或尚未实现等文字属于当时的预览记录，不是当前操作规范或完成清单。原截图临时副本已清理，当前实机截图见 [本族运行画面](art/B04_runtime.png)。

效果预览 art/B04_gameplay_preview.png 以实际游戏截图 artifacts/storybook_L21_1280.png 为基础。罗砧身体与头像、当前三种兽人/食人魔、技能徽章、任务面板、生命与资源 HUD 沿用现有内容。图中的场地、美术边缘和少量新道具属于待确认方案，尚未替换运行时素材。

| 内容 | 当前可复用基础 | 确认后需要制作的素材 |
|---|---|---|
| 角色与怪物 | 罗砧身体、头像、斥候/刀手/食人魔三种实际外观 | 本轮不增加角色或怪物，不新增技能功能 |
| 赤陶补给箱 | 当前陶箱/补给箱的体积、脚点和使用职责 | 靛蓝编织盖、兽牙扣与赤陶材质的透明底 2.5D 道具版本；避免同一箱体多处重复 |
| 战图腾、信号锣 | 当前角盔图腾、盾形锣等已存在造型 | 增补骨雕与鼓纹细节的透明底变体，保留可识别轮廓与现有交互职责 |
| 柱拱与信标 | 现有柱拱、青蓝/粉紫晶体信标 | 短赤陶柱和兽牙拱的透明底族群版本；信标保留固定脚点与统一状态配色，可追加骨结绳底座 |
| 巨兽骨秋千 | 当前没有对应完整道具 | 独立透明底 2.5D 背景道具，弯肋骨、靛蓝吊篮、短阴影；仅用于外围文明布景 |
| 捕网台 | 当前没有对应完整道具 | 透明底 2.5D 沙蛛骨架网台，网眼通透，控制高度与脚点；不引入新的蛛类野怪 |
| 牙雕寨门 | 现有拱柱可作为尺寸依据 | 透明底 2.5D 笑脸兽牙门柱与分段拱件，不伸入唯一通路，不拉伸地板贴图代替墙 |
| 场地与边缘 | 当前有赤岩地面和族群颜色基础 | 新手绘沙金—赤陶混铺地面、自然砂土过渡、旱草、低赤岩层、分段短寨墙、低骨栏、靛蓝旗和鼓；背景与前景分层，人物附近遮挡淡化 |
| 后续 UI 小图标 | 现有羊皮纸面板、黄铜边、深紫文字、圆技能徽章 | 牙雕族徽、鼓纹任务标、捕网布景标和赤陶装备小图标；未来单独输出透明 2.5D/UI 素材，保持 HUD 位置与状态色含义 |

制作顺序：先确认基于现有内容的效果预览及固定布局，再按道具/地面/边缘/UI 分组输出可直接使用的素材，最后接入游戏。不能把美术效果图当作已经实装的场景，也不能用一张大背景替代真正需要脚点、排序、碰撞和遮挡的物件。
