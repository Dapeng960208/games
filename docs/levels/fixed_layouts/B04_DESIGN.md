# 赤岩战寨 · 七张固定布局设计稿

本稿供地图设计图确认。地图、目标、信标位置、怪群事件区域和物件全部使用人工固定坐标，不属于已经实装的游戏内容。坐标以 2800 × 1800 的连续地面为基准；同一房间换难度只调整敌人批次、属性与掉落权重，不洗牌道具位置。

赤岩战寨是一座有日常生活的兽人、食人魔竞技城。画面使用沙金地面、赤陶短墙、靛蓝织物、青绿生活器皿和米白兽骨，暖阳照明。高机位三分之四斜俯视、近等距、手绘 2.5D，与其他三族保持人物尺度、描边和 UI 一致。巨兽骨秋千、火蜥风箱、沙鲸水罐、独眼沙兽风袋与沙蛛网机建立这个文明的独特性；不再重复旧矿业绞盘。

每个房间设置 3 处固定信标点；信标功能可以在进入房间时抽取，位置不变。靠近进入生效范围即可回血、回复资源或获得临时加成。信标只用于额外支援，任何普通关卡的通关条件都不依赖抽到特定功能。

主路线和侧路线均保持宽阔。每房 14 件布景，10–11 种不同道具，最多 4 件具有实体碰撞；实体脚点均不超过 120 × 75，且都位于外围。高物件只布置在后景或边缘，中央训练圈、织毯、道路纹样只有地面图案。两到三处牙栅属于可破任务目标，放在可绕行的口袋区，绝不封死唯一通路。裂谷不切出内部大坑、水池、窄桥；不使用拉伸贴图墙。

装备掉落沿用战鼓猎牙、风嚎图腾两族套装，以兽牙、鼓皮、红岩骨甲和风讯符纹组成统一材料语言。本文的裤装、戒指、新遗物效果均为设计候选，需要后续实现装备槽位、词条、保存和触发冷却后才进入实际掉落池。高难度增加精英批次、敌人属性和高级掉落权重，不用堆满杂物或无上限召唤来增加难度。

布局数据见同目录 B04.json。主稿将用这些坐标绘制七张俯视布置图，并用统一图例区分地标、非碰撞布景、小脚点实体、信标、怪群、可破目标、主线和侧线，先确认布局再改游戏。

地图边缘也纳入固定设计：上缘使用分段赤陶短寨墙、巨鼓柱与靛蓝旗，后接日照赤岩远山；东西边缘通过铺石、稀疏石板、同色砂土旱草和分层砂岩自然递进；下缘使用低矮圆石、短骨栏和小沙兽生活道具。所有边景手绘透视与人物一致，不留空灰带、不拉伸地板贴图做高墙、不做浮空方形底板。前景占屏限制在约十分之一，角色靠近时遮挡物降低透明度。七房各有 edge_variant 描述，街市边缘用凉棚、角斗庭用看台、工坊用锻炉、烽灯房用开阔峡谷远景，维持主题区分。

美术参考总览为 art/B04_concepts.png，使用内置 image_gen 按已确认画风制作，一张四列两行板包含七个独立房间与一格特色道具。该板用于材质、光照、种族文明与地标方向确认；精确位置仍以 B04.json 与固定坐标布局图为准。对应提示词记录在 art/B04_concepts.prompt.json。
