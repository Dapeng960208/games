# 四地图 · 28 房间固定布局设计册

本轮供玩家确认美术与关卡摆放，不修改游戏运行时。用户已确认先覆盖前四地图，每族六个战斗房间与一个首领场地；后八地图维持待办。

打开 [设计册](index.html)，可以切换四张主题地图并放大逐房设计图。所有 28 张固定布局图位于 `rooms/`；四张七房美术总览位于 `art/`。美术总览表达材质、光照、镜头和道具形态；逐房布局图与对应 JSON 确定人工指定的位置，不把 AI 生成插画当作精确碰撞地图。

用户追加要求：效果图以当前已有的游戏元素为基础。因此每族另有一张 `art/B0*_gameplay_preview.png`，以实际游戏截图为编辑底图，保留现有角色、怪物和 HUD，展示场景固定摆放与边缘的预期效果。新增内容在 `B0*_ASSET_DELTA.md` 列出；确认后需要输出独立 2.5D 透明道具、完整边缘素材、地面过渡片及对应 UI 图标，不能用一张效果图代替可接入素材。

## 固定与变化的边界

- 地形、场景物件、地标、入口出口、任务目标、信标位置和主支路线全部固定；同一房间重进保持空间记忆。
- 难度可以改变敌群数量、属性、有限增援与掉落收益；不得随机移动道具或改变通路。信标功能可以随机，位置保持固定。
- 每房都有独立视觉叙事、主要地标和种族生活物件。低密度小脚点掩体位于外围，中心与主路保持开阔。
- 不使用内场大矩形坑池，不把地板贴图拉成高墙，不用重复绞盘或箱子填满四种文明。道具以独立 2.5D 素材制作，保持角色尺度和实际脚点。
- 新道具、独立机关、掉落名称与完整边缘均为设计草案，不声称已经进入游戏。

## 四种边缘

[四主题边缘美术参考](art/perimeter_concepts.png) 与各族 JSON 的 `edge_design`、每房 `edge_variant` 配合使用。

| 地图 | 远侧和侧面 | 近侧与地面过渡 |
|---|---|---|
| 晴辉遗庭 | 藤蔓柱廊、玻璃小温室、远处水渠和下层花园 | 矮石栏、浅短石台侧面、花箱；水位于战斗地面外 |
| 琥珀虫巢 | 巨叶屋檐、蜂蜡巢壁、透明琥珀根与花粉灯 | 根须矮栏、蜂蜡台阶、叶片花丛；开放干地连续通行 |
| 南瓜墓镇 | 紫瓦小镇、棺材邮局、墓钟与暖阳墓园 | 低墓栏、南瓜花圃、石路软过渡；完整街区延伸到画外 |
| 赤岩战寨 | 分层赤岩、兽牙寨门、靛蓝战旗与远方峡谷 | 矮木寨栏、巨鼓台、沙坡和仙人掌；浅石地面渐变到土沙 |

共同采用五层：可走地面 → 低边界或植被过渡 → 独立短侧面/外围地物 → 后方文明背景 → 外角少量前景。碰撞界线留在可见的低边界，远景不参与碰撞。近前景不遮人物脚点、技能预警、信标与出口；必要时按人物位置淡化，不靠高频视差、屏幕抖动或滚动纹理制造立体感。地面边缘使用同色接缝、独立收边与整片过渡材质，禁止露出灰色空圈、直线接缝和透明图集外的杂色。

## 文件与复现

- `B01.json`–`B04.json`：四族人工固定坐标方案，世界尺寸统一 2800 × 1800。
- `B01_DESIGN.md`–`B04_DESIGN.md`：独立地标、种族物件、故事与边缘变体说明。
- `rooms/L01.png`–`rooms/L24.png`、`rooms/BO01.png`–`rooms/BO04.png`：逐房位置图与物件编号清单。
- `B01_layout_board.png`–`B04_layout_board.png`：每族七房固定布局总览。
- `art/*_concepts.png`：内置 image_gen 生成的美术方向板；同目录保留完整提示词。
- `tools/build_fixed_layout_atlas.py`：仅将设计数据绘制为图片与本地设计册，不接入运行时。

确认后实施顺序：先制作各族独立边缘与特色物件素材；再让游戏读取固定房间布局、移除随机摆放；最后落地逐房目标和难度敌群配置。不得只在当前随机场景上增加装饰数量。
