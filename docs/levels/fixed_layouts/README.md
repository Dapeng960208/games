# 四地图 · 28 房间固定布局设计册

用户已确认前四地图的美术与固定摆放，每族六个战斗房间与一个首领场地；后八地图维持待办。当前实现读取这 28 张蓝图，场景点位不再随随机种子改变。

打开 [设计册](index.html)，可以切换四张主题地图并放大逐房设计图。所有 28 张固定布局图位于 `rooms/`；四张七房美术总览位于 `art/`。美术总览表达材质、光照、镜头和道具形态；逐房布局图与对应 JSON 确定人工指定的位置，不把 AI 生成插画当作精确碰撞地图。

用户追加要求：效果图以当前已有的游戏元素为基础。因此每族另有一张 `art/B0*_gameplay_preview.png`，以实际游戏截图为编辑底图，保留现有角色、怪物和 HUD，展示场景固定摆放与边缘的预期效果。新增内容在 `B0*_ASSET_DELTA.md` 列出；确认后需要输出独立 2.5D 透明道具、完整边缘素材、地面过渡片及对应 UI 图标，不能用一张效果图代替可接入素材。

本轮已将独立道具、完整环境及新版 UI 构件接入游戏。设计册增加各族中心、北侧、东南三处实机截图，以及远征路线、保存退出、背包、营地、设置和按钮组件预览。`art/B0*_runtime*.png` 与 `art/ui_*_runtime.png` 均为真实 Godot 输出；原目标效果图保留供对照。

## 固定与变化的边界

- 地形、场景物件、地标、入口出口、任务目标、信标位置和主支路线全部固定；同一房间重进保持空间记忆。
- 难度可以改变敌群数量、属性、有限增援与掉落收益；不得随机移动道具或改变通路。信标功能可以随机，位置保持固定。
- 每房都有独立视觉叙事、主要地标和种族生活物件。低密度小脚点掩体位于外围，中心与主路保持开阔。
- 不使用内场大矩形坑池，不把地板贴图拉成高墙，不用重复绞盘或箱子填满四种文明。道具以独立 2.5D 素材制作，保持角色尺度和实际脚点。
- 已输出四族独立透明道具图集、边缘图集和完整连续环境母图。运行时使用环境母图的六个连续区块与独立道具；新增掉落名称、遗物效果及关卡机制仍按各族差额清单逐项落实，不能把美术完成等同于全部玩法完成。

## 四种边缘

[四主题边缘美术参考](art/perimeter_concepts.png) 与各族 JSON 的 `edge_design`、每房 `edge_variant` 配合使用。

| 地图 | 远侧和侧面 | 近侧与地面过渡 |
|---|---|---|
| 晴辉遗庭 | 藤蔓柱廊、玻璃小温室、远处水渠和下层花园 | 矮石栏、浅短石台侧面、花箱；水位于战斗地面外 |
| 琥珀虫巢 | 巨叶屋檐、蜂蜡巢壁、透明琥珀根与花粉灯 | 根须矮栏、蜂蜡台阶、叶片花丛；开放干地连续通行 |
| 南瓜墓镇 | 紫瓦小镇、棺材邮局、墓钟与暖阳墓园 | 低墓栏、南瓜花圃、石路软过渡；完整街区延伸到画外 |
| 赤岩战寨 | 分层赤岩、兽牙寨门、靛蓝战旗与远方峡谷 | 矮木寨栏、巨鼓台、沙坡和仙人掌；浅石地面渐变到土沙 |

共同采用五层：可走地面 → 低边界或植被过渡 → 独立短侧面/外围地物 → 后方文明背景 → 外角少量前景。碰撞界线留在可见的低边界，远景不参与碰撞。近前景不遮人物脚点、技能预警、信标与出口；必要时按人物位置淡化，不靠高频视差、屏幕抖动或滚动纹理制造立体感。地面边缘使用同色接缝、独立收边与整片过渡材质，禁止露出灰色空圈、直线接缝和透明图集外的杂色。

## 分块地图实现与调研结论

本次边缘问题来自三个同时存在的错误：地板贴图的色彩与比例偏离参考图，外围使用同一物件整排重复，矩形碰撞边界没有跟着实际场景轮廓走。把原来的错误大图切小不会自动解决这些问题。

采用固定手绘区块拼接、独立立体物件和单一地面轮廓的混合方案。每族生产环境母图为 1536 × 1024，按 3 × 2 划分为六块 512 × 512 连续区域；同一原画、同一缩放、同一坐标变换保证当前版本没有独立生成造成的色差与错缝。Sprite2D 的 region 共享原图，允许场景节点逐块裁剪；原图纹理仍整体驻留，这一版没有承诺显存流式加载。

后续大地图扩建，制作各族固定小场景模块，并在模块清单中明确四侧接头、地面尺度、转角、出口、世界脚点与碰撞形状。中央地板适合 TileMapLayer/terrain，外围建筑、花丛、岩壁及地标适合固定场景组合；不随机排列模块。独立生成的美术必须以同一母图和色卡为参考，在共享接缝处提供过渡区并逐对检查，不能只靠程序强行拼接。

当前地面、外围风景分块与独立道具保持低层／高层关系。可走轮廓以母图的归一化凸多边形记录，再由同一变换供角色接触、点击路径与敌人导航使用。世界镜头限定在完整原画范围内，并随窗口调整最低缩放，避免大窗口看到画外空白。HUD 和背包仍固定在屏幕层，地图移动不会拉走它们。

原画对照发现 L01 与 L06 的原入口落到岸边植被，已将入口和主路起点分别微调至蓝图单位 `(430,1370)`、`(500,1420)`，并同步对应布局图与运行数据。优先让脚点落在实际石路上，没有扩大整圈碰撞去包住水岸。

当前启用环境 v3：四张原画都细化为较小的铺地单元，墓镇保留浅色石路与淡紫缝隙，战寨减弱整屏橙黄并加入奶油浅砂。人物身体显示高度统一为 112 世界像素，三名英雄所有已接入动作共用同一尺度和脚点；普通敌人的显示高度增加 20%。只调整呈现，移动与攻击距离继续使用战斗数值，避免改比例时连带改变手感。

功能目标优先使用独立族群造型，装饰按真实纹理路径和取样矩形去重；同一图被别名引用也视为重复。战寨路障使用木寨栏、兽骨矮栏与岩障，战鼓只作场景物件。若装饰与目标或奖励宝箱重复，则在原位置选用未占用的同族物件，保留原脚点与碰撞，不随机重排。去重范围是单个房间，公共图集可以跨房复用。

操作默认改为右键移动与按住跟随，左键／A 普攻，QWER 四技能，空格闪避，F 交互，B 背包；已有自定义绑定保留。右键路径绕过固定掩体，左键点击目标时在有效攻击距离内朝向目标，不自动追到怪群。自动普攻可在设置中启用。

本轮保留与变更直接相关的检查：28 房间的固定摆放及地面可达性、自定义输入兼容、路线交互、三职业动作尺度、窗口适配和实际页面截图。遗物新增玩法、种族掉落名称、八个有效装备槽位与后八地图仍按原计划继续，不能以截图代替完整功能验收。
