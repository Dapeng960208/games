# B02 · 琥珀虫巢固定布局设计（待确认）

实施状态：本页保留批准时的设计记录。固定摆放、独立道具与分块环境已接入；实际范围及仍待实现的玩法见 [当前实现说明](../../rooms.md)。蓝图坐标保留原单位，运行时统一映射。
本稿覆盖 L07–L12 与 BO02，保留已有房间 ID 和名字。本轮交付设计图及人工坐标，尚未替换游戏内的随机摆放或实现细化技能。坐标源为同目录的 `B02.json`：场地统一 2800×1800，左上为原点，X 向右、Y 向下；主路线、侧路、幼巢、怪群、信标与道具位置均固定。

采用明亮手绘卡通奇幻、高机位三分之四斜俯视、近等距和 2.5D 体积。低对比暖琥珀地面配嫩绿叶片、亮紫翼膜、奶油蜂蜡、青玉复眼。虫族有集市、码头、育幼礼仪、观测、通风与织叶工艺；不能只把构装绞盘、工业矿箱换成黄色。七房各有独立地标与路线，树脂蜜渠、虫窟与浮巢只在外围形成景深，中央是连续硬地，没有大矩形水坑和拉伸贴图墙。

每房 15 件道具，12 种类型；含生活、运输、工艺、仪式和植物细节。每房只有四件小道具设实心碰撞，尺寸最大 118×70，均远离主路及中央开阔区。非碰撞装饰可放宽体积，但不得伪装成必须绕行的长墙。空置育幼叶座属于装饰，与可击破的战斗幼巢使用不同轮廓。

每房三个怪群区域、三个固定信标位置。难度改变固定区域里的敌人组合、数量、属性和掉落品质，不改变地形、物件、宝匣、目标或路线。信标位置固定且靠近自动触发；随机仅发生在信标功能，设计图的统一信标符号不预定回血或增益类型。

琥珀虫后的三招按身体来源设计：**琥珀弹雨**由鼓起的囊腹施放，提前 0.9 秒显示三个圆形落点；**王翼号令**由收拢的透光双翼施放，提前 0.8 秒显示 110° 扇形；**育巢共鸣**由发亮的花冠连接三幼巢，提前 1.2 秒显示目标与连线，破巢阻止有限孵化并暴露弱点。酸区限时消退，扑翼有收势，破巢提供连招窗口；避免全屏闪烁与强制震屏。

装备按虫族部件表现：翼膜、露珠、甲壳、蜜囊、酸晶、王冠，而非统一小方块图标。遗物用分叉树脂脉、复眼航标、空茧回声、花井归流、旧颚、分蜜花芯、女王花冠串联七房故事。白、绿、紫、金品质及未来八槽内容均为后续实现设计，本稿不宣称已有相应装备实例或系统。

美术总览板 `art/B02_concepts.png` 用于确认绘制语言、地标造型和虫族文明元素；精确坐标、路线及碰撞以布局图和 `B02.json` 为准。总览中的七幅是独立场景，不是把一张大地图裁成七块。

边缘同样属于设计范围。硬地依次过渡到蜂蜡碎格、小石、花粉草带、弧形蜂蜡阶沿与外围叶根/琥珀崖景；场外继续绘制暖色蜂谷，不能留下灰色空白或方形地面截断。北侧用蜂蜡屋檐、蜕壳廊、观测亭或育巢冠座区分房型；东侧以叶翅拱门连接出口，南侧以码头、茧枝、编叶栏或花圃自然收边，西侧叶根坡道接入口。巨叶和近景空茧仅出现在画面下角，遮挡角色或技能预警时淡化。各房边缘差异已存入 `edge_variant`，四向与层次规范已存入 `edge_design`。
