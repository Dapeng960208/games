## 1. 统一风格与种族差异

整体采用**明亮手绘卡通奇幻风、高机位三分之四斜俯视、近等距构图、2.5D 立体质感**。统一镜头尺度、角色比例、描边和空间可读性，不要求八个种族使用相同建筑、材质或光照环境。

种族差异必须来自所处环境、生态、生活方式与建造方式，并体现为建筑轮廓、材质、地表、植被、地标和地图机制。不能仅替换颜色、城堡尖塔或旗帜来区分种族。每关一张独立设计稿；此前八宫格只作方向总览，不代替这八张单关稿。

本批原图均为 **1122 × 1402 像素、RGB、PNG**。这是竖版世界观/场景设定板，包含环境主画面、种族造型示意和场景细节；不是原生 2K 游戏背景，不是运行截图，也不是已经通过可走区域验收的房间蓝图。
