# B11 虹伞菌谷 · 菌灵族

> 设计提案，未实装。基于PR #4 `927332a`；仅Markdown。基础档案、成长、装备资格、品质和结算见[总则](NEXT_EIGHT_CLASS_GEAR_INDEX.md)。18种普通怪、1名Boss、4套八槽装备、3件共有散件。

## 1. 等级与挑战定位

B10通关后开放；敌人Lv51/53/55，Boss Lv55；装备iLv随区段、首领上沿55。章HP/攻击因子2.20/1.80。本关在已有移动和持续伤害管理之上加入“切断传播路径”：先处理哪一处菌结，比单纯清理最近敌人更重要。

与B05的根网护盾不同，本族核心是**共享蓄能和有界延迟连锁**，不是再做一遍树木回血。桃红、紫罗兰、黄绿巨菇、透光孢子和暖阳菌阶保持清洁明亮；轮廓突出伞盖、菌褶和细菌丝足，不画成植灵枝叶换色。

## 2. 独特地图与种族机制

**菌丝蓄能网**：一个固定菌结最多连接3名普通怪，范围240；连接怪每成功提交一次主动给菌结1点蓄能，上限3。满3点后先显示1.2秒预警，再在菌结半径90内爆出0.5a孢波，a取本区普通F档攻击。爆后蓄能归零、CD8秒。切断菌结清空能量并断网8秒；菌结HP为本区F档50%，任何职业可攻击。

**有界连锁**：地图上明确画出相连孢囊。玩家击破带箭头标记的引爆囊后，沿预画连线最多传播2跳，每跳间隔≥0.8秒，每次半径80、0.45a，可伤双方。派生爆炸不能生成第三跳，也不能重新启动已经结算的囊。普通奖励只按实际怪物死亡一次结算；菌结、孢囊和技能派生物不给额外装备/经验。

**跳跃菇**：固定起点、固定落点、F交互0.6秒，0.5秒自动转移；启动受击可取消。完整弧线与落点提前可见，落点至少有半径100稳定平台。不是新增跳跃按键、精确平台跳跃或无限闪避；腾空不清除既有负面状态。启动后不新生成以落点为中心的追踪攻击，已经预告的危险照常结算。全部关键机关都有步行后备路线。

**普通孢蚀**：最多1层，0.10a/秒持续3秒，刷新不叠加。只有逐怪表明确技能附带；不因“菌族”让所有攻击自动上毒。各孢囊用形状/图标区分传播、蓄爆和修补，危险色沿现有规则，不把紫色一会当治疗一会当伤害。

蓝图2800×1800按0.58映射，坐标为百分比；地标与菌结固定。主要路线宽180世界像素以上，同时激活的传播链不超过2条，不能覆盖全部步行路线与跳菇落点。

## 4. Boss：万伞菌母

Lv55；原始HP1600/攻击36/速度64/护甲14/魔抗14。D0设计HP47520、攻击875。核心在主伞下的发光菌柄，次伞是可视攻击器官，不各自生成Boss生命条。

P1 100–70%仅两个菌结；P2 70–35%三结但最多两条有效传播线；P3 35–0%切换传播方向，方向必须提前1.5秒公布。菌母每8秒可从一个连接菌结取一次8%HP临时盾4秒，取高不叠、不是治疗。8秒内击断两个不同菌结使其停取盾并露出主柄5秒、承伤+15%，触发CD14秒。也能直接破盾打本体，不要求特定套装或跳菇路径。
