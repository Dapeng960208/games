# B05 根网：JSON坐标往返精度修复

2026-10-02。此变更不开放B05，不改变碰撞、多边形、护盾数值或奖励规则。

## 问题与修复

蓝图位置经0.58缩放成为Vector2浮点坐标后，JSON序列化可能舍去末尾约10^-12世界像素的小数。原恢复校验用逐位相等比较，导致合法存档也被拒绝。

x/y校验现允许至多0.000001世界像素的序列化尾差。恢复始终保留原配置坐标，并不从快照复制坐标；HP上限仍要求精确相等，所有HP、冷却、网络锁与水闸一致性约束保留。0.001像素的非序列化坐标修改仍被原子拒绝，失败前后状态不变。

## 验证

官方Godot4.7.2，以无生产autoload的隔离项目运行 `python3 tools/test_b05_root_network.py --suite root_network`：67项、0失败，无SCRIPT ERROR/ERROR。新增真实Vector2生产坐标的JSON往返及异常坐标拒绝测试；原跨井冷却、毁井、永久水闸、剩余时钟和坏快照检查继续通过。没有运行自然平衡矩阵。
