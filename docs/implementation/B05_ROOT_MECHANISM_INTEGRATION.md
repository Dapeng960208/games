## 明确实施补充

原正文规定半径220、最大HP12%护盾、每单位跨井12秒刷新限频、取高不叠加，但未给盾本身寿命。首轮实现统一为12秒；离网停止刷新，已获得的盾保留到到期或耗尽；毁井后未提交增益取消。后续试玩验收可调整该单一常量。护盾持续时间与限频分别保存剩余秒数，读档不重新发一份满寿命盾。

生产根井继承MineEnemy静态目标，使用同一合法伤害、免疫、护盾、抗性与整数结算路径。只有实际结算后的hp_damage回执更新根网。目标不运行敌人AI，不发击杀经验/金币/装备，也不占普通遭遇预算；毁坏图留在原位置。关闸保留完好的断网图，HP耗尽才切换毁坏图。四张原生1254²状态图统一128×128世界画布及(0.5,0.70)脚点，不按每帧透明边界重新居中；该显示尺寸仍待更多相机状态审查。

## 保存精度修正

生产蓝图点先经0.58及Vector2 float32映射，再JSON小数序列化。末位十进制尾差曾让合法根井位置在恢复校验时被拒绝。根网对x/y允许≤0.000001世界像素的序列化误差，但仍使用原冻结位置，绝不从档案覆盖坐标；HP上限仍精确相等。大于该范围的位置修改继续原子拒绝。
