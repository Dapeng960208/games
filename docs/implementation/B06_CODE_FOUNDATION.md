## 普通怪、技能、难度与成长

每房首现三种；L31/32固定Lv26，L33/34固定Lv28，L35/36固定Lv30；后区复用早期种类也按所在区解析。所有18种的D0条目均存在，不借D2/D4补足数量。L36三波明确保留；其他房间波次组成未指定，不编造数量。

JSON逐条保留当前中文技能与反制原文，并分离D0/D2/D4可机读参数。普通主动CD在真实提交释放后开始，打断50%CD；一次技能同目标一次命中，明确连发/持续例外。支援不能给首领治疗或护盾，派生物计共享预算、不另掉装备/经验。并发仍为区6、房18，D3精英替换重装，D4不同伤害锁定错开至少0.8秒；这些目前是合同，尚无B06战斗调度。

所有未写数值保留于 `unresolved_parameters`，例如M06蟹雷HP、M13技能CD最小剩余值、M17 D2反向环伤害与低于D4的间隔、首领护航CD/预警、具体技能形状。它们不填成0伤害、不从旧稿补入、不偷偷新增高难度技能。正式攻击实施前须集中制定并说明这些参数。

### 冻结解析公式（版本1）

重用B05已验证的现有职业类型/等级解析公式，B06只改变允许等级、章因子与首领原始值。基础档案F/R/C/S/A/T完全取总则，不以表格原始值当×10后的面板。等级技能阶保持现有第四阶上限，不自创第五/第六阶。

- HP：round(原始HP × 类型HP比 × [1+0.055×(L−1)] ×1.35×10×1.60×D生命比×精英比)
- 攻击：round(min(16.90,max(类型最低攻击,原始攻击×类型攻击比)) ×[1+0.025×(L−1)]×1.35×10×1.40×D攻击比×精英比)
- 护甲：round((min(24,原始护甲×类型护甲比+类型护甲平值+3×类型每阶护甲)+2D)×10)
- 魔抗：round((min(32,原始魔抗+3×类型每阶魔抗+精英4)+2D)×10)
- 速度：min(132,原始速度×类型速度比×[1+0.006×(L−1)])×(1+0.04D)
- 收势：max(0.45,原始收势×max(1,类型收势比−0.005×(L−1))/(1+0.035D))
- 普通技能伤害：round(已解析攻击×招式系数×1.25×普通技能D倍率)
- 首领HP/攻击：round(原始值×1.35×10×对应章因子×对应D倍率)，不再套普通等级成长
- 首领双抗：(9+2D)×10；速度54×(1+0.045D)
- 首领技能：round(已解析攻击×招式系数×首领技能D倍率×阶段倍率[1,1.10,1.20])

HP/攻击使用有理数连乘后只舍入一次；校准系数仍为1。序列化后整数战斗值严格校验；仅移速/收势允许与Godot自身紧凑JSON十进制表示完全相同，避免浮点末位变化被误判为档案篡改，不采用宽泛误差阈值。精英HP1.20、攻击1.12；D生命[1,1.4,2,2.8,4]，攻击[1,1.2,1.5,1.85,2.3]，普通技能[1,1.05,1.10,1.15,1.20]，首领技能[1,1.06,1.12,1.20,1.30]。完整类型系数在模块常量 `ROLES`，类型F/R与既有游击数值身份相同，不增加新的类型加成。

黄金样本：Lv26 D0 M01 HP4001/攻击399/护甲130/魔抗80；其1.1a技能包549。D0首领HP23760/攻击491/双抗90；1.1a参考包540，P3为648。D4首领双抗170。样本不证明自然TTK、强度、掉落时长或前章装备可通关。

## 潮相、排水、位移与保存

固定8秒退潮→2秒预告→6秒高潮，L31首轮退潮12秒。调用只接受活动战斗模拟时间，不补算离线/暂停时长；所有跨界事件有序返回，预告不因较大一帧或恢复档案消失。时间用整数微秒和小数余量，防止60帧累加漂移。单次advance≤60秒是防止无界事件数组的API边界，超限原子拒绝，不是改潮周期。

排水：开始后0.6秒完成，所连一区干地8秒，从完成时开始16秒CD；取消不耗CD、不发完成事件。未来适配器须在受击/离开交互范围/死亡/切房时取消。这个“完成时启动CD”的明确实现口径延续交互提交习惯。同一时刻排水完成与高潮到来时，先排水后发高潮事件，避免干地对象错误获盾。

高潮指定区玩家移速0.85，海族1.12。地形减速减免按幅度计算、上限50%，因此U01的20%减免给0.88而非完全免疫。地形区外或排水期间无潮盾。实际进入本轮高水的合法普通海族获10%最大HP盾6秒，同一演员跨区不能重复领取，至少12秒间隔；返回值覆盖同来源较高盾而非相加。不允许BO06或B05演员走普通海族潮盾API。B06-M18延长盾等个体技能尚待战斗适配。

每演员第二次强制位移在2秒内距离为0，装备减免合计≤50%。裁剪函数接受已按角色半径内缩的可走多边形，先遇到的边界立即截停，不能因终点重新进入凹形地图而穿过中间空洞。该函数不是物理移动，未来适配器还须处理实际掩体/碰撞体。

BO06 P1无活动潮钟；进入P2启动完整退潮→预告→高潮；P3保留相位，不开第二周期。高潮结束发2.5秒完整输出窗口意图；尚无首领调度器来实际阻止这一窗口的攻击。

JSON快照保存房间、区/闸映射、模拟时钟、首领阶段、部分交互、排水/CD、潮盾已领取周期与推移保护；恢复必须与已配置房间及映射完全匹配，所有数值有限、整数微秒有界，失败不部分改写。保存纯值、不存节点。测试仅用`/tmp`隔离项目与XDG，不读写真实试玩档rev158。生产存档尚不接受这个快照。
