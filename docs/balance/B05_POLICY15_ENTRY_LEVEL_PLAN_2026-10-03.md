# B05 archive15最低入场等级验收计划

用户最新协议要求不同关卡全部按最低入场等级测试。B05的新正式样本统一角色Lv21、装备ilvl≤21、合法20点天赋和实际解锁技能；旧Lv25仅保留历史诊断，不用于过验。只有B01前三难度允许裸装通关；B05裸装D0–D4均不应通过完整关卡，不要求首房死亡或固定秒数。

## 夹具

- 正式角色三职Lv21，class6 G2/P5，物品等级21；词缀合法池、同分位、实际强化实例，经生产can_equip验证。
- 20点选择：mastery6/precision6/dexterity6，战/枪agility2，法vitality2。此为明确测试选择，不称用户指定最优构筑。
- 默认矩阵和runner使用--hero-level=21，fixture案例增加entry21身份；旧Lv25须显式--hero-level=25。
- 法师零普攻旧冻结词缀与resource_cooldown有效词缀分开清单，禁止用弱效尾词缀掩盖输出。
- 实际技能定义由生产player.skill_definition读取，真实profile经验和解锁校验；不直接授予超等级技能。

## 次序与证据边界

1. 等archive15全局暴击/AP/定位/AI源冻结，parse及只读冻结27构筑（旧/有效词缀分开），核级别、物品、天赋、费用假设与来源。
2. 三職Lv21空八槽D0自然连续整章；随后D1–D4分短批。保留原生HP/资源/技能/闪避、升级及遗物跳过回血；每房记录入口与结束等级。无购买、不强制受击。
3. 三職Lv21 class6 G2/P5普通精英D0/D4，具名敌人实际HP/AP/AD/双防/暴击和攻速/移速记录。
4. Boss D4三职G2含法师有效尾词缀对照，目标60–90秒，剩HP只记录。普通/精英不用此时长目标。
5. 单seed先诊断，失败候选不扩十seed矩阵。源变动、超时、导航阻塞不伪称平衡通过或裸装无法通关。

目前仅准备，尚无archive15实际结果。模型、装备与AI代码由各生产负责人负责，测试不得覆盖生产修复。

## 全局暴击的新授权差异

archive15同时更改玩家暴击基底为25%/2倍、最终上限为100%/3倍，法师所有伤害技能也使用该规则。因此不再断言新旧角色属性“仅sha不同”。核对装备实例与合法等级/天赋，允许授权暴击项变化，其余属性在Lv21重新解析并列出差异。

最终战斗验收必须读取Game.start_run之后RunState snapshot15转换得到的run_ref.stats，并核对实际最终暴击值/上限及真实暴击伤害包；夹具StatResolver预解析值只能用作输入审计，不能代替生产运行态。等待全局crit实链冻结后补断言。
