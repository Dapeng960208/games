# S11 B04基准配装冲突复核

状态：用户已暂停S11测试。原基准条件来源缺失已确认，腐蚀六加二候选完成30场，但未采用且不算平衡验收通过。见 [S11暂缓与已知问题](S11_DEFERRED_ISSUES_2026-10-01.md)。

## 证据与用户目标

主方案第10节要求“6件核心套+2件补强”，并稳定执行职业与套装循环。章节标尺表却指定B04战士S07八件，枪手/法师为S07六件＋S03武器/戒指。S07只有2/4/6件阈值，无8件加成。

实际`equipment_effects.gd`中S07的2、4、6件均要求目标带寒冷或腐蚀；CH01的Q/W/E/R没有施加这两种状态，S07八件也没有相应来源。外部遗物/预挂状态被受控协议禁止，因此原战士基准无法启动这些套装条件。独立代码复核确认这一点。校正私有AI种子后的1001先导场，战士没有装备ICD触发，而带EQ05的远程配置启动了S07循环；单种子仍不能决定最终TTK/HP。

## 最小候选与不变条件

在查看候选TTK之前，按职业定位选择战士的同目标腐蚀进攻路线：S07六件＋S04的EQ06武器、EQ104戒指。EQ06连续三次确认命中同一目标，通过正式状态接收链施加腐蚀及重伤；S04两件提供对腐蚀目标的既有伤害收益，S07六件阈值完整保留，同时使EQ39攻速、EQ59条件暴击具备来源。战士已有RL02腐蚀遗物身份也支持这条搭配，但该遗物仍不进入受控基准。

另一候选是照用远程的EQ05/EQ102寒冷控制路线，其S03两件延长寒冷并支持EQ29护盾、EQ49暴击。选择腐蚀不是因为它某次TTK较好：选择在候选实战之前作出，依据近战同目标输出定位。腐蚀路线牺牲上述寒冷单件收益；EQ19要求腐蚀与寒冷同时存在，两条路线都不能独立启动它。不能称每条装备特性都已协同。

不新增8件效果，不让Boss读取职业/装备进行适配，不给战斗预挂状态，不改品质、k/u/g、天赋、技能分支、操作策略或验收门槛。原八件配置的十种子诊断保留：G2中位45.72秒，P5为53.21秒（+16.4%），低分位48.51秒，三个样本各10/10通关，原战士组在系数1下已满足该组门槛。套装不工作是独立设计缺口，不能伪称原结果失败或删除它。

候选30场全部通关，EQ06、EQ39、EQ59、S07_4、S07_6在每场均真实触发。G2/P5/低分位TTK中位为41.85/45.19/47.80秒，P5仅慢7.99%、HP仅低7.68个百分点，品质差距未达标。因此保留为未采用的实验结果，正式夹具仍是原八S07；没有混合两种构筑的统计或更改敌方参数。
