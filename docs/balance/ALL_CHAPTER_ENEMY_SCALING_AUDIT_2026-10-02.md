# B01–B06 敌人曲线只读审计（2026-10-02）

## 结论与范围

- 实际调用生产 resolver、encounter_plan 与 DamageResolver；720条普通/精英端点属性、12条Boss、8784条职业/配装静态预算。只新增审计文档，没有改生产参数、启动自然大矩阵或访问远端。
- B01–04是正式运行章节；B05–06是隔离 candidate。B01–04每一普通房内均是章内三级区，B05–06才是逐房升档。因此“入口/尾级”指章节最低/最高等级，并非B01–04首房只刷最低等级。
- 没发现全章漏套等级、错用Lv1或难度/精英倍率失效。普通怪HP和攻击持续成长；原始数字上升本身不代表平衡通过。
- 确认BO04→BO05耐久断层：D4 HP138067→79920（-42.1%），护甲340→160、魔抗300→160；BO06 HP95040/170/170仍低于BO04。攻击上升不抵消耐久下降。
- 不支持“所有关卡普通怪都因角色裸成长过快而普遍弱化”的推论。D4裸无天赋单怪净伤压力和普攻击杀次数未普遍下降；装备后受击压力明显降低。B01–04是否裸通尚无本审计的自然证据。

## 等级、精英、双防和技能系数

- 章内等级：B01[1,3,5]，B02[6,8,10]，B03[11,13,15]，B04[16,18,20]；B05房L25–30为21/21/23/23/25/25；B06房L31–36为26/26/28/28/30/30。
- 普通/精英基础HP线性每级+5.5%，基础攻击每级+2.5%；叠加章节HP每章+12%、攻击+8%（相对Lv1/章1基线），并非复利。攻击角色模板基础上限16.9发生在等级成长之前，不是最终攻击被锁16.9。
- 精英HP×1.20、攻击×1.12、魔抗+40（达到上限例外），没有额外护甲倍率。D4 HP×4、攻击×2.3；普通双防各+80，B01–04 Boss各+120，但B05/06 Boss仅+80。
- 普通技能档系数1/1.08/1.16/1.25，D4再×1.2，故高等级系数1包=攻击×1.5；Boss D4阶段1/2/3为攻击×1.3/1.43/1.56。技能自身倍率/多段/区域tick另计。
- 普通双防在机制tier4(Lv15)后不再随等级上涨；B05/06明确继承tier4且cap24/32（十倍后240/320），并非Lv20后意外停级。仅提升生命无法纠正防御与职业穿透、装备收益的关系。
- 伤害双防分母1000。CSV是真实Resolver结果而非直接HP÷攻击；战士被动8%盾及E12%盾金额单列但没有把可重复刷新盾简单叠到HP。命中频率和盾覆盖率须动态观察。

## 最小统一曲线候选（建议，未应用）

1. 先修Boss耐久连续性，不全章普通怪一刀切。保留章节HP因子1+.12×(章−1)，以后续Boss raw HP不得低于BO04的1880作为统一参考底线；双防底线沿用22/18、Boss难度增量统一为+3/档。
2. 得到候选BO05 D0 HP37562、护甲220/MR180；D4 HP150250、340/300。BO06 D0 HP40608、220/180；D4 HP162432、340/300。保持原攻击、技能倍率、机制和时序，便于归因。这是恢复旧章增长结构的参考下限，不是承诺能达到目标TTK。
3. 再以同级裸装H、合法装备H/穿透/资源与命中窗口校验统一曲线；不能为旧法师低效词缀单独抬物防或补魔抗。已知B06法师合法四词缀调整可从35.833降至24.017秒，这个观察由自然验证任务提供，不计为本审计新增跑测。
4. 普通怪按角色模板保留脆弱/坦克差异，后续用实际受击率、可用技能循环、护盾刷新及并发预算判定是否提升数值。静态表不能证明每怪都会打中，也不能把能力冷却当成普攻间隔。
