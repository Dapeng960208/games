## 2. 现状问题与主流玩法调研

目前等级成长由运行代码硬编码：20级相对1级，攻击仅+10%，生命和法强仅+20%，双抗各+6。数据文件的成长声明不是实际运行公式。装备为固定属性、最多+5，部分属性受装备贡献上限截断；同模板重复装备会折算金币，没有独立随机实例。裤子、戒指现在只有界面入口，未贯通属性与存档。

## 5. 全部属性的随机比例和成长公式

### 5.1 主属性

令装备等级i、强化N、槽位基值b、模板系数T、品质倍率Q。每条主属性独立抽整数 `k∈[0,100]`，共101档；`R=0.85+0.003k`。新实例保存k，后续展示按同一个值计算。

固定数值主属性：`V=b×T×[1+0.05(i−1)]×Q×R×(1+0.10N)`。

鞋子移速主属性：`V=0.03×T×Q×R`，不乘装备等级和强化。装备等级影响固定数值，不扩大百分比词条；强化提升原来滚出的主属性，+5是初始主属性的1.5倍，+10是2倍，不能逐次乘1.1。

| 槽 | 物理型基值 | 法术型基值 |
| --- | --- | --- |
| 武器 | 攻击9 | 法强14 |
| 头 | 生命16、护甲4、魔抗4 | 同左 |
| 胸 | 生命32、护甲8、魔抗8 | 同左 |
| 手 | 攻击3 | 法强4 |
| 裤 | 生命24、护甲6、魔抗6 | 同左 |
| 鞋 | 生命12、移速3% | 同左 |
| 戒 | 攻击3 | 法强4 |
| 饰 | 攻击4 | 法强6 |

例：Lv20紫色+5物理武器，主攻击=`9×1.95×1.25×R×1.5`，范围27.9703–37.8422，中点32.9063。Lv20金色掉落+2为25.0614–33.9066；之后锻造到+10为41.769–56.511。金色低强化装与紫色高强化装存在比较价值。

所有124模板的五档区间已逐件写入目标数值表。计算保留浮点原值；生命在最终面板展示时取整，不逐件整数舍入，以免同件属性区间的档位被过早合并。

### 5.2 普通随机词条

21种词条的全部槽位、类型、基准与Lv20各品质范围见目标全表。对一种词条，随机整数 `u∈[0,100]`，值在[min,max]线性取档：

- 平值词条：`Q×[1+0.05(i−1)]×[min+(max−min)u/100]`。
- 百分比词条：`Q×[min+(max−min)u/100]`。
- 两类均不乘强化N；精炼可增加分位u。

先按槽位、实例类型过滤词条池；攻击/物穿只给物理型，法强/法穿/法力只给法术型。每次无放回抽一个类型，同件不重复类型。当前模板的原属性键权重2，其余合法键权重1；一次抽选概率=`该键权重/剩余合法键权重之和`。2:1是抽选权重，不是最终保底概率。倾向键如果在该槽不合法，不加入池；新增裤子倾向生命/护甲/魔抗，戒指倾向增伤/暴率。

例如Lv20金装攻击词条为5.46–10.92，暴率词条1.4–4.2个百分点；暴伤增量7–21个百分点；冷却词条1.4–4.2个百分点。按8槽完整配装计算上限，不把单件区间当最终总收益。

### 5.3 生成、购买与重试

抽样顺序固定为：来源合法池 → 品质 → 愿望部位/其它部位 → 该部位模板 → 装备等级 → 自带强化 → 主属性各k → 普通词条各类型/u。每一次新获取生成独立实例；同模板不同获取不复用字典或随机结果。

战斗与掉落使用不同随机流。奖励、购买和打造以唯一事件/交易ID生成并持久化结果；失败重试、重新打开面板或重复点击重用同一次结果。购买前显示可能范围，扣款和实例入库作为一次提交；已生成的购买结果在待确认交易中展示。不同交易可以得到相同模板和不同属性，不能通过免费刷新同一交易结果挑选属性。

随机性意味着属性通常不同，不保证任意两件装备的全部离散档位必然不同；保证的是独立实例、独立合法抽样和可复现交易。

### 6.3 极限首领金装保底

仅D4首领成功撤离累计，按种族独立保存。连续3次成功首领撤离没有带回金装，则第4次首领奖励把其中1件变为金装，数量不增加；金装仍最高+2。该次旅途中任意金装成功带回就清空对应计数。死亡不增加、不清空；其它难度不增加、不清空。

出发时冻结计数和奖励种子，奖励显示到撤离时使用同一结果。撤离事务一次更新计数和入库；未带回的金装不会清空永久计数。

## 7. 商店、锻造、重铸、精炼、继承与回收

商店销售白/绿品质，不能直接买紫/金。每次购买选择已解锁模板、物理/法术类型、装备等级i≤角色L，生成新随机实例；同模板可以再次购买。白价=`ceil(旧模板基价×0.8×S)`，绿价=`ceil(旧基价×1.2×S)`，`S=1+0.03(i−1)`。已有整套补齐功能保留九折：对明确选中的缺件总价向上取整90%，每件仍独立随机，不按模板所有权禁止重复单买。

新增裤子/戒指的价格、来源和解锁规则见第4节；整套补齐按8槽缺件计算，购买前列出模板、品质、类型、装备等级和可能范围。

### 7.2 重铸、精炼与继承

| 系统 | 明确规则 | 基础成本 |
| --- | --- | --- |
| 重铸 | 每件可选择并永久绑定一个可重铸的普通词条槽；选择该槽的新合法类型，不能与其它槽重复，再随机u；旧/新结果二选一，结果提交前重试不重抽 | 50金、4锻材、2族材；金币乘S |
| 精炼 | 选现有普通词条，`u=min(100,u+10)`，不换类型；不调整主属性k、固定机制、装备等级或品质 | 80金、6锻材、2族材；金币乘S |

继承补差=`max(0,C(target_i,N)−C(source_i,N))`，其中C是按该装备等级逐级ceil的强化金币总和。基础继承100金不乘S。例：ilvl1的+10转到ilvl20，补差1430，继承共1530金+8锻材；加上先前2500，合计4030，比直接强化3930多100。材料费用不按装备等级变化，不补材料差。低等级新装备、预强化金装和高品质装备都按这一规则，不能通过低等级强化规避金币。

精炼前先显示实际配装收益；如果相关属性已经达到总上限、当前配装精炼不会提升有效值，则该配装中的精炼拒绝扣款并说明。满u不能再精炼。未装备实例可以精炼，但必须同时显示当前配装比较。满级仍可收藏另一套用途的高分位装备。

### 8.2 H、X、暴击与一次直接伤害

三种基值必须分开。法师普攻在新方案明确增加0.35AP，以便法强武器提升普攻；这是一项提案改动，现状是仅AD。

| 来源 | 新H口径 | 与当前差异 |
| --- | --- | --- |
| 战士/枪手普攻、直接技能 | AD | 无 |
| 法师普攻 | `AD+0.35AP`，初始27.8 | 当前为AD=18 |
| 法师技能、法晶、领域 | `AD+0.7AP`，初始37.6 | 无 |
| 法师职业遗物 | AP，初始28 | 无 |
| 装备派生 | 保存的`X×系数`；状态用本次事件H | 不把X替换为暴击后的扣血 |

`X=本次技能/普攻系数×对应H`，在职业追加、增伤、暴击和连击前保存。职业固定追加P按现状条件生成，例如两发校准0.65H、猎印1.25H。对真正手动普攻/直接技能的攻击root，抽一次暴击，所有本次直接包共享；当前只有普攻抽暴击，新方案把手动直接技能纳入。

直接基础金额：`(X+P)×[1+min(1.00,B_raw)]×C×K`，`B_raw=静态+临时+条件直接增伤+目标已腐蚀时的(0.08+有效腐蚀专属加成)`。腐蚀增益加入一次B，不另乘`1+腐蚀增益`；本击刚施加的腐蚀不追溯增强同击。C为暴击倍率或1；连击K=`1+0.005n`，n≤100，最高1.5，4秒断连。法晶自动攻击、领域跳伤、DOT、装备派生、遗物派生不独立抽暴击，也不拿本次直接包的暴击/连击再乘一次。

灼烧施加时保存`burn_snapshot=来源power×(1+有效灼烧专属加成)`，每秒`0.12×burn_snapshot`魔法伤害；来源power通常是本次H，不追加暴击或直接增伤B。流血、腐蚀DOT同样保留来源power，不额外吃直接增伤桶。

随后按实际受击路径：Boss弱点1.35 → 敌人辅助盾吸收（真伤跳过）→ 对应双抗/穿透/通用减伤 → 普通怪机关弱点1.35 → CombatStatus盾 → HP。同一个Boss弱点只乘一次，不再乘普通怪机关弱点。`伤害后=输入×100/[100+max(0,防御−穿透)]×(1−通用DR)`；腐蚀有效护甲×0.85，不减魔抗。真实伤害跳过防御、通用DR与辅助盾，但仍受无敌和CombatStatus盾约束。

真实附伤按原始有效命中的“root+目标”最多一次，技能多段不能对同目标重复注入；派生、DOT、感电追加不递归注入真实附伤。装备派生使用saved X，所有目标装备伤害派生总额≤1.2X；每root的4包预算由原生状态、职业遗物及装备packet=true命令共享（包含状态、伤害、护盾、治疗等），原生状态/遗物先预留，纯Buff的packet=false事件不占包。遗物不计1.2X金额但占包数。执行顺序按现状固定，预算不足只接受剩余额，面板/伤害日志标明被限流的来源。

### 8.5 同时修正的现状结算偏差

重构实施时，原生状态、装备after_hit、职业消耗、旧感电消费统一以“真实HP或合法护盾产生正损失”的confirmed结果为门槛；免疫、零伤、无效目标不消耗猎印/感电、不触发收益链。每次原始动作只按root计数，多目标/穿透/多发不会多次累加职业被动。

`enemy.apply_status`必须透传真实接受结果，拒绝弱值状态不当成功，不因此进入插座/效果ICD。发射计数遗物RL03保留其明示发射机制，与有效命中被动分开；显示文案改为实际W/R。旧C/V回路是未开放残留API，完整登记但不计入当前或新成长收益。
