## 4. 装备模板、实例、品质与八槽

模板定义身份；实例定义这一次获得的属性。每件至少保存：`instance_id / template_id / ruleset_version / source_event_id / item_level / rarity / power_type / main_rolls / affix_type_and_quantile / enhancement_rank / enhancement_steps(g,pity,base_price_peak) / enhancement_reroll_history / reforge_slot / enhancement_gold_ledger / material_ledger / location / lock_state`。

同一模板可以无限次独立获取；背包空间不足时放入撤离待领取仓储，不能自动转金币或覆盖旧实例。操作均以实例ID进行。模板可以在同一批奖励中重复抽到；抽到相同模板不减少后续候选池。

新增裤子、戒指两个真实槽位；14套各新增一件裤子和戒指，共28件，EQ97–EQ124按S01–S14顺序分配，先裤后戒。总模板124件。新增件无额外固定触发特性；主属性、普通词条和套装计数照常生效。每套8件仍只设置2/4/6件阈值，允许6+2、4+4及其它混搭。

原96件保留名称、ID、种族、Boss解锁门槛、价格基准与固定机制。原静态属性不再叠加到新主属性上，而是作为随机词条的倾向标签。12件通用非套装模板主属性基准乘0.75；84件套装与新增28件系数1。新裤子价格基准沿同套胸甲，戒指沿同套饰品；其种族与购买解锁沿同套。

物理型适配战士/枪手，法术型适配法师。武器、手套、戒指、饰品用对应AD或AP主属性；防具主属性共用。掉落按出发职业生成类型，商店/打造明确选择类型；切换穿戴职业不重抽或改变已保存的类型。

| 品质 | 平值倍率Q | 百分比倍率Qp | 普通随机词条数 | 获取位置 |
| --- | --- | --- | --- | --- |
| 白 | 1.00 | 1.00 | 0 | 初期掉落、商店 |
| 绿 | 1.20 | 1.10 | 2 | 商店、掉落、定向打造 |

按最新等效关系校准金平值倍率为1.875。同等级、同强化增幅向量，金装平值中点为白1.875倍；最低金主roll对最高白主roll仍高约38.6%。即使+10两件连强化增幅也分别取最差/最好，最低金仍比最高白高约13.4%，另多4条词条。百分比沿用品质系数，不随金平值倍率或×10放大。

比较“约等于”时固定同槽位、同装备等级、同模板系数、同主roll，且每阶g=10%的参考向量，仅比较平值主属性：白+5为1.50、绿+3为1.56，差4%；绿+5与紫+2均1.80；紫+5与金+2均2.25。随机roll/g、词条数量、百分比和固定特性会令实际总收益不同；金+2是玩家锻造结果，不能掉落。

品质只决定倍率与词条数量，不自动追加一种未登记的传奇效果。固定特性属于模板，与普通随机词条数量分开；固定特性的系数、持续时间、ICD不随机。

## 5. 全部属性的随机比例和成长公式

### 5.1 主属性

令装备等级i、强化N、槽位基值b、模板系数T、品质倍率Q。b已是下表×10后的平值，不能再乘10。每条主属性独立抽整数 `k∈[0,100]`，共101档；`R=0.85+0.003k`。每阶独立g∈8/9/10/11/12个百分点，概率10/20/40/20/10%；同阶g共享该件全部平值主属性。`E=1+Σg/100`，内部g存整数百分点或基点，不能把其当倍率连乘。`I(x)=floor(max(0,x)+0.5)`；保存k和整条g向量，完整表达式后仅取整一次。

固定数值主属性：`V=I(b×T×[1+0.05(i−1)]×Q×R×E)`。

鞋子移速主属性：`V=0.03×T×Qp×R`，不乘装备等级和强化，也不×10。装备等级影响平值，不扩大百分比词条；强化根据原k与g向量重算。+5倍率1.4–1.6、初次强化期望1.5；+10倍率1.8–2.2、期望2.0。改善后的重锻分布高于初次期望，不能仍说固定1.5/2倍。不能用已取整属性逐次乘1.1。

| 槽 | 物理型基值 | 法术型基值 |

### 5.2 普通随机词条

21种词条的全部槽位、类型、基准与Lv20各品质范围见目标全表。对一种词条，随机整数 `u∈[0,100]`，值在[min,max]线性取档：

- 平值词条：`I(Q×[1+0.05(i−1)]×[min+(max−min)u/100])`，min/max已×10。
- 百分比词条：`Qp×[min+(max−min)u/100]`，不×10，不取整成百分点整数。
- 两类均不乘强化N；精炼可增加分位u。

先按槽位、实例类型过滤词条池；攻击/物穿只给物理型，法强/法穿/法力只给法术型。每次无放回抽一个类型，同件不重复类型。当前模板的原属性键权重2，其余合法键权重1；一次抽选概率=`该键权重/剩余合法键权重之和`。2:1是抽选权重，不是最终保底概率。倾向键如果在该槽不合法，不加入池；新增裤子倾向生命/护甲/魔抗，戒指倾向增伤/暴率。

例如Lv20金装攻击词条73–146；暴率仍1.4–4.2个百分点、暴伤增量仍7–21个百分点、冷却仍1.4–4.2个百分点。按8槽完整配装计算上限，不把单件区间当最终收益。

### 5.3 生成、购买与重试

抽样顺序固定为：来源合法池 → 品质 → 愿望部位/其它部位 → 该部位模板 → 装备等级 → 自带强化N → 每阶g → 主属性各k → 普通词条各类型/u。每一次新获取生成独立实例；同模板不同获取不复用字典或随机结果。

战斗与掉落使用不同随机流。奖励、购买和打造以唯一事件/交易ID生成并持久化结果；失败重试、重新打开面板或重复点击重用同一次结果。购买前显示可能范围，扣款和实例入库作为一次提交；已生成的购买结果在待确认交易中展示。不同交易可以得到相同模板和不同属性，不能通过免费刷新同一交易结果挑选属性。

随机性意味着属性通常不同，不保证任意两件装备的全部离散档位必然不同；保证的是独立实例、独立合法抽样和可复现交易。
