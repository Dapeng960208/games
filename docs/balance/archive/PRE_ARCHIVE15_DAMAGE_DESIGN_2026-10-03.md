## 8. 所有技能、Buff、套装与伤害加成的统一计算

### 8.1 属性合成

| 属性 | 聚合公式 |
| --- | --- |
| 战士/枪手AD | `成长AD×(1+主力天赋)+装备平值AD` |
| 法师AD | `成长AD+装备平值AD`；法术型不抽AD普通词条 |
| 法师AP | `成长AP×(1+主力天赋)+装备平值AP` |
| 最大HP | `(成长HP×[1+体魄天赋]+装备平值HP)×[1+min(0.60,生命比例词条+套装生命比例)]` |
| 双抗 | 角色基值+每级平值+天赋平值+装备平值，再按各临时状态修正 |
| 法力容量 | 新基础1000+法术型法力平值词条；怒气/能量容量也为1000但不套法力词条 |
| 普攻间隔 | `基础间隔/(1+有效攻速)` |
| 技能冷却 | `技能当前规格冷却×(1−有效CDR)`；退CD效果按现状共享限流另结算 |
| 基础移动 | `初始移速×[1+min(0.45,装备+天赋+动态移速加成+迅行信标0.15)]`；寒冷/减速/减速抗性与施法移动倍率按现状次序后乘 |

移除旧AD45/AP90/HP220/双抗70/法力150/双穿40/真伤12的装备平值截断，不把旧上限乘10后再截新成长。所有属性键仍初始化0，双抗改为`1000/(1000+防御)`自然递减，不另设平值帽。成长→天赋先在完整表达式后I取整，装备各平值已整数，再聚合；生命比例、动态属性和H在自己的合成边界I取整。

| 百分比桶 | 新总上限 | 合成/边界 |
| --- | --- | --- |
| 暴率 / 暴伤 | 75% / 250% | 暴伤初始150%，随机词条以百分点累加 |
| 攻速 / 移速加成 | 80% / 45% | 加法桶，保留基础间隔与初始移速差异 |
| CDR | 40% | 主属性/词条/天赋/静态套装在同桶 |
| 直接增伤B | 100% | 静态、临时、条件增伤先加，再一次×(1+B) |
| 装备减伤 | 35% | 装备内部加法，超过部分不生效 |
| 全部通用减伤 | 65% | 装备减伤+当前有效技能/状态减伤，统一封顶；同类临时brace/DR取强值不相加 |
| 生命比例 | 60% | 词条与S06生命增益在同桶 |
| 状态延时 | 40% | 同一持续时间只能应用一次；显式固定技能持续时间沿现状规则 |
| 灼烧 / 腐蚀专属加成 | 各100% | 灼烧作用状态快照；腐蚀加入目标已腐蚀时的直接增伤B，不独立相乘 |
| 职业资源回复 | 30% | 资源自然回复、职业命中回复和技能退款乘1+有效值；补给/信标固定百分比不乘 |

资源回复增加后仍受现状装备回资源/秒限流、资源容量和每root触发规则约束；先放大，再执行原限流。界面显示“原合计/有效值/超出值”。比如四个最高金资源词条共67.2%，有效30%，不能把第4条全部计作收益。

### 8.2 H、X、暴击与一次直接伤害

三种基值必须分开。法师普攻在新方案明确增加0.35AP，以便法强武器提升普攻；这是一项提案改动，现状是仅AD。

| 来源 | 新H口径 | 与当前差异 |
| --- | --- | --- |
| 战士/枪手普攻、直接技能 | AD | 无 |
| 法师普攻 | `I(AD+0.35AP)`，初始278 | 当前为AD=18；尺度另×10 |
| 法师技能、法晶、领域 | `I(AD+0.7AP)`，初始376 | 系数口径保留、尺度×10 |
| 法师职业遗物 | AP，初始280 | 系数口径保留、尺度×10 |
| 装备派生 | 保存的`X×系数`；状态用本次事件H | 不把X替换为暴击后的扣血 |

`X=I(本次技能/普攻系数×对应整数H)`，在职业追加、增伤、暴击和连击前保存。职业追加P按现状条件生成后I取整，例如两发校准0.65H、猎印1.25H。真正手动普攻/直接技能每root抽一次暴击，所有本次直接包共享；当前只有普攻抽暴击，新方案增加手动直接技能。

直接基础金额：`(X+P)×[1+min(1.00,B_raw)]×C×K`，`B_raw=静态+临时+条件直接增伤+目标已腐蚀时的(0.08+有效腐蚀专属加成)`。腐蚀增益加入一次B，不另乘`1+腐蚀增益`；本击刚施加的腐蚀不追溯增强同击。C为暴击倍率或1；连击K=`1+0.005n`，n≤100，最高1.5，4秒断连。法晶自动攻击、领域跳伤、DOT、装备派生、遗物派生不独立抽暴击，也不拿本次直接包的暴击/连击再乘一次。

灼烧施加时保存`burn_snapshot=来源power×(1+有效灼烧专属加成)`，每秒`0.12×burn_snapshot`魔法伤害；来源power通常是本次H，不追加暴击或直接增伤B。流血、腐蚀DOT同样保留来源power，不额外吃直接增伤桶。

直接增伤/暴击/连击完成后先I取整为整数原包。受击路径：Boss弱点1.35 → 辅助盾吸收（真伤跳过）→ 双抗/穿透/DR → 普通怪机关弱点1.35 → I取整 → CombatStatus盾 → HP。Boss弱点只乘一次；`防御后=输入×1000/[1000+max(0,防御−穿透)]×(1−DR)`，防御/穿透均×10，腐蚀护甲0.85不变。所有扣盾/扣血为整数；真实伤害仍受无敌和CombatStatus盾约束，弱点增益后同样I取整。

盾/治疗/状态power/每个DOT跳伤分别I取整。普通治疗把比例×最大HP×治疗倍率合成后一次I，再截缺血；装备限流治疗先取整候选、裁剪共享预算，再应用重伤并取整，具体边界见角色技能目标表。连续资源自然回复用高精度时间累积器保留不足1点余量，只在达到整数时提交，避免逐帧舍入导致低帧率或高帧率收益不同。固定资源退款、正成本下限、固定回资源/秒限流×10；0成本依旧0，退CD秒数和层数不×10。

真实附伤按原始有效命中的“root+目标”最多一次，技能多段不能对同目标重复注入；派生、DOT、感电追加不递归注入真实附伤。装备派生使用saved X，所有目标装备伤害派生总额≤1.2X；每root的4包预算由原生状态、职业遗物及装备packet=true命令共享（包含状态、伤害、护盾、治疗等），原生状态/遗物先预留，纯Buff的packet=false事件不占包。遗物不计1.2X金额但占包数。执行顺序按现状固定，预算不足只接受剩余额，面板/伤害日志标明被限流的来源。

整数派生金额预算精确用`floor(6X/5)`。依现状目标顺序分配、每目标I取整后再夹剩余整数预算，不能逐目标取整后总额超过1.2X。

### 8.4 S06缝补回声的自洽循环

| 项目 | 当前 | 建议替换 |
| --- | --- | --- |
| 2件 | 有盾主攻击击退+20% | 额外最大HP+10%，在生命比例桶；有盾击退+20%保留 |
| 4件 | 有盾冲刺后首击+12%，窗口2秒、ICD3秒 | 职业被动/E护盾授予或刷新被系统接受后，直接增伤+20%持续4秒，ICD6秒；同来源刷新不叠加 |
| 6件 | 盾被打破后5秒首击，0.4X冲击波最多3目标，ICD8秒 | 有盾且满3破势启动W，首次有效命中产生0.6H_skill物理冲击波，最多3目标，ICD4秒；每root一次，按派生包/1.2X预算 |
| EQ38固定特性 | 依赖寒冷的0.2X追加 | 条件改为施法者有盾，0.2X系数、现有ICD/目标数/预算保留 |
| EQ58固定特性 | 命中寒冷目标获得2%最大HP护盾，4秒，ICD6秒 | 条件改为施法者有盾，2%最大HP护盾、4秒、ICD6秒和装备盾限额保留 |

其余S06单件机制保留。14套共42阈值，除上述S06三项外，其余39项沿用当前；不能把新增裤/戒当新增8件阈值。循环变为三次普攻/E得盾 → 获得增伤窗口 → Q/普攻攒满破势 → W免怒气爆发并出冲击波，角色能主动执行。

S06四件的新护盾事件明确分开`accepted_refresh`和`increased`：合法新授予/同源刷新成功可开窗，即使被更大来源盾遮盖、有效最大盾池没有增大；弱值被拒绝不算接受。当前guard返回值仅表达容量增大，实施时必须透传上述接受结果。此窗口只接职业被动/E来源，装备派生盾不触发，不能靠EQ58自触发续窗。

### 8.5 同时修正的现状结算偏差

重构实施时，原生状态、装备after_hit、职业消耗、旧感电消费统一以“真实HP或合法护盾产生正损失”的confirmed结果为门槛；免疫、零伤、无效目标不消耗猎印/感电、不触发收益链。每次原始动作只按root计数，多目标/穿透/多发不会多次累加职业被动。

`enemy.apply_status`必须透传真实接受结果，拒绝弱值状态不当成功，不因此进入插座/效果ICD。发射计数遗物RL03保留其明示发射机制，与有效命中被动分开；显示文案改为实际W/R。旧C/V回路是未开放残留API，完整登记但不计入当前或新成长收益。
