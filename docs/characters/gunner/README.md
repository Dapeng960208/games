# 岑线 · 游击快枪 CH02

> 状态：职业模块和全新 UI 已接入；十二技能实际释放、首关章节／首领／撤离及检查点恢复已有记录。完整新动作和人工群战手感未验收。

岑线继续是成年女性枪手。新版定位是移动射击、精准装填和弹匣爆发，服装与武器同步重新设计：米白、青绿与珊瑚色组成主色，短外套、方便翻滚的轻装和清楚的枪械测绘刻度形成轮廓。侧身射击、短促后坐力与落地补弹必须和实际状态一致，立绘、头像、八方向身体动作由角色美术注册统一接入。

## 基础动作与弹匣

普通弹匣为八发；四个主动技能使用独立能量，不消耗普通弹。中央普攻开始时冻结强化倍率，只有原始普通弹体成功创建才消耗一发弹药和对应强化弹。射空仍消耗，创建失败不消耗。

- 第八发射出后自动开始一秒装填。弹匣未满时，按实际装填键手动开始；默认 T，可改键。
- 装填期间第二次按键只判定一次。进度 45% 至 65%（含两端）立即精准成功，填满八发并将接下来三发原始普攻伤害提高 20%。判定失败继续普通装填，不能连续重试。
- 移动和主动技能可与装填并行，装填期间不能普攻。强化弹最多三发，重复获得设置为三发，不叠加。
- 普通闪避成功结束，中止基础装填并补两发普通弹；失败、受阻、取消或死亡不补。补弹不刷新强化弹。
- 装备补充普通弹仅封顶八发，不中止装填、不增加强化弹。装填期间因装备补满仍可完成当前装填。
- 同房检查点恢复保留弹数、强化弹和装填进度。切房取消装填过程，保留弹数与强化弹；新出征初始化八发普通弹、零强化弹。

旧同目标弱点和猎手标记不继续触发。职业机制 HUD 直接读取 `hud_state()`，不自行计弹、判精准窗口或消费强化弹。

## 十二个主动技能

稳定身份为 `CH02_SK01` 至 `CH02_SK12`。初始拥有前四个，之后八组永久奖励各解锁一个。已学技能只在营地编排四个不同技能到 Q／W／E／R，整个出征期间冻结技能与分支。

H 使用现有枪手技能强度；熟练度倍率由中央施法快照统一计算。冷却与消耗是基础值，实际冷却还受现有冷却缩减影响。

游击撤射 Lv.4 分支 A 后撤距离提高 20%，分支 B 完整结束补弹改为四发。火力倾泻 Lv.5 分支 A 改成六发并均分同一 4.8H 总预算，分支 B 完整结束装满弹匣并设置三发强化弹。起手取消和中途取消均不获得完成奖励。

## 接口与有限效果

- [职业模块](../../../scripts/gameplay/characters/kits/gunner_kit.gd)提供技能目录、时间轴、技能释放、装填与普通弹药事务，以及 `export_state()`／`restore_state()`。
- 首次实际释放只结算一次；战术装填由该事件发放，完成阶段不重复发放。技能完成事件按技能身份处理撤射补弹和终结分支。
- 地雷最多两枚、哨机最多一台；连续射击最多六个时间点。连锁弹每根事件仅扩展一次、最多三个不同目标，合法性沿用现有视线和存活校验。
- 角色状态保存只含版本、数字、布尔、字符串和计时。检查点不保存目标、节点、弱引用或半完成的弹体／布置物；未知或损坏职业状态拒绝恢复。
- [中央角色](../../../scripts/gameplay/characters/hero_actor.gd)负责普攻与闪避成功事件；[技能调度](../../../scripts/gameplay/characters/hero_abilities.gd)统一支付能量、身份冷却、熟练度快照和取消规则。

美术目录为 `assets/characters/gunner/{animations,portraits,skills,ui}`；纹理、动作、枪口锚点、来源和许可通过资源索引登记。关键姿态或素材数量不能替代完整连续动画与真实图形验收。
