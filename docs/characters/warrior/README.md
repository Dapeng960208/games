# 罗砧 · 狂战先锋（CH01）

> 状态：独立职业模块、十二技能与新版 UI 已接入；实际释放、首关章节／首领／撤离及检查点恢复已有记录。完整新手绘动作和人工手感未验收。角色 ID、等级与装备资格沿用 CH01。

罗砧以重斧持续近身压制。海军蓝衣装、银色护具、朱红点缀和明确的挥斧轮廓表现重量感；狂暴提高动作速度，动作和命中时刻仍由同一有限技能时间轴驱动。

## 怒气与狂暴

唯一怒气来源是现有 `run.resource`， authored 100 怒气按当前数值规则缩放；没有第二条隐藏资源。

| 有效战斗事件 | 给怒与去重 |
|---|---|
| 原始普攻造成生命或护盾损失 | 每个根事件 +10，多个目标不重复 |
| 主动技能首次有效命中 | 每次施法 +8，多段不重复 |
| 承受敌方有效伤害且仍存活 | +5，独立一秒冷却 |
| 破阵冲锋 B 分支首次有效命中 | 本次技能再 +10，与普通技能给怒一起结算 |

确认战斗事件后，满怒、未狂暴且再触发锁定结束时自动进入八秒狂暴：本体伤害 +20%、普攻攻速 +25%、移动速度 +10%。狂暴不清空怒气，不刷新八秒时长；结束后三秒锁定。保留满怒时，锁定结束后的下一个有效事件可以再次触发。

普攻与技能开始时冻结伤害倍率，已释放的飞斧及多段技能使用同一次快照。狂暴不增强护盾，不再给装备或遗物的衍生伤害重复乘倍率。脱战五秒后每秒衰减十怒，时间与小数余数由中央角色资源入口维护。

旧破势、满势免怒及三次普攻自动护盾已从新职业规则中移除。护盾主动技能与明确装备、遗物效果各自继续工作。

## 实现边界与状态

- 独立实现：[warrior_kit.gd](../../../scripts/gameplay/characters/kits/warrior_kit.gd)。中央角色、装备入口、UI 不在此模块内重复实现。
- 十二项规格：`skill_specs()` 从 `numerical.json.class_skill_specs.CH01` 读取唯一运行数值；技能变体：`apply_skill_variant(data, rank, branch)`；有限释放时间轴：`timeline(data)`；效果：`resolve_skill(cast, index)`。
- 事件：`on_original_hit`、`on_hurt`、`on_skill_release`；装备给怒结算后使用 `on_valid_combat_event()` 检查满怒。
- 普攻／技能增益与移动、攻速接口只返回实际倍率，中央内核在攻击开始时冻结伤害快照。
- `hud_state()` 返回实际怒气、正常／狂暴／锁定阶段、剩余秒数与增益，UI 不计算触发或消费。
- `export_state()` 只输出有限计时、有限字符串账本与反震的值快照；`validate_state()` 验证 JSON 值数据及范围，`restore_state()` 不保留节点或敌人引用。

同房检查点需要保存狂暴、锁定、受击冷却及反震剩余时长。旧快照迁移初始化新计时为零，已有防护状态继续由共用护盾系统保留至到期。反震释放后可以移动，触发时以角色当前位置打击；护盾使用起手属性快照中的最大生命，反击使用起手强度快照。

美术仍经 `assets/manifest.json` 统一解析；脚点、手部及战斧锚点以新动作注册为准。动作数量与设计截图不代表真实自然手感或目标硬件验收。
