## 1. 一句话与设计边界

**召出骷髅，它们自己战斗；点敌人让它们集火，危险时召回保护，关键时刻叫出大骨卫。**

暂定职业名「骷髅召唤师」，角色名「白榆」，身份是为失落遗庭收拢守卫残骸的骨契修复师。以骨白、青绿契纹、暖金扣件与清爽长衣表现友方亡骨，不用腐烂、血浆或阴暗黑红。姓名和具体造型在未来美术立项时确认；系统暂称 `CH04` / `C04`，仅为本文保留标识，不占用运行登记。

### 1.1 玩家真正需要知道的五件事

1. Q 叫近战骨兵，W 叫远程骨兵；召出来就会打，不要尸体、献祭或前置印记
2. 左键 / A 点敌人是集火；不点也能自动战斗，不需要逐只操作
3. E 把队伍叫回身边并给护盾；没有骨兵时也能叫出一只护卫
4. R 直接召唤强力骨卫，不消耗现有军队
5. 自己装备的攻击、法强、生命、双抗、速度等都会影响军队；触发类收益按指挥者统一限流

职业取舍：持续作战与安全走位较好，瞬间清场和立即转火弱于直接施法；召唤物需要走到目标、会损失、需补充。主人仍要躲首领技能、做机关和拾取。没有常驻无敌、无限军团、强制 Boss 转向或自动通关保证。

## 2. 操作、资源与成长

### 2.1 默认操作

右键移动、空格闪避、F 交互、B 背包、M 路线、Tab 技能详情、Esc 暂停保持原约定；所有提示显示实际自定义键。新增职业不占用 C/V，不要求框选、拖拽、多单位快捷键或保持施法。

**左键 / A：骨契指挥。** 在主人 600 世界单位、视线可达范围内选择敌人，建立 4 秒集火目标；同时给全队挂一个「下一击指挥加成」令牌，下一只能够正常出手的骨兵对该目标的攻击额外增加 `0.25HΣ`。自动普攻只重复这个请求，主人不会为了攻击自动追敌。

- 主人基础指挥间隔 `attack_interval=0.60s`，受同一攻速上限影响；指挥动作准备 0.08s、收势 0.12s，移动倍率 1.0
- 全队最多一个待执行令牌，2 秒有效；新命令仅换目标及刷新到新的 2 秒，不叠层、不重置骨兵攻击间隔、不凭点击额外生成攻击
- 指挥目标优先，但骨兵仍要遵守自身射程、路径、视线与主人拴绳；不能隔墙造成指挥伤害
- 实际释放时原子消费令牌，骨兵的正常基础攻击与 `0.25HΣ` 合成**一个指挥击**，算一次玩家原始普攻代理；未消费令牌的普通自主攻击不算原始普攻
- 一个骨兵攻击序列号最多消费一次；物理/魔法两种伤害分量、多目标表现、装备附伤都不能再消费令牌
- 没有合格骨兵时显示「等待骨兵」，不扣资源、不虚报命中。令牌可自然过期；被动/Q/W/E/R 都能独立恢复可用战力
- 点击合法地面不新建伤害目标；可清除集火，军队恢复自动选敌。右键仍只移动，不误触召回

天赋沿用现有六节点与每级一点、20级每节点上限5阶：`mastery` 对本职业**基础 AD 与 AP 各 +2%/阶**，而不是两者先合成后再加两次；线性 HΣ 因而同样只提高 2%/阶。`precision` 暴击 +1%/阶，`vitality` 基础生命 +3%/阶，`resistance` 双抗各 +20/阶，`agility` 攻速 +2%/阶，`dexterity` 冷却缩减 +1%/阶。装备加值仍在基础成长和天赋之后聚合。

当前 `HeroProgression` 只对 CH03 识别 AP 主属性，其他英雄走 AD。本职业的双主属性天赋需未来显式路由；本文不把它当作现成能力，也不改三个现有职业的天赋。

### 2.3 三个简单循环

- 新手：Q → W；自己走位，骨兵自动打；危险时 E，强敌时 R
- 想主动打：在上面基础上左键点优先敌人，让指挥击提供额外伤害和装备触发
- 想经营构筑：六件套改变 W 的后援兵种；技能按键、召回和集火方式不变

不要求先放某只骨兵、攒满印记、让技能穿过节点或按固定顺序连招。指挥击可提升上限，不能成为维持基本灵力或存活的必要条件。

## 3. 军队构成、数量与被动

### 3.1 兵种与基础输出

定义 `I(x)=floor(max(0,x)+0.5)`；`HΣ=I(AD+0.70AP)`。所有数值先从**主人已解析、已封顶**的属性得到，再应用该兵种系数。下表是无套装/遗物/临时状态时的目标。

| 兵种 | 来源与权重 | 最大生命 | 单次基础 X | 物理 : 魔法 | 基础间隔 / 攻击距离 | 移动系数 |
|---|---|---:|---:|---:|---|---:|
| 骨盾卫 | 被动/Q/E，1点 | `I(0.40×主人HP上限)` | `I(0.20HΣ)` | 80 : 20 | 1.10s / 78 | 主人未受控基础移速 ×1.05 |
| 骨弓手 | W，1点 | `I(0.28×主人HP上限)` | `I(0.26HΣ)` | 85 : 15 | 1.40s / 400 | ×1.00 |
| 骨灯术士 | W，1点 | `I(0.24×主人HP上限)` | `I(0.30HΣ)` | 20 : 80 | 1.80s / 360 | ×0.95 |
| 长骨督卫 | R，2点 | `I(0.85×主人HP上限)` | `I(0.65HΣ)` | 50 : 50 | 1.30s / 115 | ×1.05 |

- 所有兵种均享主人 100% 最终护甲/魔抗，但生命不是每只复制一整条主人血条
- 物理/魔法混合是「实体骨击 + 骨契能量」；每种兵的两类占比固定，因此 AD、AP、物穿与法穿都有明确作用。不是按装备高的一项自动改伤害类型
- 术士每第三次**自身自主攻击**实际命中，可给该目标施加灼烧：基础强度 `I(0.50HΣ)`，基础3秒，沿用每秒 `I(0.12×强度)` 的既有灼烧规则。全军共享3秒施加ICD，同目标同家族只取较强快照，不叠成每只一份。指挥击不会额外推进此三击计数
- 督卫每第三次自身攻击向主目标附近90内最多2名其他敌人追加各 `I(0.15HΣ)` 魔法骨纹波；主目标不再受这一波。该波不暴击、不吃连击、不触发装备/遗物/再次骨纹波；不是另一个召唤物
- 术士火与督卫波是可忽略的自动特点，不是技能前置。没有装备时四种兵都能完成基本职责

### 3.2 固定编队，避免补兵时挤掉想保留的单位

| 等级 | 前卫席（Q/被动/E） | 后援席（W） | 常驻总权重 | R 专属临时席 | 实际实体数最大值 |
|---|---:|---:|---:|---:|---:|
| L1 | 2 | W未解锁 | 2个可用；系统上限4 | 未解锁 | 2 |
| L2–3 | 2 | 2 | 4 | 未解锁 | 4 |
| L4–9 | 2 | 2 | 4 | +2点、仅1只督卫 | 5 |
| L10–20 | 2 | 4 | 6 | +2点、仅1只督卫 | 7 |

L1–9 的规则容量为4，但未解锁槽位不能提前使用。L10 增加的是一对 W 后援席，不额外提高 Q 前卫数量。默认后援每对包含弓手1、术士1；L10满员即2盾卫+2弓手+2术士。六件套可以转换后援兵种，但不增加席位或权重。总硬上限8点/7实体；任何遗物、复苏、装备、暂存重试或读档都不突破。

每个席位有稳定 `roster_slot_id`，出生携带 `summon_id`。一个席位不能同时有尸骸、出生排队和活体三个独立占位。预留席位算入容量；出生失败释放预留，不生成幽灵占位。

### 3.3 被动：续骨契约

**一行说明：骨兵自动替你作战；军队全灭后，自动唤回一名骨盾卫。**

- L1解锁，无输入、无消耗。新冒险正常初始化时生成一名骨盾卫，占前卫席；只初始化一次
- 所有常驻骨兵都死亡后，以正常战斗时钟计4秒，若主人存活且合法前卫席仍空，免费生成一名骨盾卫，生命为当前计算上限的60%
- 只有 R 督卫存活不阻止这个恢复计时，因为其寿命有限；若 Q/W/E 已生成任一常驻骨兵，清除空军计时
- 再次全灭重新计4秒；不因读档、暂停、换房或打开面板跳过计时。主人死亡/撤离则停止；复活/新冒险走其自己的正常初始化规则
- 初始满血骨兵与全灭恢复60%骨兵是两个明确事件；不能把重连或切房误判为新冒险
- 无尸体要求，无死亡爆炸、金币/经验、主人受击触发或受伤返还；不得用召唤物制造奖励/怒气/掉落

## 4. 四技能：独立可用的详细规格

本节灵力费用已是 V2 单位；若将来采用旧模板 ×10 的存储形式，Q=10、W=16、E=20、R=45，运行展示只能缩放一次。时长、速度、比例、数量、世界距离都不 ×10。

### 4.1 共用提交、瞄准和取消合同

1. 在准备前校验解锁、资源、CD、主人状态、出生/召回合法位置与席位，原子预留容量；不通过则没有成本与CD，显示精确原因
2. 校验通过即提交并扣费、启动CD。准备阶段被空格/控制/死亡打断，未释放的骨兵或护盾不生成，已提交成本不返还，预留席位释放；与现有提交后取消规则保持一致
3. 释放时再次校验地面。若预留位置失效，只在主人所在可走连通区、距原合法点60以内找替代点；不可跨墙、门、首领边界。全部失败则取消出生并保留已提交成本/CD，提示「落点受阻」，不无限重试
4. 出生成功后有0.18秒成形表现：不可攻击/被选中/挡弹，不算无敌坦克；成形结束才参与战斗。取消收势不会删除已出生单位
5. 普通输入队列沿用现有有界队列和预输入规则；取消只裁已释放后的收势。暂停、背包、弹窗、闪避、死亡、切房清输入队列，不清已提交的军队/资源/CD
6. Q/W/R 出生点是主人周围半径40–90的合法地面，瞄准敌人决定初始朝向/集火建议，不远程在墙后投放骷髅。已有集火目标无效时自动选敌

### 4.2 Q：唤骨列阵（`q`）

**一行说明：补齐两名骨盾卫；已在场的骨盾卫则获得修复。**

| 参数 | 目标值 |
|---|---|
| 解锁 / 成长 | L1；L10费用100→80，其他基础参数不变 |
| 费用 / 基础CD | 100灵力 / 4.0秒 |
| 准备 / 释放 / 收势 | 0.12 / 同帧两个席位事务 / 0.16秒，总动作0.28秒 |
| 范围 / 目标 | 主人附近40–90出生；只操作两个前卫席 |
| 数量 / 寿命 | 每个空席各1只，最多2；常驻至死亡/离开冒险 |
| 席位已有骨兵 | 对该单位修复 `I(0.06×主人HP上限)`，单次最多两份；不复活尸骸之外的已占用单位，不更换ID、不重置攻击或触发计数 |
| 移动 / 取消 | 全程100%移速；按共用合同 |

两个席位都满血且无待出生缺口时，Q 无效且不扣费，UI写「前卫已齐备」；至少一个席位可修复或缺失即可施放。修复按该骨兵的重伤效果减至60%，不溢出为盾、不治疗主人、不触发治疗装备链。

L18可选分支，未选保留标准Q；只在营地改选：

- A「厚骨」：前卫生命系数0.40→0.50，前卫普通攻击系数0.20→0.17；Q费用维持L10后的80。后援套装转换出的盾卫不算这两个前卫，不获得此分支
- B「轻骨」：前卫移速系数1.05→1.20，攻击间隔1.10→0.95秒；生命系数0.40→0.32。Q修复值仍按主人HP的6%，不因脆弱而加倍

### 4.3 W：后援唤骨（`secondary`）

**一行说明：召来一名骨弓手和一名骨灯术士；满员时强化它们的下一击。**

| 参数 | 目标值 |
|---|---|
| 解锁 / 成长 | L2；L12已存在后援的强化系数0.15→0.20HΣ |
| 费用 / 基础CD | 160灵力 / 6.0秒 |
| 准备 / 释放 / 收势 | 0.16 / 同帧一对席位 / 0.16秒，总动作0.32秒 |
| 范围 / 目标 | 主人附近40–90出生；只操作后援席 |
| 数量 / 寿命 | 一次处理一对：弓手1、术士1；常驻，无自然倒计时 |
| 满员收益 | 对本次所选一对已存活后援各赋「下一次攻击额外0.15HΣ」，持续5秒，单体最多1次；重施刷新而不叠层 |
| 移动 / 取消 | 全程100%移速；按共用合同 |

L10后优先选择空缺最多的一对，其次强化剩余时间最短的一对，再按固定席位序号；一对中空席生成、另一席强化，规则一致。W不会挤走前卫，也不会把满血后援删掉重生。一次W最多两只，不因为全灭自动补四只。

W加成与指挥加成可以同次使用，先把系数加到该次X再算暴击/抗性；它本身不产生第二个命中事件。未能实际出手则不消费加成，5秒自然到期；实际发出攻击即消费，之后无敌、落空或墙挡不返还，也不产生触发。六件套只替换后援兵种，同一席位规则继续成立。

### 4.4 E：归阵骨盾（`f`，默认键E）

**一行说明：把骨兵召回身边，为自己和军队加盾；空军时也能叫出护卫。**

| 参数 | 目标值 |
|---|---|
| 解锁 / 成长 | L3；L14主人护盾10%→12%HP，军队池不额外增加 |
| 费用 / 基础CD | 200灵力 / 10.0秒 |
| 准备 / 释放 / 收势 | 0.10 / 0.15秒归阵 / 0.15秒，总动作0.40秒 |
| 作用范围 | 当前房间内所有自有、存活骨兵；不能跨房远程拉取 |
| 召回落点 | 主人周围40–90合法位置；单位在归阵过程中暂不攻击，保留实际HP、攻击剩余CD、负面状态与寿命 |
| 主人护盾 | `I(0.10×主人HP上限)`，4秒，L14为12% |
| 军队护盾 | **总池** `I(0.24×主人HP上限)`，4秒，按参与单位权重分配；不是每只24% |
| 空军补救 | 若无常驻单位且有空前卫席，先生成1只满血盾卫，计入分盾；不补满整队 |

军队池按权重比例计算，先取整数下界，剩余点数按稳定席位顺序各补1；护盾遵守单体上限及同源覆盖，未能分配的尾量作废。督卫权重2，可分两份，不能因为生命高再额外乘一次。独立单位各自有盾，单位内部多个盾源仍取最大值。

E不治疗、不清负面状态、不提供无敌、不嘲讽、不清敌方弹体。归阵后的骨兵仍会受到落点危险；主人仍需空格躲技能。敌人已锁定的攻击照原锁定位置/目标规则结算，不因E强迫重新锁到主人。

### 4.5 R：长骨督卫（`ultimate`）

**一行说明：召唤一名强大骨卫，短时间与现有军队一起作战。**

| 参数 | 目标值 |
|---|---|
| 解锁 / 成长 | L4；L16基础存续10→12秒，单位系数不同时提高 |
| 费用 / 基础CD | 450灵力 / 35.0秒 |
| 准备 / 释放 / 收势 | 0.28 / 单只出生事务 / 0.22秒，总动作0.50秒 |
| 数量 / 上限 | 1只、权重2，只使用R专属额外2点；常驻上限不变 |
| 出生 / 攻击 | 主人附近40–90；115近战；普通攻击/第三击骨纹波见兵种表 |
| 持续 | L4–15为10秒；L16–20为12秒，正常战斗时钟 |
| 移动 / 取消 | 主人可100%移动；共用取消规则；已生成督卫不因主人收势取消而消失 |

已有督卫时R不能重施，不耗费、不刷新寿命；复用未来CD缩减也不能叠两只。到期「归骨」只清理本体，不触发死亡、击杀、遗物和返还。阵亡则提前失去剩余价值，CD照常走。R单独在空军时可用，不需要Q/W，也不献祭旧兵。

L20可选分支，未选保留标准R，均沿用35秒CD、450费用及同一R临时席：

- B「远骨督卫」：持续10秒，生命系数0.85→0.55，射程480，攻击系数0.45、间隔0.90秒，物理/魔法25:75；移速系数1.00，失去第三击范围波。更快转火，减少寿命与范围输出

### 4.6 静态资源预算（不是战斗平衡结论）

L4完整起手Q+W+E+R成本910，基础灵力1000可独立完成一次；L10起手890。纯补兵Q每4秒100、W每6秒160为51.67/s，考虑停回与走位仍需观察，不承诺无限无间断重建军队。Q满员满血会拒绝施放，正常情况下无需一直重按。

若全部技能一好就放，L4平均成本 `100/4+160/6+200/10+450/35=84.52/s`，超过基础60/s；CD40%时该支出约140.87/s，仍不能靠资源回复上限30%后的78/s无脑永动。技能期间停回还会进一步降低供给。军队常驻不收费，资源紧张时可继续自动作战；全灭被动保证不会永远无兵。

## 5. AI、首领与碰撞规则

### 5.1 自动选敌与跟随

- 搜敌仅限当前已激活遭遇、主人同可达区域、距主人520以内的存活敌人；不攻击休眠房间、奖励箱、门、机关或友方
- 优先级：合法集火目标 → 最近伤害主人的普通敌人（2秒记忆）→ 本兵种可攻击最近敌人 → 跟随。等距按稳定实体ID；当前目标仍合法且新目标只近24以内时不切换，防止抖动
- 无集火时盾卫优先主人周围160内敌人；弓手/术士选择可见目标，无需复杂职业配对。督卫不独立开怪
- 近战接近到攻击距离，远程保持220–350距离；远程后退只在主人周围合法区进行，不能无限放风筝穿门
- 距主人280开始追随，480放弃普通追击；600禁止发起新攻击，720触发安全召回。集火不能突破600攻击拴绳
- 目标路径连续0.8秒无法前进，或超720：取消尚未释放攻击，0.15秒归骨到主人身边合法点，保留HP、盾、状态、攻击CD与寿命；1秒内不重新选择同一不可达目标。已发弹体不回收
- 主人当前区域无合法点时进入非战斗待放置状态，仍占原席位，最多每0.5秒重试一次；既不伤害敌人也不挡路。房间切换可重新放置；不能原地无限创建节点
- 空间采样只选视线和导航都可达的落点，禁止跨闭门、深坑、Boss封锁线或利用视觉发射点穿墙

### 5.2 出手与控制

| 兵种 | 准备 / 释放 / 收势 | 其他明确行为 |
|---|---|---|
| 盾卫 | 0.16 / 0.06 / 0.22秒 | 单目标挥击；无永久嘲讽、击退或阻挡墙 |
| 弓手 | 0.20 / 真实出箭 / 0.22秒 | 弹速700、基础最大行程440；不穿墙、不追踪已发目标 |
| 术士 | 0.24 / 真实出弹 / 0.24秒 | 弹速600、基础最大行程400；灼烧仅确认有效命中后计数 |
| 督卫 | 0.24 / 0.08 / 0.28秒 | 主体单目标；第三击的额外波单独去重且最多2个其他目标 |

上表是动作占用时间，攻击间隔是完整两次起手的最小间距，不把动作再额外加到间隔上。攻速缩短间隔；动作各段等比例压缩，最低准备0.08秒，不能变成瞬发视觉。减速/控制在各自单位上独立结算；主人被冻住不冻结全军，骨兵被控制不回传主人。召回不解除控制。

### 5.3 仇恨与 Boss

- 普通敌人可以选择骨兵为合法目标，但不得被零生命/排队释放对象卡住。目标失效后一个AI更新周期内回到主人或其他有效对象
- 前卫只是可以挨打的前线，默认不生成强制嘲讽。任何未来遗物嘲讽都需单独审查，首版不纳入
- Boss主要追击与机制目标保持主人；允许其自然近战/范围波击中骨兵，不因为七个单位而生成七份针对玩家的点名或七倍增援
- Boss原有阶段、弱点、锁定朝向、反制和奖励不因骨兵数量改变；伤害归主人，但骨兵不能操作护盾回路、虫卵任务、封墓或战鼓反制交互
- 指向主人、要求主人躲避的首领弹体不被骨兵自动吃掉；普通敌人可挡的单体飞弹最多由一只合格骨兵接触，不能多只重复吸收同一弹
- 骨兵照常承受Boss范围伤害，不默认给予90%范围减伤。若真实游玩出现不可恢复的群灭，只调兵种生命、E池或重建窗口，不先做免疫

### 5.4 碰撞与拥挤

骨兵只与地形阻挡发生实体碰撞；与主人、友方骨兵和敌人用软分离，不能封堵门、卡住首领或形成不可穿过的肉墙。软分离每只最多采样4个邻居，不递归推挤；敌人攻击的命中体积仍有效。远程射线不会被友方身体挡住，不能穿过地形。脚底半径建议盾卫12、远程10、督卫18，实际接受度需未来场景验证；图片大骨架不能等同大面积导航障碍。

## 6. 全面属性继承合同

**“全面属性”指每种相关属性都有可解释的受益路径，不是把主人完整伤害、生命、护盾、治疗和触发次数复制七份。** 单个骨兵通过兵种系数承接数值，军队共享事件预算，经济始终只结算给主人。

### 6.1 从真实字段到收益

下表覆盖当前 `StatResolver` 的数值输出、当前词条以及关键运行状态。`装备原始键 → 解析键` 表示同一值的不同阶段，不能相加两遍。

| 当前实际字段 | 骨兵/指挥者如何受益 | 计算、上限与禁止重复项 |
|---|---|---|
| `attack` | 全兵种伤害中的 AD 部分 | 全量进入 `HΣ=I(AD+0.70AP)`，之后乘各自系数 |
| `ability_power` | 全兵种骨契能量部分 | 全量以0.70权重进入HΣ；不是只法系兵种可用 |
| `max_hp` | 主人存活、每兵最大生命、Q修复、E共享池 | 先得到主人最终HP再乘兵种系数；不把每兵HP回加主人 |
| `hp_ratio` | 通过主人最终HP完整传给上述路径 | 主人生命桶上限+60%；骨兵不得再乘一次hp_ratio |
| `armor` / `magic_resist` | 每兵继承100%最终双抗 | 各自非负；抗性减伤 `r/(1000+r)`；不能继承“抗性数值”后再叠继承减伤率 |
| `armor_damage_reduction` / `magic_damage_reduction` | 仅派生展示 | 使用继承双抗重算；不是可再次相乘的额外减伤 |
| `damage_reduction` / `equipment_damage_reduction` | 继承主人装备减伤桶一次 | 两者在当前解析中指向同一装备减伤；装备≤35%，加自身合法短减伤后通用≤65%；不得将别名相加 |
| `attack_speed` → `attack_speed_bonus` | 主人指挥更快，骨兵自己的攻击间隔也缩短 | 总增益上限80%；`间隔=兵种基础间隔/(1+有效AS)`；不用主人已缩短的attack_interval再除一次 |
| `attack_interval` | 指挥请求频率；也可反推当前有效攻速 | 主人0.60基线与兵种基线不同；AS来源统一，禁止把主人0.60秒直接赋给所有骨兵 |
| `move_speed`（装备为比例，最终为速度）/ `move_speed_bonus` | 主人走位与骨兵跟随、接敌 | 正向增益共同上限45%；`兵速=230×兵种移动系数×(1+主人有效正向移速桶)`，随后施加该骨兵自己的减速；不重复乘已结算move_speed |
| `crit_chance` | 所有骨兵主体攻击和指挥击可暴击 | 最终上限75%；每个攻击根只掷一次，两伤害分量共享结果 |
| `crit_multiplier` | 同上 | 最终1.0–2.5；额外波、持续伤害、装备真伤不暴击 |
| `armor_penetration` / `magic_penetration` | 对应所有骨兵的两类伤害分量 | 全量继承，目标有效抗性 `max(0,目标抗性−穿透)`；负抗性不会放大伤害 |
| `damage_bonus` | 骨兵直接攻击增伤 | 主人有效常驻/临时同桶，含触发条件已满足的部分，总上限100%；条件按对应目标和主人状态核实 |
| `corrosion_damage_bonus` | 骨兵攻击已腐蚀敌人时提高伤害 | 沿用当前 `0.08+该加成` 并入同一个damage_bonus桶；本词条自身上限100%，不是独立再乘一次的腐蚀DOT放大器 |
| `burn_damage` | 骨灯术士、RL02或合法装备施加的灼烧 | 只放大灼烧强度/伤害一次，上限100%；没有灼烧来源时不会无条件转成直接增伤，UI需写明条件 |
| `status_duration` | 召唤攻击/指挥代理成功施加的负面状态 | 个人状态时长增幅≤40%；按各家族规则，免疫不触发；不延长骨兵寿命、E盾、W强化、R或集火令牌 |
| `true_damage_bonus` | 通过全军唯一指挥击代理追加真伤 | 每个已确认的指挥根、同目标最多一包；自主骨兵命中不各自复制；不暴击、不触发、不吃抗性或装备减伤 |
| `cooldown_reduction` | 更频繁Q/W/E/R及现有规则允许的闪避收益 | QWER `CD=base×(1−CDR)`，≤40%；不同时加快骨兵自动攻击、遗物ICD、被动4秒或R寿命 |
| `max_mana` / `resource_max` | 更多召唤、修复和保护储备 | mana职业同一个池；最终1000+装备max_mana，不乘单位数 |
| `resource_regen` / `resource_regen_delay` | 主人持续补兵与指挥支援 | 60/s，停回0.20秒；继承的是施法可用性，骨兵不额外开自己的灵力池 |
| `resource_gain_bonus` | 资源再生和合法回复提高 | 上限30%；每秒先 `I(regen×(1+bonus))` 再累积小数时间，与现有余量积分一致；药水/信标百分比回复按既有口径，不又加一次 |
| `starting_resource` | 新冒险初始灵力 | 仅主人一次初始化；出生、补兵、搬房不重复发资源 |
| `range` | 更远的合法集火指挥范围 | 主人指令校验使用该值；不把600直接覆盖弓手400/术士360；当前无射程词条，未来增加时必须明确是指挥还是兵种射程 |
| `resource_type` / `resource_name` | 共用mana机制，显示灵力 | 元数据，不作为倍率；不新增骨兵独立资源 |
| `level` / `talents` / `hero_base` | 等级成长、技能节点与被动容量 | 主人解析一次，骨兵不再跑HeroProgression；talent_points_available不参与战斗 |
| `sets` / `loadout` / `equipment_templates` | 解锁正确的套装与固定词条逻辑 | 主人保留权威所有权；骨兵不拥有八件复制装备、不再次计套装 |
| `equipment_contribution` / `uncapped_equipment_contribution` | 属性来源和上限提示 | 审计/显示数据，不是附加第二套属性；只能用封顶后的有效数值战斗 |
| `hero_id` / `ruleset_version` | 归属、数值版本、奖励归账 | 所有攻击包固定为主人版本；不能让新召唤把旧冒险升级到V2 |

### 6.2 不在 StatResolver 内、也不能漏掉的运行效果

| 效果/字段或事件 | 具体路由 |
|---|---|
| 主人当前 `hp` / 护盾 `shield` | 主人血量不是每只当前HP；主人护盾不自动复制。E/遗物明确分配到骨兵后才有独立盾 |
| `CombatStatus` 的 `damage_reduction`、`brace_guard`、`invulnerable`、`grievous`、chill等 | 主人的无敌/受控/受伤不传染全军；骨兵拥有自己的状态。给主人加的短减伤只保护主人，给军队的效果需明确目标；同类减伤取强、通用上限65%，重伤治疗×0.6 |
| 装备 `shield_gain` / `damaged` / `dash` / `skill_cast` | 主人实际事件仅发一次；每只骨兵挨打/分盾不伪装成主人被打/得盾/施法。军队专用受击触发使用独立、共享限流事件 |
| 吸血、击杀治疗、资源返还、护盾吸收、减速抗性、击退放大、技能费用修改 | 当前是装备条件命令/修正，不是统一独立基础属性。指挥击可触发已允许的进攻命令；治疗/返蓝默认归主人一次，护盾按效果指定目标；被动自动攻击不能逐兵复制。主人减速抗性留给主人，明确写“军队”的效果才给骨兵 |
| `hit_chain` 连击 | 只有实际执行的指挥击增一次并使用现有倍率；自主攻击、DOT、R骨纹波不加层、不吃连击。连击不因单位数增长，也不永久保存 |
| 装备灼烧/感电/寒冷/腐蚀/流血/重伤 | 走指挥击的唯一原始命中代理，遵循每根预算、目标免疫和成功施加回执；两伤害分量不算两次状态施加 |
| 主人 `temporary_buffs` 的amplify与场景属性修正 | 增伤进入同一封顶桶；地形给主人的回复倍率只增加主人补兵能力。是否给单个骨兵的地面减速/危险，由其实际脚点决定 |
| 金币、XP、材料、研究XP、掉落率、难度、奖励回执 | 杀敌归主人一次；骨兵无独立金币/XP/掉落。杀死骨兵不给任何一方奖励。多个骨兵同帧击杀同一目标仍一个death_event_id |
| 视觉颜色、武器图、`projectile_speed`、攻击形状 | 不是当前通用可装备属性；按新职业兵种设计使用，不把主人视觉/武器的弹速强塞给全军 |

未来新增任何词条必须落入「直接继承 / 转为主人支援收益 / 条件事件 / 明确仅主人」四类之一并补说明，禁止未知键静默按0处理或自动100%复制。

### 6.3 动态继承与快照边界

- 活体属性以主人当前已解析属性为源。换装、升级、天赋、合法增益变化标记revision，下一物理帧统一更新全队；不会把出生时最强装备永远留在骨兵身上
- HP上限提高不免费加当前HP；降低时只 `current_hp=min(old_current,new_max)`；盾同样按新容量裁切，增加上限不填盾。HP从未按比例提升，防止高血装来回换治疗
- 护甲、双抗、暴击、攻速、移动与穿透同步新值；正在倒计时的攻击按“已过进度比例”转换新间隔，不能换装立即多打一刀。QWER已启动的剩余CD不因换装重新计算或重置
- **真正发出攻击时**冻结HΣ、两类X、暴击结果、穿透、增伤、相关集合和root ID。弹体飞行途中换装不改该次攻击；下次攻击用新revision
- DOT按当前 `CombatStatus` 的较强快照/等强不缩短规则保存；旧强DOT只能活到原有限时，不得拿弱刷新无限延长强快照。卸装立即停止新来源触发，已提交的有限弹体/状态不撤销
- E盾、Q治疗、资源返还都是实际释放时的一次值命令，不是每帧重新根据当前HP填满。套装/遗物禁用后不清其已消费ICD和账本
- 脱下转换兵种的六件套：下一安全帧将对应后援席改回默认兵种，保留ID、当前HP绝对值并裁切，保留攻击进度/状态/寿命；不视为死亡或新召唤，不能刷新满血

### 6.4 伤害、顺序与整数

这里沿用当前V2的半入整数边界以及 `Room` 先计算直接包、`DamageResolver` 再做防御的分工。混合伤害需要未来专门的原子两分量包装；不能简单连续调用两个“原始命中”入口。

1. 主人成长和天赋先取整；装备实例的既有整数值相加；主人HP最后乘已封顶hp_ratio并取整
2. `HΣ=I(AD+0.70AP)`，`X=I((兵种系数+有效指挥/W加成系数)×HΣ)`
3. `Xp=I(X×物理占比)`，`Xm=X−Xp`，两者总和必须严格等于X；混合不是两份完整X
4. 整个攻击根只掷一次暴击；共享一次条件判断、一次触发预算、一次命中连击快照。令 `B=clamp(直接增伤桶,0,1)`，`C=暴击倍率或1`；K仅指挥击使用连击倍率，其余K=1
5. 两分量各得到 `pre_p=I(Xp×(1+B)×C×K)`、`pre_m=I(Xm×(1+B)×C×K)`，进入对应防御；`effective_r=max(0,r−pen)`，`post=I(pre×1000/(1000+effective_r)×(1−DR)×合法弱点倍率)`。真伤不走抗性/DR/暴击
6. 目标以原子事务接收两个分量并分配到同一个共享护盾池和生命；二者均结算后只产生一个实际损失回执/死亡事件。目标无敌时总损失为0，不启动触发
7. 令牌在实际释放时已原子消费；确认损失后才提交状态/遗物/真伤。若目标已死亡，不为附伤造新目标；独立的额外敌人效果须重新验证目标

不把比例、时间和速度整数化，不对每帧资源回复四舍五入。极小分量可能取整为0，不强行每类最低1伤害。伤害文字默认合并显示总实伤，可在详情中查看物理/魔法分量。

## 10. 技术设计、保存与迁移

本节是未来接口合同，不是已存在的新模块清单。建议独立 `SummonRoster`（纯值状态）、`SummonStats`（纯计算）、`SummonActor/Brain`（表现与AI）和 `OwnerCombatBridge`（归属与触发），实际文件名由实施时确定。

### 10.1 权威归属与事件

每只骨兵拥有 `owner_hero_id`、`run_id`、`summon_id`、`roster_slot_id`、`spawn_generation`、`room_epoch`。战斗根ID由主人统一单调序号生成，不能用系统毫秒或节点内存地址作为持久唯一性。

- 伤害上下文用 `damage_source=summon_auto/summon_command/summon_derived` 区分；普通骨兵主体可暴击/继承增伤，但不是现有原始装备事件
- 指挥代理产生一个原始普攻事件，兵种两类伤害分量是这个根的子分量；不能分别调用会增层/发遗物/返真伤的原始入口
- 每次死亡先提交 `enemy_death_id`，由主人已有奖励事务结算一次；友方骨兵无奖励源。目标被两只同帧击中只允许第一个合法死亡事务产生回执
- 已离场generation或room_epoch的延迟事件一律拒绝；不能把上一房弹体击中映射到下一房同ID敌人
- 指挥令牌/席位/触发包均先原子预留再执行。渲染、音效或对象池是否取到节点不决定第二次资源扣费

### 10.2 保存内容与不保存内容

| 保存为值 | 说明 |
|---|---|
| `summon_schema_version` / ruleset / content版本 | 用于明确迁移、未知版本拒绝与兼容 |
| roster各席的summon_id、archetype、来源Q/W/E/passive/R、generation | 固定身份与去重；缺席/待成形/存活状态明确 |
| 当前HP整数、护盾各来源值与剩余秒、负面状态值与tick余量 | 保存实际消耗，不保存一个“满血”布尔去重建 |
| 位置值、朝向值、当前房间标识、跟随/待放置状态 | 位置载入后重新校验；不能借坏位置穿墙 |
| 攻击剩余时间/进度、术士/督卫计数、W强化值与剩余时间 | 不读档重置到立即攻击/再得免费强化 |
| R剩余寿命、被动全灭剩余时间、技能剩余CD、资源与余量、停回计时 | 继续同一正常战斗时钟；离线/暂停不自动补满 |
| 主人共享遗物ICD、计数、变体/等级、已消费事件水位、预算状态 | 不通过换装、读档、回房重置触发 |
| 战斗随机流状态或确定性根序号、已出手攻击的暴击结果 | 同一检查点恢复不能为同一个已提交攻击重新抽暴击；美术随机不消耗战斗随机流 |
| 当前必要属性revision及有限攻击/DOT的数值快照 | 基础权威从存档主人装备重算；保留有限已提交效果的旧值 |

禁止保存Node、NodePath当作实体身份、`get_instance_id()`引用、闭包、材质对象、导航代理、运行中scene句柄。存档中的目标只能是当前房间的稳定敌人ID；无法解析则清除目标，保持骨兵本身与剩余状态。

安全检查点在物理帧事务结束后写入。尚未结算的原始攻击如必须跨检查点恢复，应保存有界攻击值描述与唯一根ID；若当前检查点体系无法恢复它，明确取消该攻击且保留已扣成本/CD/已消费令牌，不得边恢复弹体边重新执行施放。

### 10.3 载入顺序与事务

1. 验证schema、主人、冒险ID、规则版本、编队合法兵种/权重与数值有限性；拒绝重复summon_id、重复席位、负寿命与超容量
2. 先恢复主人HP/资源/CD与装备；重算新当前最大值，不触发新冒险送兵或room_enter奖励
3. 恢复纯值军队，当前HP和盾只裁切不补足；过期督卫删去但不触发死亡收益。出生队列的预留只能恢复一次
4. 清理这个owner+run+epoch已有运行骨兵，再从值状态建立恰好一份节点；这一步必须幂等，不能重试一次多出一队
5. 重新选择合法脚点、解析合法目标；恢复AI时钟/攻击进度。恢复过程中禁止攻击/掉落/遗物事件
6. 全部提交成功后开放输入；失败则回滚整个快照并给出可恢复错误，不能静默变成满血满蓝的新军队

### 10.4 切房、暂停、退出与死亡

- 切房：军队值状态只搬运一次，保持HP/盾剩余时长/负面状态/攻击进度/R寿命/被动计时；新房入口合法脚点重排。清集火目标、未执行输入与原房弹体；未执行指挥令牌取消，无返还资源事件
- 切换加载期间不推进战斗时钟；反复回房不回血、延盾、刷初始被动或再领R。原有房间一次奖励账本继续权威
- 暂停/背包/地图/弹窗：军队与主人同样停时；恢复时不一次补跑暂停期间数十次AI/攻击。声音延迟队列不穿越暂停重播
- 关闭游戏/进程恢复：使用最后已提交检查点；不利用墙钟算离线回蓝或免费CD。异常退出无法恢复未保存进度时如实走现有检查点策略
- 当前单机不凭空引入多人同步。若未来有断线恢复，主人为唯一权威、epoch变更拒绝旧包；重连只恢复值，不发第二个初始军队
- 主人死亡：立即禁止全军攻击与后续触发，按现有死亡规则结算主人损失，军队解散无奖励；不得让已死主人靠召唤在后台击杀回收损失。已提交同帧事件按既定事务顺序完成一次
- 正常撤离：军队不作为永久装备/资产入库，主人既有金币、经验、材料和装备按原规则处理；新冒险重新初始化
- 进行中旧三职业冒险冻结旧内容；不把添加第四职业当成可原地转换职业的迁移理由

### 10.5 内容与资格版本

当前多个模块显式只允许三英雄，且装备资格历史版本和经济回执不能重写。未来实施必须盘点：Registry英雄/套装验证、HeroProgression、ProfileStore、角色选择/预设、八槽装备资格、掉落生成、奖励归属、职业遗物、局内快照和恢复。不允许只改可选英雄列表就宣称完整。

旧存档缺少召唤字段时默认“没有召唤系统状态”，而不是读取成已实装CH04。只有明确新增职业的新冒险才生成被动初始兵。未知CH04新版本被旧客户端读到时保留原档备份并拒绝运行该角色，不静默删装备/遗物/存档。变体、新套装与可选8件档均各自版本化，不能靠名字猜能力。

## 12. 平衡目标、风险与反滥用

### 12.1 目标与可调旋钮

目标是“正常走位时稳定指挥军队”，不是远处挂机无风险过极限首领。三方向应有明显差异：白垣重承伤、青翎重单体/射线、灯骨重魔法/状态与支援频率。初期先比较同等级同预算装备，不拿六件金装召唤师与无装旧角色比。

主要旋钮限定为：兵种X系数、攻击间隔、HP系数、E总池、Q修复与费用、W费用、R寿命/CD。一次测试只改解释问题的少数参数；不同时全面提高继承率、数量、暴击和触发频率。

| 风险 | 可能后果 | 本提案边界 | 未来必须验证的可观察结果 |
|---|---|---|---|
| 每兵复制全主人HP/伤害 | 军队无成本七倍成长 | HP/伤害分兵种系数，总容量有界 | 七实体仍不产生七套主人基础攻击/真伤 |
| 增益随单位数互乘 | 套装从线性变平方 | 禁止“每只给全队加层”；E为总池 | 1/4/6单位时E总发放分别≤同一池 |
| 高血装召出兵后换输出 | 永久保留高血高攻 | 活体动态更新，HP绝对值只裁切 | 卸装后下一帧新上限正确，无免费回填 |
| 读档/回房刷新军队 | 无限血/蓝/盾/R | 保存实际值和剩余计时，恢复不触发初始化 | 连读/回房10次后数值不增加 |
| 每只原始命中触发遗物 | 暴击/真伤/资源/连击失控 | 只有指挥击是单根原始代理 | 自主打100次不增长遗物/连击/真伤账本 |

| 召回躲掉一切/重置攻击 | 无限生存/瞬发 | 保留状态/CD，无无敌，不清敌人锁定 | E不能洗DOT/控制，不能额外打一轮 |

### 12.2 反例上限算账

- E基础军队池是0.24主人HP：一只得整池并受自身盾上限；六只常驻平均每只约0.04主人HP；六只+督卫按8权重点分，普通约0.03、督卫约0.06主人HP。不是军队越大总盾越高
- 6只骨兵每秒各命中一次，真伤20仍只能随合格指挥根最多一次，而不是每秒6×20；自主攻击不能启动该真伤
- 叉骨羽II每次最多`2×0.30HΣ`，共享2秒ICD，其理论附加总吞吐上限约0.30HΣ/s，且需要其他目标与有效指挥击，不随召唤数再乘6
- 骨核匣II每4秒最多`I(45×1.30)=59`灵力，理论≤14.75/s；B01族效果至多`I(10×1.30)=13`每3秒，二者上界相加约19.08/s，仍不能让140.87/s的满CDR全技能倾泻永动。实际第三击计数/停回/目标可达还会降低可达上界
- R仅一个额外实体；延时分支有固定到期，没有“每击杀续1秒”。套装、击杀或召回都不能把它变常驻
