# 露弥 · 暗黑魔法师 CH03

> 状态：职业机制和新版 UI 已接入；十二技能实际释放、首关章节／首领／撤离及检查点恢复已有记录。战斗美术身份失败：旧完整动作仍是男性工程师，新的女性露弥只有立绘和东南普攻样板。完整新动作与人工手感未验收。旧法晶、充能、引爆和交替槽位施法被动已经退出。

露弥是22岁的成年女性暗黑魔法师，保留可爱的圆柔脸颊与成年身体比例。身形采用丰满胸部、窄腰、纤细肩臂和腿部，配合卷发、大魔女帽、短披肩、收腰中长裙和短靴。黑曜黑、午夜深紫、银饰与幽蓝魔光形成清楚的角色轮廓；黑银星环法杖镶嵌暗紫水晶。原创资源与来源由美术登记维护。

团团是一只圆润四角星形的小星灵，只有一个跟随主体。团团不拥有血量、仇恨、装备、独立自动攻击循环或额外技能键。普攻仍由角色中央入口创建并结算，团团只承担释放动作；自动普攻开关、距离与视线规则继续有效。

## 职业循环

真实战斗中，每次主动技能完成第一次实际释放积累一层星辉，最多三层。已满三层时，下一次实际释放消耗全部星辉，该次技能基础伤害或护盾提高25%，回复十点基础法力（按当前数值单位与资源获取加成结算）。整个技能的数值在首次释放时冻结；多段和持续效果不会重复积累星辉或退款。

八秒未继续施法则星辉消散；暂停冻结计时，切房、死亡和回营地由角色生命周期重置。起手取消不会获得、消耗星辉或退款。技能“双星共鸣”额外补一层星辉，并在六秒内下一法术首次有效命中时提供一次0.8H衍生伤害；其数值保存于释放快照，不重复触发装备、职业被动或熟练度。
