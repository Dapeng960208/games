# 逐房地图与 UI 表现设计

更新日期：2026-10-01。覆盖实际已接入的 B01–B04：24 个普通房间与 4 个首领房。B05–B12 仍待开发。

## 运行方式

`data/room_presentations.json` 为独立表现配置。`RoomPresentation.apply_scenery()` 在固定蓝图完成坐标映射后，仅重组无碰撞陈设，保留原地标、实体掩体、奖励原位与全部玩法字段。未使用设计草稿整房覆盖运行 JSON。

每个房间使用一张独立生成的完整背景原画，共 28 张；同族保持手绘风格与色卡，各房的建筑、生态、外围与铺地构图分别设计。资源位于 `assets/generated/world/rooms/{room_id}_environment_v1.png`，相邻 JSON 保存独立干地轮廓、统一蓝图映射与生成来源。`WorldArt`、碰撞边界、镜头、小地图与六区块采样均按同一蓝图房间 ID 读取，首领房也使用其独立原画。缺失资源时保留旧族背景兼容回退，但已完成的 28 房必须实际加载各自纹理。

每房另有固定两组用途陈设，以浅铺地、主题镶嵌和工位地纹补足地图细节。独立原画接入后，额外地纹降低透明度，避免覆盖手绘地面。四族保持小石砖、浅色地面、近等距脚点与 0.58 蓝图映射。每张完整原画的六块共享本房纹理；没有把共享旧母图切块或换色当作独立背景，也不声称显存流式加载。

背景放大时由 `shaders/environment_sampling.gdshader` 使用 Catmull–Rom 重建采样，减少线性采样造成的边缘柔化；缩小时保留 mip 抗锯齿，在接近原尺寸时平滑切换。六块继续读取完整母纹理，不单独钳制各块边缘。生产窗口采用 `canvas_items`，实际全屏渲染为物理窗口分辨率；没有先渲染成 720p 再放大整幅画面。当前原画仍是 1536×1024，此改动改善放大采样，不代表已补齐更高分辨率的原画细节，人物、镜头和蓝图比例保持原值。

房间 UI 使用相同羊皮纸与黄铜语言，逐房切换独立徽记、章节印签、房间用途和真实路线缩略图。生命、资源、护盾与技能键位维持一致。装饰用途仅作环境叙事，不赋予新的交互或战斗规则。

## 维护与验收

新增房间时显式定义徽记、中心、半径、铺地宽度与两组陈设；位置不使用运行种子随机。奖励展示与目标剪影仍按有效纹理 region 预留、去重，不把素材别名当作不同图片。装饰使用原脚点排序与遮挡淡化，不增加看不见的碰撞。

定向验收入口：`tools/test.ps1 -Suite room_presentation -Graphical`。定向检查确认 28 个独立纹理路径和不同像素摘要，以及任务点、入口出口、信标、首领反制与固定奖励的运行可达性。总览中的青线仅用于标示实际可走边界与功能点，中心镜头保留生产 HUD。实际 GPU 画面与总览输出至 `artifacts/room-presentation/`，属于可重新生成的验收产物，不入库。此目录的图册展示生产房间渲染，不用设计效果图代替实际画面。最新完成的检查证据记入 `DEVELOPMENT_PROGRESS.md`。

全屏采样定向入口：`tools/test.ps1 -Suite environment_clarity -Graphical -SkipImport -SkipRestart`。真实 GPU 对比放大边缘及放大/缩小的六块与整图一致性，再通过生产房间加载 L16、BO04，在固定 1280×720 逻辑画布下捕获 1280×720、1920×1080 窗口，以及 L16 的实际全屏。改前/改后画面输出至 `artifacts/environment-clarity/`，不入库；检查使用隔离存档，不更改玩家档案。
