# 开发路线图

更新：2026-10-03。这里列当前未完成事项，已失效的 PR 过程和旧六槽实施步骤已移除。当前范围见 [开发进度](DEVELOPMENT_PROGRESS.md)。

| 优先级 | 区域 | 状态 | 完成条件 |
|---|---|---|---|
| P0 | 前四关自然平衡 | 待验证 | 多职业、难度、种子和合法成长路径；区分裸装与正常构筑，记录真实治疗/伤害与撤离结果 |
| P1 | B05、B06 | 隔离候选 | 普通怪/首领/房间/装备/存档链路与自然获取实测完成后，再决定调整正式闸门 |
| P1 | 职业动作与手感 | 部分接入／待完善 | 八方向完整动作、转向保持相位、枪口与脚点一致，实际群战可读，不由视觉改变碰撞或伤害 |
| P1 | 三职业与十二选四重构 | 独立分支代码、新版 UI、36 技能释放、控制／反击及首关检查完成／整体待验收 | 完整新美术、更多章节、长期平衡与人工手感；HUD 保留现有布局 |
| P0 | 原创角色美术身份 | 三职业新身体身份与八方向共享家族实际接入，并通过 Main 图形检查 | 十二技能各自的连续八方向动作、原生 2K 美术与人工手感验收仍待完成；共享身体姿态不代表完整技能动画 |
| P1 | 资源与性能 | 待验证 | 实际目标硬件、完整切房与长时间内存表现；共享图块不算流式加载 |
| P2 | 药品 | 未实现 | 库存、恢复、冷却、职业资源、输入/HUD、暂停/死亡与保存一致 |
| P2 | 可见换装 | 未实现 | 身体附件跨方向/动作接入，与实际穿戴一致 |
| P2 | 扩展遗物构筑 | 部分接入 | 独立种族池、完整效果、预算和防递归，显示真实触发条件 |
| P2 | B07–B12 | 未实现 | 按关完成普通怪、首领、房间、装备、资源、保存与验证，禁止仅凭设计册标完成 |
| P2 | 召唤师 | 未实现 | 按职业完成动作、技能、AI/召唤边界、装备资格、UI、保存和自然玩法 |

十二关的设计入口见 [levels/README.md](levels/README.md)。新工作按 `docs/characters/<profession>`、`docs/system/<feature>`、`docs/levels/<chapter>/{enemies,bosses,rooms,...}` 更新；状态统一使用“已接入”“候选／待验证”“未实现”。

数值默认采用当前参数，不以旧快照、目标表或候选倍率悄悄修改生产值。固定房间设计 JSON 与运行 JSON 分开，合入时仅按批准字段更新并保留种族、首领机关、奖励和任务。
