# 游戏开发规范

依据用户已确认要求维护。当前停止新增玩法，恢复开发时使用本规范。Windows 中文 Markdown 统一 UTF-8，读取必须指定 `Get-Content -Encoding UTF8`。

## 视觉和 UI

明亮手绘卡通奇幻，高机位三分之四斜俯视、近等距构图、2.5D 立体质感、暖阳和清新配色。统一角色比例、描边、材质和镜头尺度。UI 使用米白羊皮纸、黄铜、深紫文字与圆技能徽章，状态色跨地图一致。

种族由轮廓、建筑、生态和机制区分。虫族彩壳透光琥珀、僵尸完整卡通身体和缝补布料、炎魔明亮赤陶火焰，避免压抑黑红与血腥腐烂。野怪和装备有奇幻创意，不能只给旧机械换色。技能符合职业、种族与首领身份。

复用现有珐琅主操作、卷轴次操作、箭头返回、蜡封危险操作、页签及黄铜选择器；插槽保持浅色中心、细边和图文空间，不回退成所有页面相同的大矩形按钮。新增交互设施同步制作图标、状态和说明。

## 固定地图与房间差异

地形、入口出口、目标、信标、地标、陈设和路线人工固定；随机只用于批准的敌群、奖励与信标功能。每族房间风格一致、构图不同，按工位、生活区或机关区成组，中心及主路开阔。

禁止内场大方块坑池、地板拉成高墙、同物件整排重复和无意义孤立陈设。功能目标、装饰、奖励箱造型清楚不同；按实际纹理与 region 去重，别名不算新素材。

当前 2800×1800 蓝图统一映射 0.58，人物、技能距离和 HUD 不跟随缩小。地景与可走多边形共用变换，所有功能点可达。按真实脚点排序、遮挡淡化，以脚底小范围定义碰撞，不用整张立体图挡路。镜头不露画外，HUD 固定屏幕层。

文档 JSON 与运行 JSON 不同，禁止整房覆盖 `data/fixed_rooms.json`。草稿只按批准字段合并，保留种族、首领反制、固定奖励、遭遇及状态，更新对应图纸和总览。明确区分效果图和真实截图。

当前六图块共享母图，不代表显存流式加载。独立模块记录接头、转角、色卡、砖尺度、出口、脚点及碰撞，固定组合并核对接缝。不能只切分错误大图而不改比例和边缘。

## 操作与战斗

默认右键移动、左键/A 普攻、QWER 技能、空格闪避、F 交互、B 背包、M 路线、Tab 技能详情、Esc 暂停。支持自定义与旧配置，文案显示实际绑定。每职业一个独特被动替代 C/V。

身体、枪口、弹体和反馈以本次实际提交方向为准，绘制不驱动伤害。自动普攻不追敌，不绕过距离、视线、资源和等级。接招队列有界，暂停、弹窗、背包、闪避、死亡或切房清空。

增加敌群使用有限波次，保留并发、弹体和召唤上限。首领预警、锁定、攻击及收势清楚；关闭技能路径后保留必要危险提示。数字显示实际伤害、恢复和护盾，暴击放大但不淹没画面。震动默认关闭，降低特效保留关键信息。

## 装备与保存

八槽目标为头、胸、手、裤、鞋、戒、饰品、武器。八格 UI 不等于后端完成；登记、属性、掉落、配装、保存和迁移一起贯通。模板、实例、品质、词条与强化分别保存，同模板多件不能按模板 ID 覆盖。

掉落和遗物遵守本族、职业特性。新装备撤离后永久入库；换装不回血、不重置冷却、不重复领奖。死亡保留等级与已结算经验，按明示规则扣本局金币和未结算经验。

购买、出售、洗练、提升、领奖与撤离一次结算；失败或重复点击不重复扣款、重抽或发奖。检查点保存值数据，不保存节点引用。检查使用隔离存档，不能改实际玩家档 `%APPDATA%/AbyssSalvagerM1/profile.json`。

## 资源与清理

运行素材记录真实路径、尺寸、region、脚点、碰撞及来源。旧版本名不能单独证明废弃，动态路径和旧档 fallback 也是有效依赖。拒收候选不启用；字体、许可、版权和批准设计不能作为垃圾删除。

构建、下载、截图副本、试听、日志、隔离存档及 Python 缓存不入 Git；正式设计册、源代码、现有必要检查和来源记录入库。清理前确认目标不被进程使用，Windows 递归删除先校验绝对路径在工作区内，再用 `Remove-Item -LiteralPath`。保留引擎程序、实际存档和活跃缓存。

## 提交与最少必要检查

主分支 main，需要分支时使用 codex/ 前缀。按责任或功能提交，现有代码与文档清理分开，说明实际改变和未完成范围，方便 diff。合并后删除已合并临时分支，不强删未合并工作、不强推覆盖远端。

只运行与修改相关的一项定向检查或短段实机观察；资源清理做导入/解析。退出码零仍检查 SCRIPT ERROR/ERROR。不要新建无意义测试、重复无变化验证、默认跑全部检查或自行扩大 review。

多 agent 仅在授权时使用，明确单关和文件责任，不覆盖他人修改。要求停止后停止代码、图片与测试新增，只读交接。进度区分原型、待验证代码、草稿和待开发；不能把需求或素材清单当完成证据。
