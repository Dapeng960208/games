# 深渊拾荒者 / Abyss Salvager

明亮手绘卡通奇幻主题的 Godot 单人动作游戏，使用高机位斜俯视、近等距构图与 2.5D 立体表现。当前版本包含前四个种族地牢原型；仓库保留游戏代码、运行资源、启动工具、设计与待办说明。本机截图、录屏、运行日志和存档不入版本。

## 当前可玩内容

- 三个职业、每职业一名英雄：斧卫积攒破势重击、枪手游走标记爆发、术士以四拍有效普攻回蓝并为目标附近节点蓄能，配合Q/R充能后用F引爆。节点三枚晶格与分级提示音显示电荷，零层也能引爆、满能更强。Q／鼠标右键／F／R 随等级 1／2／3／4 解锁，正式远征开局即可使用 Q。
- 独立“完整技能试玩”：Lv8即可体验全部技能，不改写正式存档。入口有安全回路练习，结束后可换职业。
- 普攻、Q、鼠标右键、F、R可按顺序衔接：在前招收势阶段输入后招，最多缓存三个后继动作，命中/射击/突进完成后可提前进入下一招，减少剩余后摇。每项输入最多保留0.9秒；技能仍须满足等级、资源、冷却与落点条件，执行时才扣除一次消耗。
- 引雷回路：C放置两枚引雷桩，引敌人或弹道穿线积攒电能，V释放线状爆发；满能后不再拦截弹道，重布会清空电能。
- 远征长度由出发等级决定：1–4级6站、5–9级8站、10–14级10站、15级以上12站。新局保持所选种族与本族首领；较长路线以不同房间种子复用本族模板，包含分支、中途补给与撤离点。历史跨区路线仅用于兼容旧存档。
- 晴辉遗庭、琥珀虫巢、南瓜墓镇、赤岩战寨四个种族区域，24 个房间变体、36 类普通怪与四个分阶段首领。供能破盾、毁巢断援、封墓抑制有限复苏、引诱冲锋破障是当前正式远征的四项主题机制。
- 金币补给、装备加成与套装、工坊配装和安全检查点恢复。清房掉落可立即装备到本局，也可保留当前装备；新掉落仍须撤离才永久入库。换装不回血、不重置冷却或首杀收益；旧存档若有来源不明的临时增益，则保留当前装备、撤离后在营地配装。
- 正式远征只掉落本族且适合职业的装备；当前 60 个稳定模板分为四族、每族 15 件。五档难度实际提高敌群数量、敌人等级与收益：普通房掉落 1～2 件，首领掉落 2～4 件；较高难度提供预强化 +1～+3 的真实装备加成。强化等级与未来白、绿、紫、金品质系统分别设计。
- 固定点信标每轮随机功能，靠近 72 世界单位且视线畅通时自动恢复或给予状态，无需 E；成功使用后冷却 45 秒，再次触发需要离开范围后返回。满生命或满资源不会浪费对应恢复信标。
- 三个职业的现有遗物增加四族主题适配：晴辉有效普攻回职业资源、琥珀延长遗物持续伤害、墓镇斧卫低生命强化回震护盾、战寨近距离强化裂地／分流／回响。每项仍受原有遗物拥有条件与触发限制约束。
- 新版单种族副本死亡损失本局 50% 金币，并丢弃未结算的战斗经验；已经结算的角色经验、等级及永久装备保留。历史副本仍按原存档版本结算。

十二关总设计与后八关待办见 [关卡设计](docs/LEVEL_DESIGN_V1.md) 和 [实施路线图](docs/LEVEL_ROADMAP.md)。前四关各自的 UI、敌人、装备、地图和遗物设计保存在 [单关设计目录](docs/levels)。八槽、四档随机词条、独立装备实例、背包售出、洗练、快捷药品和角色可见换装属于后续完整装备系统阶段；当前强化 `+N` 不代表品质稀有度。

针对当前原型的必要检查可运行 `tools/verify_first_four.ps1`；加 `-Showcase` 会生成一次真实游戏截图。默认只执行种族路线、掉落结算、首领、主题机制、遗物与死亡规则检查。
- 战斗HUD用角色彩绘头像、纸面任务提示、路线节点与圆形技能徽章显示当前状态；悬停或键盘聚焦头像/等级区域，可查看经验、下一成长目标与本房待结算经验，点击可查看角色属性。技能解锁提示按顺序播放，结算说明装备是否带回；待提交经验不会提前解锁技能。
- 三个遗物槽位按职业提供九种实际效果，各两阶；斧卫裂地破甲、枪手弹道流血、术士法术回响与节点充能。
- 物理/魔法/真实伤害、攻击力/法强、双抗/穿透、暴击/暴伤、重伤/无敌/减伤/持续伤害进入真实战斗结算。
- 四首原创场景音乐；本轮重做三职业分层打击音效，区分挥空与命中，并提供金属、石质、有机目标的接触音色及四种实际波形变体。角色、敌人、首领、道具和界面使用本项目原创资源。
- 地图采用明亮的奶油色石板、青绿水面与植物，并以区域配色区分四个区域。B01/B03/B04的普通干燥障碍缩至原宽高的一半以内，最大240×180世界像素；桥梁机关及液面保留各自结构并拓宽安全通路。随机实体道具通常每房4–7件、上限8件，其中2–3件普通道具换为小脚点的彩绘立柱；中央留出战斗空间与横纵通路，边缘装饰不参与碰撞。
- 移动按角色圆形接触面处理障碍与墙角滑动，减少贴角反复挤动；沿用缓存寻路，并将静态地形绘制与动态效果分开，仅在障碍几何或绘制对象变化时刷新静态画布。
- 装备选择优先比较同槽位，直接显示收益、损失与建议，建议不会自动购买。

界面按已选定的第三版明亮插画方向重做：奶油纸面、黄铜描边、青绿强调色与深紫文字，营地与主菜单使用日光庭院背景；三名英雄拥有独立彩绘胸像，导航入口和十二个职业技能使用专门绘制的图标。任务信息收为战斗右侧的纸面清单，回路保留独立的蓝色闪电球和电荷节点。36类普通敌人与四个首领采用珊瑚、靛蓝、翡翠、暖铜与紫晶等配色，保留原有身体、姿态与动作资源。

关卡在现有2D地面坐标与碰撞基础上加入2.5D视觉层次：外围平台侧面、普通干燥障碍抬高的石质底座、彩绘立柱与残墙形成厚度和高度；桥梁空隙与液面保留凹陷结构，位于角色下层。道具、任务物体、建筑与出口拱门按真实脚点和角色一起排序，角色被高处轮廓遮住时该轮廓淡化；接地阴影留在地面，危险预警保持在上层。立柱替换已有普通实体道具，外围建筑与出口拱门不新增碰撞，已拓宽的通路仍由实际地面碰撞决定。

“设置与操作”提供独立的镜头震动开关，默认关闭；没有该字段的旧存档也按关闭处理。它与“降低特效”分别保存；降低特效开启时仍会抑制镜头冲击。障碍、移动与绘制调整用于改善实际游玩舒适度，具体帧率仍取决于设备与战斗场景。

新版打击反馈已接入本地 Demo：根据实际扣血、护盾吸收和护盾破裂，区分身体命中、盾击与破盾的局部特效和职业音色；同次伤害优先播放盾音，破盾时音乐短暂让位。枪手弹体改为直线显示，鼠标右键采用抵肩、瞄准与后坐三姿态保持持枪稳定；连射按真实出弹发声，中断后停止未来枪声。斧卫CH01已接入与彩绘胸像一致的战斧全身素材家族，覆盖战斗待机、走路、普攻、横扫及Q/F/R/闪避的现有姿态映射，角色卡使用同一风格胸像；满三层破势时鼠标右键免怒气，仍有四秒冷却。横扫保留独立扫风声，真实命中再叠加材质重击音。当前只精做部分代表动作，主观手感、混音和完整角色动画仍需打磨。

普通、精英及召唤怪物死亡时，复用现有身体姿态做短暂倒伏、退场与材质音效，不再瞬间消失；残影不挡路，降低特效时改为静态淡出。实际播放命中声音时，背景音乐短暂降低音量，为轻击和重击留出空间，随后恢复，音量设置保持不变。

敌人和首领预警显示在角色与技能特效上方，跟踪用暖橙、锁定用红色，进度连续推进。有效命中的技能击退改为短时连续减速推移，精英位移减半、首领免疫；足够大的可达推移会立即取消尚未释放的近战。身体受击只短暂停留局部姿态，AI、伤害和预警继续运行。补给护盾在下一房首次吸收伤害时才开始四秒倒计时。

当前仍为 Demo。奖励分支、失败积累与奖励事务已通过定向检查，路线预览及一般结算画面已复核；自然战斗平衡和多局成长节奏尚未验收。斧卫新素材家族每个正/背视角包含四个通用姿态、四个步态、六个普攻姿态与六个横扫姿态；Q/F/R/闪避复用通用姿态，并以水平镜像形成四朝向。枪手保留正/背视角各四个关键步态及水平镜像。两者尚非完整八方向连续动画；术士正面步态候选未通过验收，仍未启用。完整角色动作与完整十二遗物也尚未实现，打击感和音效仍需继续检查。

## Windows 运行

需要 **Godot 4.7 或更高版本**。安装脚本默认获取并校验官方 **4.7.2-stable** Windows x64 便携引擎。引擎二进制和独立游戏构建不包含在源码仓库中。

首次下载后，在项目目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\setup.ps1
```

随后双击 `RUN_GAME.cmd`，或运行：

```powershell
.\tools\run.ps1
```

已有引擎可通过 `-EnginePath` 指定路径，或设置 `GODOT_BIN`。打开编辑器使用 `.\tools\run.ps1 -Editor`。首次启动会重新导入资源；获取引擎需要联网，游戏本身不需要联网或注册账号。

## 操作

WASD／方向键移动，鼠标瞄准，鼠标左键普攻，Q／鼠标右键／F／R职业技能，空格闪避，C布置引雷桩，V释放回路，E交互，M查看路线（入口或清关后可直接选下一关），Tab查看技能/装备/角色属性，Esc暂停。

“鼠标右键”就是鼠标右侧的按键，界面不再以RMB缩写表示。第一轮建议选择“完整技能试玩”，在入口先练习布线和职业技能，再按M选择下一处矿区。

连招时，在当前招式最后约0.24秒的接招窗口内按下下一招；前面已有动作排队时可继续输入，最多排入三个后继动作。可尝试“普攻→鼠标右键→F”或“Q→鼠标右键→R”，但需先解锁对应技能并留足资源。HUD技能图标显示各自的1/2/3接招顺序，角色附近也显示后续接招提示。暂停、打开阻断战斗的界面、闪避、死亡或离开房间会清空接招；左键在阻断时仍按住，需先松开再重新按下。接招不会跳过前摇、未完成的命中段，也不会取消技能冷却。

完成右侧纸面提示的任务，清理现存敌人后到出口继续。中途补给消耗本局金币；掉落装备须成功撤离后进入永久库存。击败区域首领并成功撤离后解锁下一区域。

安全阶段保存退出保留当前状态；战斗中退出回到本房已提交入口，本房未提交战利品不保留。正式存档位于 `%APPDATA%\AbyssSalvagerM1\profile.json`，不随源码上传。

## 项目结构

| 目录 | 内容 |
|---|---|
| `scripts/`、`scenes/` | 核心状态、战斗、关卡和 UI |

| `data/`、`config/` | 角色、装备、房间、敌人与数值配置 |
