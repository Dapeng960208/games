# 深渊拾荒者 / Abyss Salvager

原创废矿工业奇幻主题的 Godot 2D 单人动作游戏，当前为连续远征 Demo。本仓库保留游戏代码、运行资源、启动工具与许可说明；开发截图、录屏、测试代码和本机验收产物不随仓库上传。

## 当前可玩内容

- 三个职业、每职业一名英雄，拥有不同资源机制和技能；Q／右键／F／R 随角色等级 2／4／6／8 解锁。
- 每局八站：入口整备、五个不重复的战斗／机制模板、中途补给和区域首领；支持分支选路，以及第 4／7 站提前撤离。
- 四个区域、24 个房间模板，包含搬运、护送、守点、破坏和动态机关；36 类普通敌人与四个分阶段首领。
- 金币补给、装备加成与套装、工坊配装、待带回装备和安全检查点恢复。
- 三件可选遗物，各两阶。角色、敌人、首领、道具和界面采用本项目原创设计资源。
- 已修复隔障碍追击时重复重建寻路图导致的贴墙卡顿。

当前仍为 Demo。完整十二遗物、部分次要关卡效果与奖励分支、完整角色动画和自然战斗平衡尚未完成。

## Windows 运行

需要 **Godot 4.7 或更高版本**。安装脚本默认获取并校验官方 **4.7.2-stable** Windows x64 便携引擎。引擎二进制和独立游戏构建不包含在源码仓库中。

首次下载后，在项目目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\setup.ps1
```

随后双击 `RUN_GAME.cmd`，或运行：

```powershell
.\tools\run.ps1
```

已有引擎可通过 `-EnginePath` 指定路径，或设置 `GODOT_BIN`。打开编辑器使用 `.\tools\run.ps1 -Editor`。首次启动会重新导入资源；获取引擎需要联网，游戏本身不需要联网或注册账号。

## 操作

WASD／方向键移动，鼠标瞄准，左键普攻，空格闪避，E 交互，M 查看路线，Tab 查看详情，Esc 暂停。

完成顶部提示的任务，清理现存敌人后到出口继续。中途补给消耗本局金币；掉落装备须成功撤离后进入永久库存。击败区域首领并成功撤离后解锁下一区域。

安全阶段保存退出保留当前状态；战斗中退出回到本房已提交入口，本房未提交战利品不保留。正式存档位于 `%APPDATA%\AbyssSalvagerM1\profile.json`，不随源码上传。

## 项目结构

| 目录 | 内容 |
|---|---|
| `scripts/`、`scenes/` | 核心状态、战斗、关卡和 UI |
| `assets/` | 游戏美术、音效、字体及资源元数据 |
| `data/`、`config/` | 角色、装备、房间、敌人与数值配置 |
| `localization/` | 界面本地化 |
| `tools/` | 引擎安装、发现与启动工具 |
